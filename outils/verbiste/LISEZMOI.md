# Données Verbiste

Ces fichiers proviennent de **Verbiste**, logiciel libre de conjugaison française de Pierre Sarrazin :
http://sarrazip.com/dev/verbiste.html (copie prise dans le paquet Debian `verbiste` 0.1.49).

- `verbs-fr.xml` : plus de 7 000 verbes, chacun associé à un modèle de conjugaison.
- `conjugation-fr.xml` : les modèles de conjugaison (terminaisons de chaque temps).
- `COPYING` : texte de la licence.

Copyright (C) 2003-2016 Pierre Sarrazin. Distribués sous **GNU GPL version 2 ou ultérieure**.

Le Projet Plume les conserve tels quels, comme source du fichier généré `contenu/conjugaison.js` (produit par `outils/generer_conjugaison.py`). Ce fichier généré est lui aussi sous GPL.
