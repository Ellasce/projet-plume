# Tout, tous, toute, toutes

Identifiant : tout
Niveau : lycée
Résumé : Déterminant, pronom ou adverbe : tout ne s'accorde pas toujours.

## Fiche

**Tout déterminant ou pronom** s'accorde avec le nom qu'il accompagne ou remplace.
> tous les jours, toutes les filles, ils sont tous venus

**Tout adverbe** signifie « entièrement, très ». Il est **invariable** :
> Ils sont tout étonnés. Elle est tout heureuse.

**Exception** : devant un adjectif féminin qui commence par une **consonne** ou un **h aspiré**, l'adverbe s'accorde (pour l'oreille).
> Elle est toute rouge. Elles sont toutes honteuses.

Devant une voyelle ou un h muet, il reste invariable : elles sont tout heureuses.

## Pour aller plus loin

- **Toute autre** solution (= n'importe quelle autre) ≠ une **tout autre** affaire (= complètement différente).
- De **tous** côtés.

## Exercices essentiels

1. Ils ont travaillé [tout → tous] les week-ends.
   Pourquoi : Déterminant devant « les week-ends » (masculin pluriel) : « tous ».

2. Elle était [tout → toute] rouge de honte.
   Pourquoi : Adverbe devant un adjectif féminin commençant par une consonne : accord, « toute ».

3. [Toute → Tous] les invités sont arrivés.
   Pourquoi : Déterminant accordé avec « les invités » : « tous ».

4. Les filles sont [tout → toutes] fières de leur victoire.
   Pourquoi : Adverbe devant un adjectif féminin commençant par une consonne (f) : « toutes ».

5. Elles sont ___ heureuses de te revoir.
   Choix : **tout** / toutes
   Pourquoi : Adverbe devant un h muet : invariable, « tout heureuses ».

6. Il lit ___ les soirs avant de dormir.
   Choix : tout / **tous**
   Pourquoi : Déterminant devant « les soirs » : « tous ».

7. Tri : Dans chaque phrase, « tout » est-il adverbe ou déterminant / pronom ?
   Colonnes : Adverbe (= très) | Déterminant ou pronom
   - Ils viennent tous les jours. → Déterminant ou pronom
   - Ils sont tout étonnés. → Adverbe (= très)
   - Elle a dormi toute la nuit. → Déterminant ou pronom
   - Elle est toute petite. → Adverbe (= très)
   - Ils sont tous venus. → Déterminant ou pronom
   - Elles sont tout heureuses. → Adverbe (= très)
   Pourquoi : L'adverbe signifie « très, entièrement » ; il ne s'accorde que devant un adjectif féminin commençant par une consonne ou un h aspiré (toute petite).

8. Il marche [tout → tous] les matins.
   Pourquoi : Déterminant devant « les matins » (masculin pluriel) : « tous ».

9. J'ai été très occupé [tout → toute] la matinée.
   Pourquoi : Déterminant devant « la matinée » (féminin singulier) : « toute ».
   Source : LanguageTool (AGREEMENT_TOUT_LE[3]#4)

10. Elle porte une veste [tout → toute] neuve.
   Pourquoi : Adverbe devant un adjectif féminin commençant par une consonne : « toute neuve ».
   Source : LanguageTool (ACCORD_TOUT_ADJECTIF[0]#0)

## Exercices avancés

11. Ils sont tout étonnés de la nouvelle.
   Pourquoi : Correct : adverbe (= très) devant une voyelle, invariable.

12. Elle est tout aussi compétente que lui.
   Pourquoi : Correct : « tout » modifie l'adverbe « aussi », il est invariable.

13. [Tout → Toute] autre solution serait plus coûteuse.
   Pourquoi : « Toute autre solution » = n'importe quelle autre solution : déterminant, accordé avec « solution ».

14. Elle était [tout → toute] honteuse de son erreur.
   Pourquoi : Devant un h aspiré (honteuse), l'adverbe s'accorde comme devant une consonne : « toute ».

15. Les touristes arrivaient de [tout → tous] côtés.
   Pourquoi : « De tous côtés » : déterminant accordé avec « côtés ».

16. Ah, mais ça, mon cher, c'est une [toute → tout] autre affaire.
   Pourquoi : « Tout autre » = complètement différente : adverbe, invariable.
   Source : LanguageTool (TOUS_TOUT[4]#0)

17. Il fera [tous → tout] pour sauver son frère.
   Pourquoi : Pronom signifiant « toute chose » : « tout ».
   Source : LanguageTool (TOUS_TOUT[16]#0)
