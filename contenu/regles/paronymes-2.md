# Les paronymes, 2e série : irruption, compréhensif, recouvrer

Identifiant : paronymes-2
Niveau : supérieur
Résumé : Faire irruption, entrer en éruption ; une explication compréhensible, un ami compréhensif.

## Analyse

Décision demandée : choisir entre deux mots proches par la forme mais de sens différent.
Cas de base
  1. éruption (d'un volcan, de boutons) / irruption (entrée brutale).
  2. compréhensible (qu'on peut comprendre) / compréhensif (qui comprend les autres).
  3. recouvrer (retrouver, récupérer) / recouvrir (couvrir entièrement).
  4. allocution (discours bref) / allocation (somme versée).
  5. consumer (détruire par le feu) / consommer (utiliser, manger).
  6. prolongement (dans l'espace) / prolongation (dans le temps).
  7. prodigue (qui dépense sans compter) / prodige (personne exceptionnelle).
Cas particuliers et pièges
  8. originel (des origines) / original (nouveau, singulier).
  9. littéral (à la lettre) / littéraire (qui concerne la littérature).
  10. notable (digne d'être noté ; personne importante) / notoire (connu de tous).
  Paires où l'usage hésite (émigrer / immigrer selon le point de vue) : non exercées.
Niveau : supérieur.

## En bref

- faire **irruption** (entrer brutalement) / un volcan en **éruption** ;
- une phrase **compréhensible** (claire) / un ami **compréhensif** (indulgent) ;
- **recouvrer** la vue (la retrouver) / **recouvrir** un mur (le couvrir) ;
- le **prolongement** d'une route (l'espace) / les **prolongations** d'un match (le temps).

## Fiche

Les paronymes se ressemblent mais n'ont pas le même sens :
- **éruption** (d'un volcan, de boutons) / **irruption** (entrée brutale : faire irruption) ;
- **compréhensible** (qu'on peut comprendre) / **compréhensif** (qui comprend les autres, indulgent) ;
- **recouvrer** (retrouver : recouvrer la santé, une dette) / **recouvrir** (couvrir entièrement) ;
- **allocution** (discours bref) / **allocation** (somme versée) ;
- **consumer** (détruire par le feu) / **consommer** (utiliser, manger) ;
- **prolongement** (dans l'espace : d'une route) / **prolongation** (dans le temps : d'un match, d'un contrat) ;
- **prodigue** (qui dépense sans compter : l'enfant prodigue) / **prodige** (personne exceptionnelle : un enfant prodige).

**Le test** : remplacez par une définition. « Entrer brutalement » → irruption ; « qui comprend les autres » → compréhensif.

## Pour aller plus loin

- **originel** (qui remonte aux origines : le péché originel) / **original** (nouveau, singulier).
- **littéral** (à la lettre : le sens littéral) / **littéraire** (qui concerne la littérature).
- **notoire** (connu de tous, souvent en mal : un escroc notoire) / **notable** (digne d'être noté ; une personne importante).

## Exercices essentiels

1. Les policiers ont fait [éruption → irruption] dans la salle.
   Pourquoi : Entrer brutalement : « faire irruption ».

2. Le volcan est entré en [irruption → éruption].
   Pourquoi : Un volcan actif : « éruption ».

3. Mon professeur est très [compréhensible → compréhensif].
   Pourquoi : Qui comprend les autres, indulgent : « compréhensif ».

4. Après l'opération, il a enfin [recouvert → recouvré] la vue.
   Pourquoi : Retrouver la vue : « recouvrer ».

5. Le président a prononcé une courte [allocation → allocution].
   Pourquoi : Un discours bref : « allocution ».

6. Le feu a [consommé → consumé] toute la forêt.
   Pourquoi : Détruire par le feu : « consumer ».

7. Le match est allé jusqu'aux [prolongements → prolongations].
   Pourquoi : Un temps supplémentaire : « prolongations ».

8. Le fils [prodige → prodigue] est revenu après avoir tout dépensé.
   Pourquoi : Qui dépense sans compter : « prodigue ».

9. Ses explications sont compréhensibles, et il se montre toujours compréhensif.
   Pourquoi : Correct : des explications claires (compréhensibles), une personne indulgente (compréhensif).

10. Le ___ de la route jusqu'au village est prévu.
    Choix : **prolongement** / prolongation
    Pourquoi : Dans l'espace (une route) : « prolongement ».

11. Tri : prolongement ou prolongation ?
    Colonnes : prolongement (espace) | prolongation (temps)
    - la route → prolongement (espace)
    - le contrat → prolongation (temps)
    - la ligne de métro → prolongement (espace)
    - le match → prolongation (temps)
    - le mur → prolongement (espace)
    - le séjour → prolongation (temps)
    Pourquoi : Ce qui s'étend dans l'espace : prolongement. Ce qui dure plus longtemps : prolongation.

## Exercices avancés

12. Le sens [littéraire → littéral] de cette expression est « à la lettre ».
    Pourquoi : À la lettre : « littéral ».

13. Selon la Bible, Adam et Ève ont commis le péché [original → originel].
    Pourquoi : Qui remonte aux origines : « originel ».

14. Il aime [invoquer → évoquer] ses souvenirs d'enfance.
    Pourquoi : Rappeler des souvenirs : « évoquer ».

15. C'est un fait notoire : cet homme est un notable de la ville.
    Pourquoi : Correct : « notoire » (connu de tous), « notable » (personne importante).

16. L'entreprise cherche à ___ ses créances.
    Choix : **recouvrer** / recouvrir
    Pourquoi : Récupérer une somme due : « recouvrer ».

17. Ce voleur [notable → notoire] a enfin été arrêté.
    Pourquoi : Connu de tous (en mal) : « notoire ».
