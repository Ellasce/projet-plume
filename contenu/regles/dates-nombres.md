# Écrire une date, un nombre, une somme

Identifiant : dates-nombres
Niveau : supérieur
Résumé : Le 1er mai, lundi 3 juin, 12 500 habitants, 12,50 €, 15 % : les règles d'écriture des dates et des nombres.

## Analyse

Décision demandée : écrire une date, un grand nombre, un nombre décimal, une somme, un pourcentage.
Cas de base
  1. Dates : jours et mois en minuscules (lundi 3 juin) ; le premier jour s'écrit 1er
     (le 1er mai) ; années sans espace ni point (2025).
  2. Grands nombres : on sépare les tranches de trois chiffres par une espace (12 500),
     jamais par un point.
  3. Décimales : virgule (12,50 ; 3,5 kg).
  4. Sommes et pourcentages : le symbole après le nombre, avec une espace (25 €, 15 %).
Cas particuliers et pièges
  5. Les années, les numéros de page ou de rue s'écrivent sans espace (l'an 2000, p. 1250).
Niveau : supérieur.

## En bref

- Dates : le **1er** mai ; **lundi** 3 **juin** (minuscules) ; l'an **2025**.
- Nombres : **12 500** (espace, pas de point) ; **3,5** (virgule).
- Symboles **après** le nombre : **25 €**, **15 %**.

## Fiche

**Les dates** :
- les **jours** et les **mois** prennent une **minuscule** : lundi 3 juin ;
- le premier jour du mois : le **1er** mai (et non « le 1 mai ») ;
- les **années** s'écrivent sans espace ni point : en **2025**, l'an **2000**.

**Les grands nombres** : on sépare les tranches de trois chiffres par une **espace**, jamais par un point.
> 12 500 habitants ; 1 000 000 d'euros

**Les décimales** : on emploie la **virgule** (le point est l'usage anglais).
> 12,50 euros ; 3,5 kg

**Les symboles** se placent **après** le nombre, séparés par une espace :
> 25 € ; 15 % ; 1,80 m

**Le test** : relisez en pensant aux usages français (virgule, espace) et non anglais (point, symbole devant).

## Pour aller plus loin

- On n'insère pas d'espace dans une année, un numéro de page ou un code : l'an 2000, page 1250.
- En lettres, on écrit « quinze pour cent » ; en chiffres, « 15 % ».

## Exercices essentiels

1. Rendez-vous le [1 mai → 1er mai] devant la mairie.
   Pourquoi : Le premier jour du mois s'écrit « 1er ».

2. Il est né le 3 [Mars → mars] 1990.
   Pourquoi : Les mois prennent une minuscule.

3. La ville compte [12.500 → 12 500] habitants.
   Pourquoi : Les tranches de trois chiffres se séparent par une espace, pas par un point.

4. Le prix est de [12.50 → 12,50] euros.
   Pourquoi : En français, les décimales s'écrivent avec une virgule.

5. Les prix ont augmenté de 15 [pourcents → %].
   Pourquoi : En chiffres, on écrit le symbole « % » après le nombre.

6. La place coûte [€12 → 12 €].
   Pourquoi : Le symbole de l'euro se place après le nombre.

7. Nous sommes le [Lundi → lundi] 3 juin.
   Pourquoi : Les jours prennent une minuscule.

8. En l'an [2.000 → 2000], tout le monde fêtait le nouveau millénaire.
   Pourquoi : Une année s'écrit sans espace ni point.

9. Le 1er janvier 2025, la ville comptait 2 345 678 habitants.
   Pourquoi : Correct : « 1er », année sans espace, grand nombre avec espaces.

10. Le billet coûte ___.
    Choix : **25 €** / €25 / 25.00€
    Pourquoi : Le symbole se place après le nombre, avec une espace.

11. Tri : écriture correcte ou fautive ?
    Colonnes : correcte | fautive
    - le 1er avril → correcte
    - le 1 avril → fautive
    - 3,5 kg → correcte
    - 3.5 kg → fautive
    - 10 000 euros → correcte
    - 10.000 euros → fautive
    Pourquoi : « 1er », la virgule décimale et l'espace entre les milliers sont les usages français.

## Exercices avancés

12. Il a gagné [1.000.000 → 1 000 000] d'euros.
    Pourquoi : Les tranches de trois chiffres se séparent par des espaces.

13. Le taux est de [4.2 % → 4,2 %].
    Pourquoi : Les décimales s'écrivent avec une virgule.

14. La facture s'élève à [$50 → 50 $].
    Pourquoi : En français, le symbole monétaire se place après le nombre.

15. La réunion aura lieu le mardi 12 mars à 9 h 30.
    Pourquoi : Correct : jour et mois en minuscules, heure avec le symbole « h ».

16. Il mesure ___.
    Choix : **1,80 m** / 1.80 m / 1.80m
    Pourquoi : Virgule décimale, puis espace avant le symbole « m ».

17. Rendez-vous le [Vendredi 5 Avril → vendredi 5 avril].
    Pourquoi : Les jours et les mois prennent une minuscule.
