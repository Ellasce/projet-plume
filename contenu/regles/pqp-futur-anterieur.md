# Plus-que-parfait et futur antérieur

Identifiant : pqp-futur-anterieur
Niveau : collège
Résumé : J'avais fini (avant un moment passé) ; j'aurai fini (avant un moment futur).

## Analyse

Décision demandée : choisir le temps de l'auxiliaire dans un temps composé.
Cas de base
  1. Plus-que-parfait : auxiliaire avoir ou être à l'imparfait + participe passé (j'avais fini,
     elle était partie). Action terminée avant une autre action passée.
  2. Futur antérieur : auxiliaire au futur + participe passé (j'aurai fini, nous serons partis).
     Action terminée avant une autre action future, souvent après quand, dès que, lorsque.
Cas particuliers et pièges
  3. Après « quand, dès que, lorsque » suivis d'un futur dans la principale : futur antérieur
     à l'écrit soigné (quand tu auras fini, tu pourras jouer).
  4. Le choix de l'auxiliaire (avoir ou être) suit les mêmes règles qu'au passé composé.
Hors sujet : j'aurai / j'aurais (règle « Le conditionnel passé »).
Niveau : collège.

## En bref

- **Plus-que-parfait** = auxiliaire à l'**imparfait** : j'**avais** fini, elle **était** partie. C'est **avant** un moment **passé**.
- **Futur antérieur** = auxiliaire au **futur** : j'**aurai** fini, nous **serons** partis. C'est **avant** un moment **futur**.

## Fiche

**Le plus-que-parfait** : avoir ou être à l'**imparfait** + participe passé.
> j'avais fini, tu avais mangé, elle était partie, nous étions rentrés
Il exprime une action **terminée avant une autre action passée** : quand je suis arrivé, le film **avait** déjà **commencé**.

**Le futur antérieur** : avoir ou être au **futur** + participe passé.
> j'aurai fini, tu auras mangé, elle sera partie, nous serons rentrés
Il exprime une action **terminée avant une autre action future** : quand tu **auras fini**, tu pourras jouer.

**Le test** : situez l'action sur une ligne du temps.
> avant un moment passé → **avais, étais** (plus-que-parfait) ;
> avant un moment futur → **aurai, serai** (futur antérieur).

**Les pièges** :
- Après **quand, dès que, lorsque**, si la suite est au futur, on écrit le futur antérieur : dès que j'**aurai reçu** ta lettre, je te répondrai.
- L'auxiliaire est le même qu'au passé composé : elle **est** partie → elle **était** partie → elle **sera** partie.

## Pour aller plus loin

- Le futur antérieur peut aussi annoncer un fait accompli à une date future : dans un an, ils **auront terminé** leurs études.
- Le plus-que-parfait s'emploie après « si » pour une hypothèse passée : si j'**avais su**…

## Exercices essentiels

1. Quand tu [as → auras] fini tes devoirs, tu pourras jouer.
   Pourquoi : Action terminée avant une action future (tu pourras) : futur antérieur, « auras fini ».

2. Dès que j'[ai → aurai] reçu ta lettre, je te répondrai.
   Pourquoi : Avant une action future (je répondrai) : « aurai reçu ».

3. Hier, j'ai retrouvé le livre que j'[ai → avais] perdu la semaine précédente.
   Pourquoi : Action terminée avant une autre action passée (j'ai retrouvé) : plus-que-parfait, « avais perdu ».

4. Elle [aura → avait] déjà mangé quand je suis arrivé.
   Pourquoi : Avant un moment passé (quand je suis arrivé) : « avait mangé ».

5. Demain à cette heure-ci, nous [sommes partis → serons partis].
   Pourquoi : Action terminée avant un moment futur (demain à cette heure-ci) : « serons partis ».

6. Quand la pluie a commencé, nous [sommes déjà rentrés → étions déjà rentrés].
   Pourquoi : Avant un moment passé : plus-que-parfait, « étions rentrés ».

7. Lorsque vous [avez → aurez] terminé, vous rendrez vos copies.
   Pourquoi : Avant une action future (vous rendrez) : « aurez terminé ».

8. Ils [ont → avaient] déjà vendu la maison quand nous l'avons visitée.
   Pourquoi : Avant un moment passé (quand nous l'avons visitée) : « avaient vendu ».

9. Quand il aura fini, il rangera ce qu'il avait sorti.
   Pourquoi : Correct : « aura fini » (avant « il rangera »), « avait sorti » (avant, dans le passé).

10. Le train ___ déjà quand je suis arrivé à la gare.
    Choix : **était parti** / est parti / sera parti
    Pourquoi : Avant un moment passé : plus-que-parfait, « était parti ».

11. Tri : plus-que-parfait ou futur antérieur ?
    Colonnes : plus-que-parfait | futur antérieur
    - j'avais fini → plus-que-parfait
    - tu auras mangé → futur antérieur
    - elle était venue → plus-que-parfait
    - nous serons rentrés → futur antérieur
    - ils avaient compris → plus-que-parfait
    - vous aurez lu → futur antérieur
    Pourquoi : Auxiliaire à l'imparfait (avais, était) : plus-que-parfait. Auxiliaire au futur (auras, serons) : futur antérieur.

## Exercices avancés

12. Je croyais qu'il [est → était] parti depuis longtemps.
    Pourquoi : Action antérieure à un moment passé (je croyais) : « était parti ».

13. Dans un an, ils [ont → auront] terminé leurs études.
    Pourquoi : Fait accompli à une date future : « auront terminé ».

14. Nous [sommes → serons] arrivés avant la nuit, je te le promets.
    Pourquoi : Une promesse pour l'avenir : futur antérieur, « serons arrivés ».

15. Elle avait oublié ses clés : elle a donc attendu dehors.
    Pourquoi : Correct : l'oubli a eu lieu avant l'attente, d'où le plus-que-parfait.

16. Dès que vous ___ la réponse, vous lèverez la main.
    Choix : **aurez trouvé** / avez trouvé / aviez trouvé
    Pourquoi : Avant une action future (vous lèverez) : futur antérieur.

17. Quand je suis rentré, mes parents [ont → avaient] déjà dîné.
    Pourquoi : Avant un moment passé (quand je suis rentré) : « avaient dîné ».
