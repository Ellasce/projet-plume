# notre ou nôtre, votre ou vôtre

Identifiant : notre-notre
Niveau : lycée
Résumé : Notre maison (devant un nom) ; la nôtre (avec le, la, les) : l'accent change tout.

## Analyse

Décision demandée : écrire notre / nôtre, votre / vôtre.
Cas de base
  1. notre, votre : déterminants possessifs, devant un nom, sans accent (notre maison, votre avis).
  2. le nôtre, la vôtre, les nôtres : pronoms possessifs, toujours précédés de le, la, les, avec un accent.
  Test : y a-t-il « le », « la » ou « les » juste avant ? Alors accent.
Cas particuliers et pièges
  3. Pluriel du déterminant : nos, vos (pas de « nôtres » devant un nom).
  4. Expressions : être des nôtres (venir avec nous), à la vôtre (pour trinquer).
  5. Prononciation : le o de « nôtre » est fermé, celui de « notre » est ouvert.
Niveau : lycée.

## En bref

- Devant un **nom** : **notre**, **votre**, sans accent → **notre** maison.
- Avec **le, la, les** devant : **nôtre**, **vôtre**, avec un accent → c'est **la nôtre**.

## Fiche

- **notre** et **votre** se placent **devant un nom**, sans accent : **notre** maison, **votre** avis.
- **le nôtre, la vôtre, les nôtres** remplacent un nom déjà cité. Ils prennent un **accent circonflexe** et sont toujours précédés de **le, la** ou **les**.

**Le test** : regardez le mot d'avant.
> Ce n'est pas votre voiture, c'est la nôtre. → « la » devant ✔ → **nôtre**.
> Merci pour votre aide. → un nom après ✔ → **votre**.

**Les pièges** :
- Au pluriel, devant un nom, on écrit **nos, vos** : **nos** amis.
- **les nôtres, les vôtres** prennent un s : ils jouent avec **les nôtres**.

## Pour aller plus loin

- **Être des nôtres** = venir avec nous : serez-vous **des nôtres** samedi ?
- **À la vôtre !** : pour trinquer, avec l'accent.

## Exercices essentiels

1. C'est [nôtre → notre] maison.
   Pourquoi : Devant le nom « maison » : déterminant, « notre » sans accent.

2. Ce n'est pas votre voiture, c'est la [notre → nôtre].
   Pourquoi : « La » devant, pas de nom après : pronom, « nôtre ».

3. [Vôtre → Votre] avis compte beaucoup.
   Pourquoi : Devant le nom « avis » : « votre » sans accent.

4. Ton jardin est plus grand que le [notre → nôtre].
   Pourquoi : « Le » devant : pronom, « nôtre ».

5. Merci pour [vôtre → votre] aide.
   Pourquoi : Devant le nom « aide » : « votre ».

6. Leurs enfants jouent avec les [notres → nôtres].
   Pourquoi : « Les » devant : pronom, « nôtres », avec accent et s.

7. Ce stylo est-il le [votre → vôtre] ?
   Pourquoi : « Le » devant : pronom, « vôtre ».

8. Nous avons vendu [nôtre → notre] vieux canapé.
   Pourquoi : Devant le groupe « vieux canapé » : déterminant, « notre ».

9. Votre chien et le nôtre s'entendent bien.
   Pourquoi : Correct : « votre chien » (devant un nom), « le nôtre » (pronom).

10. Cette valise est la ___.
    Choix : **vôtre** / votre
    Pourquoi : « La » devant, pas de nom après : « vôtre ».

11. Tri : avec ou sans accent ?
    Colonnes : notre, votre (devant un nom) | nôtre, vôtre (le, la, les)
    - C'est ___ tour. → notre, votre (devant un nom)
    - Ce sac est le ___. → nôtre, vôtre (le, la, les)
    - Voici ___ adresse. → notre, votre (devant un nom)
    - Leur maison ressemble à la ___. → nôtre, vôtre (le, la, les)
    - ___ professeur est malade. → notre, votre (devant un nom)
    - Nos idées et les ___. → nôtre, vôtre (le, la, les)
    Pourquoi : Devant un nom : sans accent. Après le, la, les : avec accent.

## Exercices avancés

12. Serez-vous des [notres → nôtres] samedi ?
    Pourquoi : « Être des nôtres » (venir avec nous) : pronom, « nôtres ».

13. À la [votre → vôtre] !
    Pourquoi : Pour trinquer : « à la vôtre », pronom avec accent.

14. Chacun a ses idées ; nous gardons les [notres → nôtres].
    Pourquoi : « Les » devant : pronom, « nôtres ».

15. Nos voisins ont repeint leur façade ; nous repeindrons la nôtre.
    Pourquoi : Correct : « la nôtre » remplace « notre façade ».

16. Je vous présente ___ fille.
    Choix : **notre** / nôtre
    Pourquoi : Devant le nom « fille » : « notre ».

17. C'est [nôtre → notre] tour de jouer.
    Pourquoi : Devant le nom « tour » : « notre ».

18. Leur équipe a gagné ; la [notre → nôtre] a perdu.
    Pourquoi : « La » devant : pronom, « nôtre ».
