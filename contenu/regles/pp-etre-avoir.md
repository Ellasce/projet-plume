# Participe passé avec être ou avoir

Identifiant : pp-etre-avoir
Niveau : lycée
Résumé : Avec être, on accorde avec le sujet ; avec avoir, jamais avec le sujet.

## Fiche

**Avec l'auxiliaire être**, le participe passé s'accorde en genre et en nombre avec le sujet.
> Mes cousines sont arrivées.
> La décision a été prise.

**Avec l'auxiliaire avoir**, le participe passé ne s'accorde **jamais avec le sujet**.
> Les enfants ont mangé.
> Nous avons fini.
(Il peut toutefois s'accorder avec un COD placé avant : c'est la règle suivante.)

**Employé sans auxiliaire**, le participe passé s'accorde comme un adjectif.
> Des fenêtres ouvertes.

## Pour aller plus loin

- Un masculin et un féminin réunis : accord au **masculin pluriel**.
- Avec « vous », le contexte indique le genre et le nombre : vous êtes arrivé**s** les premiers.

## Exercices essentiels

1. Mes cousines sont [arrivé → arrivées] hier soir.
   Pourquoi : Auxiliaire être : accord avec « mes cousines » (féminin pluriel).

2. Les enfants ont [mangés → mangé] toute la tarte.
   Pourquoi : Auxiliaire avoir : pas d'accord avec le sujet, et le COD « la tarte » est placé après.

3. Elle est [né → née] en 1990.
   Pourquoi : Auxiliaire être : accord avec « elle » (féminin).

4. Nous avons [finis → fini] le projet à temps.
   Pourquoi : Auxiliaire avoir : pas d'accord avec « nous ».

5. Les fenêtres sont restées ___ toute la nuit.
   Choix : ouvert / ouverte / **ouvertes**
   Pourquoi : « Ouvertes » se rapporte à « les fenêtres » (féminin pluriel), comme un adjectif.

6. Mes sœurs ont ___ le train de 8 h.
   Choix : **pris** / prises / prise
   Pourquoi : Auxiliaire avoir, COD placé après : « pris » reste invariable.

7. La décision a été [pris → prise] à l'unanimité.
   Pourquoi : « A été » : le participe s'accorde avec « la décision » (voix passive).

8. Madame Dupont n'est pas [allé → allée] en ville.
   Pourquoi : Auxiliaire être : accord avec « Madame Dupont », féminin.
   Source : LanguageTool (MADAME_EST_PPA[0]#0)

9. Les élèves ont [terminés → terminé] leurs devoirs.
   Pourquoi : Auxiliaire avoir et COD placé après (leurs devoirs) : participe invariable.
   Source : LanguageTool (AUX_AVOIR[9]#0)

10. Hier, la déclaration a été [soumis → soumise].
   Pourquoi : « A été » : accord avec le sujet « la déclaration » (féminin).
   Source : LanguageTool (ETRE_VPPA_OU_ADJ[22]#0)

## Exercices avancés

11. Les résultats seront publiés lundi.
   Pourquoi : Correct : auxiliaire être, accord avec « les résultats ».

12. Les portes ont été [fermé → fermées] à clé.
   Pourquoi : « Ont été » : voix passive, accord avec « les portes ».

13. Vous êtes [arrivé → arrivés] les premiers, bravo !
   Pourquoi : « Les premiers » montre que « vous » est un masculin pluriel : « arrivés ».

14. Elles ont [eues → eu] beaucoup de chance.
   Pourquoi : Auxiliaire avoir, COD placé après : « eu » reste invariable.

15. Ma sœur et mon frère sont partis tôt.
   Pourquoi : Correct : un masculin et un féminin donnent un accord au masculin pluriel.

16. Cette expérience m'a [permise → permis] d'être plus sociable.
   Pourquoi : Auxiliaire avoir : « m' » n'est pas un COD (permettre À quelqu'un), donc pas d'accord.

17. Seules les boissons et la nourriture sont [autorisés → autorisées].
   Pourquoi : Auxiliaire être, sujets « les boissons et la nourriture » (féminins) : « autorisées ».
   Source : LanguageTool (ETRE_VPPA_OU_ADJ[30]#1)
