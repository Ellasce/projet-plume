# L'accord du verbe avec son sujet

Identifiant : accord-sujet-verbe
Niveau : collège
Résumé : Trouver le vrai sujet, même s'il est loin ou placé après le verbe.

## Analyse

Décision demandée : accorder le verbe en personne et en nombre avec son sujet.
Cas de base
  1. Le verbe s'accorde avec son sujet. Test : « Qui est-ce qui… ? » / « Qu'est-ce qui… ? ».
  2. Sujet pluriel → verbe au pluriel ; plusieurs sujets → pluriel.
Cas particuliers et pièges
  3. Sujet éloigné du verbe (« Les enfants de ma voisine jouent »).
  4. Pronom placé entre le sujet et le verbe (« Je les vois », « il leur parle ») : ce n'est pas le sujet.
  5. Sujet inversé (« Où sont passées les clés ? », « Que disent les élèves ? »).
  6. Le pronom relatif « qui » : le verbe s'accorde avec le mot que « qui » remplace.
  7. Sujets coordonnés avec des personnes différentes (toi et moi → nous).
Hors sujet : la plupart, chacun, plus d'un… (règle « Accords délicats du verbe »).
Niveau : collège.

## En bref

Le verbe s'accorde avec son **sujet**. Pour le trouver, posez la question **« Qui est-ce qui… ? »** devant le verbe.
> Les enfants de ma voisine **jouent**. → Qui est-ce qui joue ? les enfants → pluriel.
> Je les **vois**. → Qui est-ce qui voit ? je → « les » n'est pas le sujet.

## Fiche

Le verbe s'accorde avec son **sujet**. Pour le trouver, posez la question **« Qui est-ce qui… ? »** (ou « Qu'est-ce qui… ? ») devant le verbe.
> Les enfants de ma voisine **jouent** dans le jardin. → Qui est-ce qui joue ? les enfants → pluriel.

**Les pièges** :
- Le sujet peut être **loin du verbe** : ne vous laissez pas tromper par le mot qui le précède juste avant.
- **les, leur, lui, me, te, nous, vous** placés juste avant le verbe ne sont **pas** le sujet : je **les** vois, il **leur** parle.
- Le sujet peut être **après le verbe**, surtout dans les questions : où **sont** passées les clés ?
- Plusieurs sujets donnent un **pluriel** : mon frère et ma sœur **viennent**.

## Pour aller plus loin

- Avec **qui**, le verbe s'accorde avec le mot que « qui » remplace : les livres qui **sont** sur la table ; c'est toi qui **as** raison.
- Des sujets de personnes différentes : **toi et moi** = nous → toi et moi **partons** ; **toi et lui** = vous → toi et lui **êtes** invités.

## Exercices essentiels

1. Les enfants de ma voisine [joue → jouent] dans le jardin.
   Pourquoi : Qui est-ce qui joue ? « les enfants » (pas « ma voisine ») : pluriel, « jouent ».

2. Je les vois souvent au marché.
   Pourquoi : Correct : le sujet est « je » ; « les » est un pronom complément.

3. Il les [mangent → mange] tous les matins.
   Pourquoi : Le sujet est « il » ; « les » n'est pas le sujet : « mange ».

4. Mon frère et ma sœur [vient → viennent] dîner ce soir.
   Pourquoi : Deux sujets : pluriel, « viennent ».

5. Le bruit des voitures [m'empêchent → m'empêche] de dormir.
   Pourquoi : Qu'est-ce qui m'empêche de dormir ? « le bruit » (pas « les voitures ») : singulier.

6. Où [est → sont] passées mes clés ?
   Pourquoi : Le sujet est placé après le verbe : « mes clés » (pluriel), donc « sont ».

7. Mes cousins nous [rend → rendent] visite chaque été.
   Pourquoi : Le sujet est « mes cousins » ; « nous » est un complément : pluriel, « rendent ».

8. Les feuilles de cet arbre [tombe → tombent] en automne.
   Pourquoi : Qu'est-ce qui tombe ? « les feuilles » : pluriel, « tombent ».

9. Les élèves de la classe de mon fils préparent un spectacle.
   Pourquoi : Correct : qui est-ce qui prépare ? « les élèves » : pluriel.

10. Le chat de mes voisins ___ toute la nuit.
    Choix : **miaule** / miaulent
    Pourquoi : Qui est-ce qui miaule ? « le chat » : singulier.

11. Tri : quel est le sujet du verbe en majuscules ?
    Colonnes : singulier | pluriel
    - Le prix des fruits AUGMENTE. → singulier
    - Les amis de Paul ARRIVENT. → pluriel
    - Je les ATTENDS. → singulier
    - Où SONT tes parents ? → pluriel
    - La couleur des murs PLAÎT. → singulier
    - Pierre et Lou CHANTENT. → pluriel
    Pourquoi : Le prix, je, la couleur sont singuliers ; les amis, tes parents, Pierre et Lou sont pluriels.

## Exercices avancés

12. Les livres qui [est → sont] sur la table appartiennent à Léa.
    Pourquoi : « Qui » remplace « les livres » : pluriel, « sont ».

13. C'est toi qui [a → as] gagné le concours.
    Pourquoi : « Qui » remplace « toi » : « tu as ».

14. Que [dit → disent] les spécialistes de cette question ?
    Pourquoi : Le sujet est après le verbe : « les spécialistes » (pluriel).

15. Toi et moi [partez → partons] demain matin.
    Pourquoi : « Toi et moi » équivaut à « nous » : « partons ».

16. Toi et lui [sont → êtes] invités à la fête.
    Pourquoi : « Toi et lui » équivaut à « vous » : « êtes ».

17. La liste des invités ___ sur le bureau.
    Choix : **est** / sont
    Pourquoi : Qu'est-ce qui est sur le bureau ? « la liste » : singulier.

18. Dans le jardin [pousse → poussent] des tulipes et des roses.
    Pourquoi : Les sujets sont placés après le verbe : « des tulipes et des roses », pluriel.

19. Ce sont mes parents qui m'ont appris à nager.
    Pourquoi : Correct : « qui » remplace « mes parents » : pluriel, « ont ».
