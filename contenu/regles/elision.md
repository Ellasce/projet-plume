# L'élision : l', qu', jusqu'à, presqu'île

Identifiant : elision
Niveau : lycée
Résumé : Lorsqu'il, jusqu'à, l'hôpital… mais le héros, presque arrivé, si elle.

## Analyse

Décision demandée : faire ou non l'élision (remplacer la voyelle finale par une apostrophe).
Cas de base
  1. le, la, de, je, me, te, se, ne, que deviennent l', d', j', m', t', s', n', qu'
     devant une voyelle ou un h muet (l'hôpital, qu'il).
  2. Les composés de « que » font de même : lorsqu'il, puisqu'il, quoiqu'il, jusqu'à, quelqu'un.
  3. si devient s' seulement devant il et ils : s'il, mais si elle.
Cas particuliers et pièges
  4. Pas d'élision devant un h aspiré : le héros, le hoquet, le hérisson.
  5. Pas d'élision devant « onze » : le onze mars.
  6. presque ne s'élide que dans presqu'île.
Niveau : lycée.

## En bref

- Devant une **voyelle** ou un **h muet**, on remplace la voyelle par une **apostrophe** : **l'**hôpital, **lorsqu'**il, **jusqu'**à.
- **Pas d'élision** devant un **h aspiré** : **le** héros, **le** hoquet.
- **si** ne s'élide que devant **il** : **s'il**, mais **si elle**.

## Fiche

- **le, la, de, je, me, te, se, ne, que** perdent leur voyelle devant une **voyelle** ou un **h muet** : **l'**arbre, **l'**hôpital, **qu'**il, **j'**aime.
- Les mots formés avec **que** font de même : **lorsqu'**il, **puisqu'**il, **quoiqu'**elle, **jusqu'**à, **quelqu'**un.
- **si** ne s'élide que devant **il** et **ils** : **s'il** vient, mais **si elle** vient.

**Le test** : le mot suivant commence-t-il par une voyelle ou un h muet (on fait la liaison : les‿hôpitaux) ?
> lorsque + il → **lorsqu'il**.
> le + héros (h aspiré : les / héros, sans liaison) → **le héros**.

**Les pièges** :
- Devant un **h aspiré**, pas d'élision : **le** héros, **le** hoquet, **le** hérisson, **la** hache.
- **presque** ne s'élide que dans **presqu'île** : il est **presque** arrivé.

## Pour aller plus loin

- On ne fait pas l'élision devant **onze** : le **onze** mars.
- Pour reconnaître un h aspiré, faites le pluriel : s'il n'y a pas de liaison (les / héros), il est aspiré.

## Exercices essentiels

1. [Lorsque il → Lorsqu'il] pleut, je lis.
   Pourquoi : « Lorsque » devant « il » : élision, « lorsqu'il ».

2. Je t'attendrai [jusque à → jusqu'à] midi.
   Pourquoi : « Jusque » devant « à » : « jusqu'à ».

3. [Le hôpital → L'hôpital] est fermé la nuit.
   Pourquoi : « Hôpital » commence par un h muet (les‿hôpitaux) : « l'hôpital ».

4. [L'héros → Le héros] du film est courageux.
   Pourquoi : « Héros » commence par un h aspiré (les / héros, sans liaison) : pas d'élision.

5. Reste à la maison, [puisque il → puisqu'il] pleut.
   Pourquoi : « Puisque » devant « il » : « puisqu'il ».

6. [Quelque un → Quelqu'un] a sonné.
   Pourquoi : « Quelqu'un » s'écrit avec une apostrophe.

7. Je ne sais pas [si il → s'il] viendra.
   Pourquoi : « Si » devant « il » : « s'il ».

8. Il a [l'hoquet → le hoquet] depuis ce matin.
   Pourquoi : « Hoquet » commence par un h aspiré : « le hoquet ».

9. Lorsqu'elle est arrivée, le héros dormait déjà.
   Pourquoi : Correct : « lorsqu'elle » (voyelle), « le héros » (h aspiré).

10. Nous avons fait le tour de la ___.
    Choix : **presqu'île** / presque île
    Pourquoi : « Presqu'île » est le seul mot où « presque » s'élide.

11. Tri : élision ou pas ?
    Colonnes : élision (l') | pas d'élision (le, la)
    - … hôtel → élision (l')
    - … héros → pas d'élision (le, la)
    - … haricot → pas d'élision (le, la)
    - … homme → élision (l')
    - … hache → pas d'élision (le, la)
    - … arbre → élision (l')
    Pourquoi : Devant une voyelle ou un h muet (hôtel, homme) : élision. Devant un h aspiré (héros, haricot, hache) : pas d'élision.

## Exercices avancés

12. Il est [presqu'arrivé → presque arrivé].
    Pourquoi : « Presque » ne s'élide que dans « presqu'île ».

13. Nous sommes [l'onze → le onze] mars.
    Pourquoi : Pas d'élision devant « onze ».

14. [S'elle → Si elle] vient, je pars.
    Pourquoi : « Si » ne s'élide que devant « il » ou « ils ».

15. Puisqu'il le faut, je viendrai jusqu'à la gare.
    Pourquoi : Correct : « puisqu'il » et « jusqu'à » : élisions devant une voyelle.

16. ___ hibou chante la nuit.
    Choix : **Le** / L'
    Pourquoi : « Hibou » commence par un h aspiré : « le hibou ».

17. J'ai vu [l'hérisson → le hérisson] dans le jardin.
    Pourquoi : « Hérisson » commence par un h aspiré : « le hérisson ».
