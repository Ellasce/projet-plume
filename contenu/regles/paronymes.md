# Les paronymes

Identifiant : paronymes
Niveau : supérieur
Résumé : Conjecture ou conjoncture ? Éminent ou imminent ?

## Fiche

Les paronymes sont des mots qui se ressemblent mais n'ont pas le même sens.
- **conjecture** (hypothèse) / **conjoncture** (situation d'ensemble)
- **éminent** (remarquable) / **imminent** (qui va arriver très bientôt)
- **perpétrer** (commettre un crime) / **perpétuer** (faire durer)
- **infecter** (contaminer) / **infester** (envahir en grand nombre)
- **infliger** (imposer une peine) / **affliger** (causer du chagrin)
- **effraction** (entrée en forçant) / **infraction** (violation d'une règle)
- **acception** (sens d'un mot) / **acceptation** (fait d'accepter)
- **inclinaison** (pente d'une chose) / **inclination** (penchant, goût)
- **induire** en erreur (tromper) / **enduire** (recouvrir d'un enduit)

## Pour aller plus loin

- **précepteur** (qui instruit un enfant) / **percepteur** (qui perçoit les impôts)
- **collision** (choc) / **collusion** (entente secrète)

## Exercices essentiels

1. La [conjecture → conjoncture] économique est défavorable.
   Pourquoi : La situation d'ensemble : « conjoncture ».

2. Le départ est [éminent → imminent] : montez dans le train.
   Pourquoi : Qui va arriver très bientôt : « imminent ».

3. Le crime a été [perpétué → perpétré] en pleine nuit.
   Pourquoi : Commettre un crime : « perpétrer ».

4. Ce quartier est [infecté → infesté] de moustiques.
   Pourquoi : Envahi en grand nombre : « infesté ».

5. Le juge lui a ___ une lourde amende.
   Choix : **infligé** / affligé
   Pourquoi : Imposer une peine : « infliger ».

6. Ce chercheur ___ a reçu un prix.
   Choix : **éminent** / imminent
   Pourquoi : Remarquable : « éminent ».

7. Les voleurs sont entrés par [infraction → effraction].
   Pourquoi : Entrer en forçant : « effraction ».

8. Dans la [conjecture → conjoncture] économique actuelle, les Français dépensent moins.
   Pourquoi : La situation économique d'ensemble : « conjoncture ».

## Exercices avancés

9. Ce mot a plusieurs acceptions.
   Pourquoi : Correct : « acception » = sens d'un mot.

10. L'inclinaison du toit est trop forte.
   Pourquoi : Correct : la pente d'une chose est une « inclinaison ».

11. Ce mot est pris dans son [acceptation → acception] la plus large.
   Pourquoi : Le sens d'un mot : « acception ».

12. Elle a une vraie [inclinaison → inclination] pour la musique.
   Pourquoi : Un penchant, un goût : « inclination ».

13. Le [percepteur → précepteur] enseignait le latin aux enfants du roi.
   Pourquoi : Celui qui instruit un enfant : « précepteur ». Le percepteur, lui, perçoit les impôts.

14. La [collusion → collision] entre les deux voitures a fait un blessé.
   Pourquoi : Un choc : « collision ». La collusion est une entente secrète.

15. Ils m'ont [enduit → induit] en erreur.
   Pourquoi : Tromper quelqu'un : « induire en erreur ». « Enduire » = recouvrir d'un enduit.
