# Le genre des noms piégeux : un astérisque, une oasis

Identifiant : genre-noms
Niveau : supérieur
Résumé : Un astérisque, un armistice, un tentacule… mais une oasis, une échappatoire, une acné.

## Analyse

Décision demandée : connaître le genre d'un nom dont la forme trompe, pour accorder
le déterminant et l'adjectif.
Cas de base
  1. Masculins souvent crus féminins : astérisque, armistice, tentacule, haltère, intervalle,
     apogée, éloge, en-tête, effluve, hémisphère, pétale, emblème.
  2. Féminins souvent crus masculins : oasis, acné, échappatoire, anagramme, épithète, orbite,
     icône, amnistie, apostrophe.
  Test : aucun test fiable ; on vérifie dans un dictionnaire et on retient.
Cas particuliers et pièges
  3. Devant une voyelle, « son » et « l' » masquent le genre (son orbite, l'apogée) :
     on accorde l'adjectif pour vérifier (une orbite basse, un apogée tardif).
  4. Noms à double genre (un / une après-midi, délice, amour, orgue) : non exercés.
Niveau : supérieur.

## En bref

Certains noms trompent par leur forme. Il faut **retenir** leur genre :
- **masculins** : un astérisque, un armistice, un tentacule, un haltère, un intervalle, un apogée, un en-tête ;
- **féminins** : une oasis, une acné, une échappatoire, une anagramme, une épithète, une orbite.

## Fiche

Le genre d'un nom ne se devine pas toujours. Ces mots sont souvent mal employés.

**Masculins** (on dit **un**) :
> un astérisque, un armistice, un tentacule, un haltère, un intervalle, un apogée, un éloge, un en-tête, un effluve, un hémisphère, un pétale

**Féminins** (on dit **une**) :
> une oasis, une acné, une échappatoire, une anagramme, une épithète, une orbite, une icône, une amnistie

**Le piège** : devant une voyelle, **l'** et **son** cachent le genre (l'apogée, son orbite). Accordez un adjectif pour vérifier : un apogée **tardif**, une orbite **basse**.

## Pour aller plus loin

- Certains noms changent de genre selon le sens ou le nombre (un orgue, de belles orgues ; un amour, de folles amours) : ce sont des cas à part.
- **Après-midi** peut être masculin ou féminin.

## Exercices essentiels

1. Il a mis [une → un] astérisque à côté du mot.
   Pourquoi : « Astérisque » est masculin : « un astérisque ».

2. Nous avons atteint [un → une] oasis au coucher du soleil.
   Pourquoi : « Oasis » est féminin : « une oasis ».

3. La pieuvre a huit tentacules très [longues → longs].
   Pourquoi : « Tentacule » est masculin : « longs ».

4. Il souffre d'[un → une] acné sévère.
   Pourquoi : « Acné » est féminin : « une acné ».

5. Les deux pays ont signé [une → un] armistice.
   Pourquoi : « Armistice » est masculin : « un armistice ».

6. Elle soulève des haltères très [lourdes → lourds].
   Pourquoi : « Haltère » est masculin : « lourds ».

7. Il cherche [un → une] échappatoire.
   Pourquoi : « Échappatoire » est féminin : « une échappatoire ».

8. Elle a écrit [une → un] long éloge de son professeur.
   Pourquoi : « Éloge » est masculin : « un long éloge ».

9. Cet hémisphère est le plus peuplé de la planète.
   Pourquoi : Correct : « hémisphère » est masculin : « cet hémisphère ».

10. Le satellite suit une orbite très ___.
    Choix : **basse** / bas
    Pourquoi : « Orbite » est féminin : « basse ».

11. Tri : masculin ou féminin ?
    Colonnes : masculin (un) | féminin (une)
    - astérisque → masculin (un)
    - oasis → féminin (une)
    - tentacule → masculin (un)
    - acné → féminin (une)
    - armistice → masculin (un)
    - échappatoire → féminin (une)
    Pourquoi : Un astérisque, un tentacule, un armistice ; une oasis, une acné, une échappatoire.

## Exercices avancés

12. Sa carrière a connu un apogée [tardive → tardif].
    Pourquoi : « Apogée » est masculin : « tardif ».

13. Laissez [une → un] intervalle de deux mètres.
    Pourquoi : « Intervalle » est masculin : « un intervalle ».

14. Elle a trouvé [un → une] anagramme amusante de son prénom.
    Pourquoi : « Anagramme » est féminin : « une anagramme ».

15. Une épithète bien choisie vaut mieux qu'un long éloge.
    Pourquoi : Correct : « épithète » est féminin, « éloge » est masculin.

16. Il a imprimé ___ en-tête sur chaque lettre.
    Choix : **un** / une
    Pourquoi : « En-tête » est masculin : « un en-tête ».

17. [Une → Un] effluve agréable s'échappait de la cuisine.
    Pourquoi : « Effluve » est masculin : « un effluve ».
