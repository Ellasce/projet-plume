# Participe présent ou adjectif verbal

Identifiant : participe-present-adjectif
Niveau : supérieur
Résumé : Fatiguant ou fatigant ? Convainquant ou convaincant ?

## Fiche

- Le **participe présent** exprime une action. Il est **invariable** et se termine toujours en **-ant**. Il peut avoir un complément.
> En le convainquant de rester… Le jour précédant la fête…
- L'**adjectif verbal** exprime une qualité. Il **s'accorde**, et son orthographe change parfois.
> Des arguments convaincants. Un travail fatigant.

**Paires à connaître** (participe / adjectif) :
- fatiguant / fatigant, convainquant / convaincant, provoquant / provocant, communiquant / communicant
- négligeant / négligent, précédant / précédent, différant / différent, excellant / excellent, influant / influent, équivalant / équivalent

**L'astuce** : si vous pouvez ajouter « très », c'est l'adjectif.

## Pour aller plus loin

- **équivalant** (participe) / **équivalent** (adjectif) ; **influant** / **influent**.

## Exercices essentiels

1. Ce travail est très [fatiguant → fatigant].
   Pourquoi : « Très » → adjectif verbal : « fatigant », sans u.

2. Ses arguments étaient [convainquants → convaincants].
   Pourquoi : Adjectif (qualité) : « convaincants », avec c.

3. Le jour [précédent → précédant] la fête, tout le monde était nerveux.
   Pourquoi : Action avec complément (précédant quoi ? la fête) : participe présent « précédant ».

4. Ces deux résultats sont [différants → différents].
   Pourquoi : Adjectif (qualité) : « différents », avec e.

5. C'est un élève ___ : il oublie toujours ses affaires.
   Choix : **négligent** / négligeant
   Pourquoi : Qualité (on peut dire « très négligent ») : adjectif « négligent ».

6. Les candidats ___ les critères seront convoqués.
   Choix : **remplissant** / remplissants
   Pourquoi : Participe présent avec complément (les critères) : invariable.

7. Tri : Participe présent (action) ou adjectif verbal (qualité) ?
   Colonnes : Participe présent | Adjectif verbal
   - En le convainquant de rester… → Participe présent
   - Des arguments convaincants. → Adjectif verbal
   - Un travail fatigant. → Adjectif verbal
   - Le jour précédant la fête… → Participe présent
   - Deux résultats différents. → Adjectif verbal
   - Les candidats remplissant les critères… → Participe présent
   Pourquoi : Le participe présent exprime une action et a souvent un complément ; l'adjectif verbal exprime une qualité et s'accorde.

8. Il a réussi en [convaincant → convainquant] ses collègues.
   Pourquoi : Action avec complément (convaincre ses collègues) : participe présent « convainquant ».
   Source : LanguageTool (CONVAINCANT_CONVAINQUANT[0]#0)

## Exercices avancés

9. En le convainquant de rester, tu nous as rendu service.
   Pourquoi : Correct : participe présent (action, avec complément) : « convainquant ».

10. Nous avons eu une discussion fatigante.
   Pourquoi : Correct : adjectif verbal accordé avec « discussion ».

11. Les chiffres [équivalant → équivalents] sont présentés en annexe.
   Pourquoi : Qualité (des chiffres équivalents) : adjectif « équivalents », avec e.

12. Il a reçu une somme [équivalent → équivalant] à trois mois de salaire.
   Pourquoi : Action avec complément (équivaloir à trois mois) : participe présent « équivalant ».

13. Ce sont les membres les plus [influants → influents] du parti.
   Pourquoi : Qualité (très influents) : adjectif « influent », avec e.

14. Le trajet me [fatigant → fatiguant] trop, j'ai décidé de ne pas venir.
   Pourquoi : Action (le trajet me fatigue) : participe présent « fatiguant ».
   Source : LanguageTool (CONVAINCANT_CONVAINQUANT[1]#0)

15. C'est en [fabricant → fabriquant] que l'on devient fabricant.
   Pourquoi : Action (en fabriquant) : participe présent avec « qu ». « Fabricant » est le nom.
   Source : LanguageTool (FABRICANT_FABRIQUANT[4]#0)

16. Cela fait trois mois que son poste est [vaquant → vacant].
   Pourquoi : L'adjectif s'écrit « vacant » (un poste vacant).
   Source : LanguageTool (CONVAINCANT_CONVAINQUANT[2]#1)
