# Les lettres muettes en fin de mot

Identifiant : lettres-muettes
Niveau : collège
Résumé : Le lait (laitier), le galop (galoper), le banc (banquette) : un mot de la famille révèle la lettre muette.

## Analyse

Décision demandée : écrire la consonne muette à la fin d'un mot, ou le e muet d'un nom en -ment.
Cas de base
  1. La lettre finale muette s'entend dans un mot de la même famille ou au féminin :
     lait → laitier, galop → galoper, banc → banquette, grand → grande, bavard → bavarder.
  2. Les noms en -ment formés sur un verbe en -ier, -ouer, -uer, -yer gardent le e muet :
     remercier → remerciement, se dévouer → dévouement, aboyer → aboiement.
Cas particuliers et pièges
  3. Familles trompeuses (abri / abriter, tabac / tabatière) : non exercées.
  4. Rectifications de 1990 (gaiment, paiment…) : non exercées.
Niveau : collège.

## En bref

Pour trouver la **lettre muette** à la fin d'un mot, pensez à un **mot de la même famille** ou au **féminin** :
- le lai**t** → lai**t**ier ; le galo**p** → galo**p**er ; le ban**c** → ban**qu**ette ;
- gran**d** → gran**d**e ; bavar**d** → bavar**d**er.

## Fiche

Beaucoup de mots se terminent par une **lettre qui ne s'entend pas**. Pour la trouver :
- cherchez un **mot de la même famille** : le lai**t** (lai**t**ier), le galo**p** (galo**p**er), le déb**ut** (déb**ut**er), le tapi**s** (tapi**ss**er), le do**s** (do**ss**ier), le ban**c** (ban**qu**ette) ;
- ou mettez au **féminin** : gran**d** (gran**d**e), peti**t** (peti**t**e), bavar**d** (bavar**d**e).

**Les noms en -ment** formés sur un verbe en **-ier, -ouer, -uer, -yer** gardent le **e** du verbe, qui ne s'entend pas :
> remercier → remerci**e**ment ; se dévouer → dévou**e**ment ; aboyer → aboi**e**ment.

**Le test** : « Comment dit-on quand on fait l'action ? » ou « au féminin ? ».

## Pour aller plus loin

- Quelques mots n'ont pas de famille qui aide : il faut les retenir (le sirop, le respect).
- Le **p** de plom**b** s'entend dans plom**b**ier ; le **t** de sau**t** dans sau**t**er.

## Exercices essentiels

1. J'ai bu un verre de [lai → lait].
   Pourquoi : « Laitier » fait entendre le t : « lait ».

2. Le cheval part au [galo → galop].
   Pourquoi : « Galoper » fait entendre le p : « galop ».

3. Il est assis sur le [ban → banc].
   Pourquoi : « Banquette » fait entendre le son du c : « banc ».

4. Mon frère est très [bavar → bavard].
   Pourquoi : « Bavarder » fait entendre le d : « bavard ».

5. Ce n'est que le [débu → début].
   Pourquoi : « Débuter » fait entendre le t : « début ».

6. Il a mal au [do → dos].
   Pourquoi : « Dossier » fait entendre le s : « dos ».

7. Le [tapi → tapis] du salon est neuf.
   Pourquoi : « Tapisser » fait entendre le s : « tapis ».

8. Je vous adresse mes [remerciments → remerciements].
   Pourquoi : Formé sur « remercier » : le e muet reste, « remerciement ».

9. Le marchand range le lait et le chocolat dans un grand placard.
   Pourquoi : Correct : lait (laitier), chocolat (chocolaté), grand (grande), placard (placarder).

10. Le ___ de cette maison est très haut.
    Choix : **toit** / toi / toie
    Pourquoi : « Toiture » fait entendre le t : « toit ».

11. Tri : t ou d à la fin ?
    Colonnes : t | d
    - un cha… (chaton) → t
    - gran… (grande) → d
    - bavar… (bavarder) → d
    - le lai… (laitier) → t
    - chau… (chaude) → d
    - peti… (petite) → t
    Pourquoi : Le mot de la famille ou le féminin fait entendre la lettre muette.

## Exercices avancés

12. Il a montré un grand [dévoument → dévouement].
    Pourquoi : Formé sur « se dévouer » : le e reste, « dévouement ».

13. Un morceau de [plon → plomb] est tombé.
    Pourquoi : « Plombier » fait entendre le b : « plomb ».

14. L'[aboiment → aboiement] du chien m'a réveillé.
    Pourquoi : Formé sur « aboyer » : le e reste, « aboiement ».

15. Il a fait un [saud → saut] de deux mètres.
    Pourquoi : « Sauter » fait entendre le t : « saut ».

16. Le respect est le début de l'amitié.
    Pourquoi : Correct : « respect » (respecter), « début » (débuter).

17. Il y a un ___ de sable dans la cour.
    Choix : **tas** / ta / tat
    Pourquoi : « Tasser » fait entendre le s : « tas ».
