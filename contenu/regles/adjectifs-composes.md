# Les adjectifs composés : nouveau-nés, grandes ouvertes, haut placés

Identifiant : adjectifs-composes
Niveau : supérieur
Résumé : Deux adjectifs s'accordent tous les deux ; un mot employé comme adverbe reste invariable.

## Analyse

Décision demandée : accorder les éléments d'un adjectif composé.
Cas de base
  1. Deux adjectifs qui qualifient tous deux le nom : les deux s'accordent
     (des personnes sourdes-muettes, des sauces aigres-douces, ivres morts).
  2. Un élément employé comme adverbe (il modifie l'autre) : invariable
     (des enfants nouveau-nés = nouvellement nés ; des personnes haut placées ;
     des jeunes filles court vêtues ; des enfants mort-nés).
  3. Usage consacré : grand ouvert s'accorde (des fenêtres grandes ouvertes),
     comme premier-né et dernier-né (les derniers-nés).
Cas particuliers et pièges
  4. nouveau suivi d'un participe pris comme nom s'accorde dans « les nouveaux venus » ;
     non exercé.
Niveau : supérieur.

## En bref

- **Deux adjectifs** : les deux s'accordent → des sauces **aigres-douces**, des voyageurs **ivres morts**.
- Un mot qui joue le rôle d'un **adverbe** reste **invariable** → des enfants **nouveau**-nés (= nouvellement nés), des personnes **haut** placées.
- Par l'usage : des fenêtres **grandes** ouvertes, les **derniers**-nés.

## Fiche

**Deux adjectifs** qui qualifient chacun le nom : **tous les deux s'accordent**.
> des personnes sourd**es**-muet**tes**, des sauces aigre**s**-douce**s**, des voyageurs ivre**s** mort**s**

**Un élément employé comme adverbe** (il modifie l'autre adjectif ou le participe) : il reste **invariable**.
> des enfants **nouveau**-nés (= nouvellement nés), des enfants **mort**-nés, des personnes **haut** placées, des jeunes filles **court** vêtues

**L'usage** fait varier quelques mots : des fenêtres **grandes** ouvertes, les **derniers**-nés, les **premiers**-nés.

**Le test** : peut-on remplacer le premier mot par un adverbe en -ment (nouvellement, hautement) ? → invariable.

## Pour aller plus loin

- **nouveau** s'accorde quand le participe est employé comme nom : les **nouveaux** venus, les **nouveaux** mariés.
- **frais** s'accorde par l'usage devant un participe : des fleurs **fraîches** cueillies.

## Exercices essentiels

1. Les enfants [nouveaux-nés → nouveau-nés] dorment beaucoup.
   Pourquoi : « Nouveau » = nouvellement : adverbe, invariable.

2. Ils ont servi des sauces [aigre-douces → aigres-douces].
   Pourquoi : Deux adjectifs : les deux s'accordent.

3. Les fenêtres étaient [grand ouvertes → grandes ouvertes].
   Pourquoi : Par l'usage, « grand ouvert » s'accorde : « grandes ouvertes ».

4. Ce sont des personnes [hautes placées → haut placées].
   Pourquoi : « Haut » modifie « placées » (= hautement) : invariable.

5. On a retrouvé deux voyageurs [ivre morts → ivres morts].
   Pourquoi : Deux adjectifs : les deux s'accordent.

6. Les jeunes filles étaient [courtes vêtues → court vêtues].
   Pourquoi : « Court » modifie « vêtues » : invariable.

7. Cette école accueille des enfants [sourd-muets → sourds-muets].
   Pourquoi : Deux adjectifs : les deux s'accordent.

8. Voici les [dernier-nés → derniers-nés] de la portée.
   Pourquoi : Par l'usage, « dernier-né » s'accorde : « derniers-nés ».

9. Les portes grandes ouvertes laissaient entrer des invités haut placés.
   Pourquoi : Correct : « grandes ouvertes » (usage), « haut placés » (adverbe invariable).

10. La maternité compte dix bébés ___.
    Choix : **nouveau-nés** / nouveaux-nés
    Pourquoi : « Nouveau » = nouvellement : invariable.

11. Tri : premier élément accordé ou invariable ?
    Colonnes : accordé | invariable
    - des sauces (aigre)-douces → accordé
    - des enfants (nouveau)-nés → invariable
    - des fenêtres (grand) ouvertes → accordé
    - des personnes (haut) placées → invariable
    - des voyageurs (ivre) morts → accordé
    - des filles (court) vêtues → invariable
    Pourquoi : Un adjectif qui qualifie le nom s'accorde ; un mot qui joue le rôle d'un adverbe reste invariable.

## Exercices avancés

12. Les agneaux [morts-nés → mort-nés] ont été emportés.
    Pourquoi : « Mort » modifie « nés » : invariable.

13. Ses filles sont ses [première-nées → premières-nées].
    Pourquoi : Par l'usage, « premier-né » s'accorde : « premières-nées ».

14. Elle aime les pommes [aigre-douces → aigres-douces].
    Pourquoi : Deux adjectifs : les deux s'accordent.

15. Les bébés nouveau-nés sont pesés chaque jour.
    Pourquoi : Correct : « nouveau » reste invariable.

16. Ces fonctionnaires sont ___ placés.
    Choix : **haut** / hauts
    Pourquoi : « Haut » modifie « placés » : invariable.

17. Les volets étaient [grand ouverts → grands ouverts].
    Pourquoi : Par l'usage, « grand ouvert » s'accorde.
