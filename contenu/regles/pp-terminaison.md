# Participe passé : pris, fini, dit, mis

Identifiant : pp-terminaison
Niveau : collège
Résumé : J'ai pris (et non prit) : le test du féminin donne la lettre finale.

## Analyse

Décision demandée : écrire la terminaison du participe passé (-é, -i, -is, -it, -u…).
Cas de base
  1. Test : mettre le participe au féminin pour entendre la consonne finale :
     prise → pris, mise → mis, dite → dit, écrite → écrit, finie → fini (rien à entendre).
  2. Le participe passé n'est pas la forme conjuguée : j'ai fini (participe) / il finit (présent),
     j'ai pris / il prit (passé simple), j'ai dit / tu dis (présent).
Cas particuliers et pièges
  3. Verbes en -ir du 2e groupe : participe en -i, sans consonne (fini, choisi, réussi).
  4. Participes en -u : vu, cru, su, lu (féminin vue, crue, sue, lue).
  5. Après « avoir », c'est toujours le participe, jamais une forme conjuguée.
Hors sujet : l'accord du participe (règles du thème Accords) ; -é / -er (règle infinitif-participe).
Niveau : collège.

## En bref

Pour trouver la dernière lettre du participe passé, **mettez-le au féminin** :
> une chose **prise** → j'ai **pris** ; une lettre **écrite** → j'ai **écrit** ; une tâche **finie** → j'ai **fini**.

Après **avoir**, c'est toujours le participe : j'ai **pris** (et non « prit »), j'ai **fini** (et non « finit »).

## Fiche

Le participe passé se termine souvent par une **lettre muette** : pris, mis, dit, écrit… Pour la trouver, **mettez le participe au féminin** :
> une chose **prise** → **pris** ; une chose **mise** → **mis** ; une chose **dite** → **dit** ; une lettre **écrite** → **écrit** ; une chose **permise** → **permis**
> une tâche **finie** → **fini** ; une chose **choisie** → **choisi** (aucune consonne)

**Les pièges** :
- Après **avoir**, c'est toujours le **participe** : j'ai **pris**, il a **fini**, vous avez **dit**.
- Ne confondez pas avec les formes conjuguées : il **prit** (passé simple), il **finit** (présent), tu **dis** (présent).

## Pour aller plus loin

- Les participes en **-u** : vu, cru, su, lu, bu (féminin : vue, crue, sue, lue, bue).
- Les verbes en **-ir** du 2e groupe ont un participe en **-i** : fini, choisi, réussi, grandi.
- Quelques participes courants : **conduit** (conduite), **inclus** (incluse), **conclu** (conclue), **acquis** (acquise).

## Exercices essentiels

1. Il a [prit → pris] le dernier bus.
   Pourquoi : Une chose « prise » : le participe s'écrit « pris ».

2. J'ai [finit → fini] mon puzzle.
   Pourquoi : Une tâche « finie » : pas de consonne, « fini ».

3. Tu as [dis → dit] la vérité.
   Pourquoi : Une chose « dite » : « dit ».

4. Elle a [mit → mis] son manteau rouge.
   Pourquoi : Une chose « mise » : « mis ».

5. Ils ont [écris → écrit] une chanson.
   Pourquoi : Une chanson « écrite » : « écrit ».

6. Nous avons [finit → fini] de ranger le garage.
   Pourquoi : Une tâche « finie » : « fini ».

7. J'ai enfin [comprit → compris] l'exercice.
   Pourquoi : Une chose « comprise » : « compris ».

8. C'est le gâteau que nous avons [choisit → choisi].
   Pourquoi : Une chose « choisie » : « choisi ».

9. Il a pris son manteau, a dit au revoir et est parti.
   Pourquoi : Correct : « pris » (prise), « dit » (dite), « parti » (partie).

10. Les progrès de la médecine ont ___ d'augmenter l'espérance de vie.
    Choix : **permis** / permit / permi
    Pourquoi : Une chose « permise » : « permis ».

11. Tri : quelle est la dernière lettre du participe ? Pensez au féminin.
    Colonnes : -s ou -t (on l'entend au féminin) | aucune consonne
    - j'ai (prendre) → -s ou -t (on l'entend au féminin)
    - j'ai (finir) → aucune consonne
    - j'ai (dire) → -s ou -t (on l'entend au féminin)
    - j'ai (choisir) → aucune consonne
    - j'ai (mettre) → -s ou -t (on l'entend au féminin)
    - j'ai (réussir) → aucune consonne
    Pourquoi : Prise, dite, mise : on entend la consonne (pris, dit, mis). Finie, choisie, réussie : aucune consonne (fini, choisi, réussi).

## Exercices avancés

12. Le trajet n'a [prit → pris] qu'un quart d'heure.
    Pourquoi : Après « avoir », le participe : « pris ».

13. J'ai [réussit → réussi] mon permis de conduire.
    Pourquoi : Une chose « réussie » : « réussi ».

14. Tu as [conduis → conduit] toute la nuit.
    Pourquoi : Une voiture « conduite » : « conduit ».

15. Ses parents lui ont [permit → permis] de sortir.
    Pourquoi : Une chose « permise » : « permis ».

16. Le service est [inclu → inclus] dans le prix.
    Pourquoi : Une boisson « incluse » : « inclus ».

17. Le contrat a été [conclut → conclu] hier.
    Pourquoi : Une affaire « conclue » : on n'entend pas de consonne, « conclu ».

18. Je l'ai ___ dans le journal.
    Choix : **lu** / lut / lus
    Pourquoi : Une chose « lue » : « lu ».

19. Où as-tu [mit → mis] mes lunettes ?
    Pourquoi : Une chose « mise » : « mis ».
