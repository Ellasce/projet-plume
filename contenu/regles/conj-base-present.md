# Le présent des trois groupes

Identifiant : conj-base-present
Niveau : collège
Résumé : Je chante, je finis, je prends : les terminaisons du présent.

## Fiche

**1er groupe** : **-e, -es, -e, -ons, -ez, -ent**.
> je chante, tu chantes, il chante, nous chantons, vous chantez, ils chantent
Attention : manger → nous mang**e**ons ; commencer → nous commen**ç**ons (pour garder le son).

**2e groupe** : **-is, -is, -it, -issons, -issez, -issent**.
> je finis, tu finis, il finit, nous finissons, vous finissez, ils finissent

**3e groupe** : le plus souvent **-s, -s, -t** (ou **-d** pour les verbes en -dre), puis **-ons, -ez, -ent**. Le radical change souvent.
> je pars, il part — je prends, il prend — ils viennent, ils vont

**À retenir** : vous **faites**, vous **dites** (et non « faisez », « disez ») ; je **peux**, je **veux** (avec un x).
