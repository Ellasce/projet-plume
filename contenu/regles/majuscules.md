# Les majuscules

Identifiant : majuscules
Niveau : lycée
Résumé : Les Français parlent français : majuscule au peuple, minuscule à la langue.

## Analyse

Décision demandée : mettre ou non une majuscule.
Cas de base
  1. Début de phrase et noms propres (personnes, villes, pays) : majuscule.
  2. Habitants et peuples : majuscule (les Français, une Parisienne).
  3. Langues et adjectifs de nationalité : minuscule (le français, un vin français).
  4. Jours, mois, saisons : minuscule (lundi, janvier, l'été).
Cas particuliers et pièges
  5. Points cardinaux : minuscule pour une direction (au nord de Paris), majuscule pour une
     région (le Nord, l'Amérique du Sud).
  6. Les accents se gardent sur les majuscules (À, É).
  7. Titres et institutions : l'État, la Révolution française, le Moyen Âge.
Niveau : lycée.

## En bref

- **Majuscule** : début de phrase, noms de personnes, de villes, de pays, et **habitants** : les **F**rançais, une **P**arisienne.
- **Minuscule** : **langues** et **adjectifs** (le **f**rançais, un vin **f**rançais), **jours** et **mois** (**l**undi, **j**anvier).

**Le test** : s'il s'agit de **personnes**, majuscule ; d'une **langue** ou d'un **adjectif**, minuscule.

## Fiche

**Majuscule** :
- au début d'une phrase ;
- aux noms propres : personnes, villes, pays, fleuves (Paris, la France, la Loire) ;
- aux noms d'**habitants** et de **peuples** : les **F**rançais, une **P**arisienne, les **E**spagnols.

**Minuscule** :
- aux **langues** : il parle **f**rançais, apprendre l'**a**nglais ;
- aux **adjectifs** de nationalité : un vin **f**rançais, la cuisine **i**talienne ;
- aux **jours**, **mois** et **saisons** : **l**undi, **j**anvier, l'**é**té.

**Le test** : s'il s'agit de **personnes** (les Français = des gens), majuscule ; d'une **langue** ou d'un **adjectif**, minuscule.

**L'accent se garde** sur une majuscule : **À** demain, **É**tienne.

## Pour aller plus loin

- **Points cardinaux** : minuscule pour une direction (au **n**ord de Lyon), majuscule pour une région (le **N**ord, l'Amérique du **S**ud).
- **Institutions et périodes historiques** : l'**É**tat, la **R**évolution française, le **M**oyen **Â**ge.

## Exercices essentiels

1. Les [français → Français] sont souvent fiers de leur cuisine.
   Pourquoi : Il s'agit de personnes (les habitants) : majuscule, « Français ».

2. Le [Français → français] est-il difficile à apprendre ?
   Pourquoi : Il s'agit de la langue : minuscule.

3. Ton [Français → français] a fait des progrès.
   Pourquoi : La langue : minuscule.

4. Il parle [Espagnol → espagnol] et portugais.
   Pourquoi : Une langue : minuscule.

5. Les soldes commencent en [Janvier → janvier].
   Pourquoi : Les mois prennent une minuscule.

6. Je te rappelle [Mardi → mardi] soir.
   Pourquoi : Les jours prennent une minuscule.

7. Nous avons dîné dans un restaurant [Italien → italien].
   Pourquoi : Adjectif de nationalité : minuscule.

8. Les [italiens → Italiens] et les Français sont Européens.
   Pourquoi : Des personnes (les habitants de l'Italie) : majuscule.

9. Les Espagnols parlent espagnol et adorent l'été.
   Pourquoi : Correct : « Espagnols » (des personnes) avec majuscule ; la langue et la saison avec minuscule.

10. Mon voisin est un ___ très sympathique.
    Choix : **Allemand** / allemand
    Pourquoi : Un nom désignant une personne : majuscule.

11. Tri : majuscule ou minuscule ?
    Colonnes : majuscule | minuscule
    - les (habitants de la France) → majuscule
    - parler (la langue de l'Espagne) → minuscule
    - (mois) mars → minuscule
    - une (habitante de Lyon) → majuscule
    - un fromage (de France) → minuscule
    - la ville de (Marseille) → majuscule
    Pourquoi : Les Français, une Lyonnaise, Marseille → majuscule. L'espagnol (langue), mars (mois), un fromage français (adjectif) → minuscule.

## Exercices avancés

12. Nous habitons au [Nord → nord] de Lyon.
    Pourquoi : Une direction : minuscule. (Majuscule seulement pour la région : le Nord.)

13. Il a voyagé en Amérique du [sud → Sud].
    Pourquoi : « L'Amérique du Sud » est un nom de région : majuscule.

14. Le [moyen âge → Moyen Âge] a duré environ mille ans.
    Pourquoi : Nom de période historique : majuscules (avec l'accent sur le Â).

15. [A → À] quelle heure arrive le train ?
    Pourquoi : L'accent se garde sur la majuscule : « À ».

16. Les Parisiens adorent les terrasses au printemps.
    Pourquoi : Correct : « Parisiens » (des personnes) avec majuscule ; « printemps » (saison) avec minuscule.

17. Il a écrit un livre sur la Révolution ___.
    Choix : **française** / Française
    Pourquoi : « Française » est ici un adjectif : minuscule. Seul « Révolution » prend la majuscule.

18. Elle apprend le [Chinois → chinois] depuis deux ans.
    Pourquoi : Une langue : minuscule.

19. Les [canadiens → Canadiens] parlent anglais ou français.
    Pourquoi : Des personnes : majuscule.
