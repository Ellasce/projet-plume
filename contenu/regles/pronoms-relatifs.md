# Les pronoms relatifs : qui, que, où, lequel

Identifiant : pronoms-relatifs
Niveau : lycée
Résumé : La fille avec qui je travaille, la raison pour laquelle je suis venu, le jour où…

## Analyse

Décision demandée : choisir le pronom relatif (qui, que, dont, où, lequel et ses formes).
Cas de base
  1. qui = sujet du verbe qui suit (l'homme qui parle).
  2. que = complément direct (l'homme que je vois).
  3. où = lieu ou temps (la ville où je vis, le jour où il est parti).
  4. Après une préposition : à qui / avec qui (personnes), lequel, laquelle, lesquels, lesquelles
     (choses et personnes) ; à + lequel = auquel, de + lequel = duquel.
Cas particuliers et pièges
  5. Fautes fréquentes : « la fille que je sors avec » → avec qui ; « la raison que » → pour laquelle ;
     « l'endroit que je vais » → où ; « le jour que » → où.
  6. Accord de lequel : les questions auxquelles, le projet auquel.
  7. dont : règle dont-que.
Niveau : lycée.

## En bref

- **qui** : sujet du verbe qui suit → l'homme **qui** parle.
- **que** : complément direct → l'homme **que** je vois.
- **où** : un lieu ou un moment → la ville **où** je vis, le jour **où** il est parti.
- Après une **préposition** : **avec qui**, **pour laquelle**, **auquel** → la raison **pour laquelle** je viens.

## Fiche

- **qui** est **sujet** du verbe qui suit : l'homme **qui** parle (c'est l'homme qui parle).
- **que** est **complément direct** : l'homme **que** je vois (je vois l'homme).
- **où** indique un **lieu** ou un **moment** : la ville **où** je vis, le jour **où** il est parti.
- Après une **préposition** (avec, pour, à, sur, dans…), on emploie :
  - **qui** pour une personne : la collègue **avec qui** je travaille ;
  - **lequel, laquelle, lesquels, lesquelles** : la raison **pour laquelle** je viens, le stylo **avec lequel** j'écris.

**Le test** : refaites la phrase simple. Je travaille **avec** cette collègue → la collègue **avec qui** je travaille.

**Les pièges** :
- « la fille **que** je sors avec » ✘ → la fille **avec qui** je sors ;
- « la raison **que** je suis venu » ✘ → la raison **pour laquelle** je suis venu ;
- « l'endroit **que** je vais » ✘ → l'endroit **où** je vais.

## Pour aller plus loin

- **à + lequel** devient **auquel** (auxquels, auxquelles) ; **de + lequel** devient **duquel** : le projet **auquel** je pense, les questions **auxquelles** il a répondu.
- **lequel** s'accorde avec le nom qu'il remplace : les amies **avec lesquelles** je pars.

## Exercices essentiels

1. C'est la ville [que → où] je suis né.
   Pourquoi : Un lieu : « où ».

2. Voici la collègue [que → avec qui] je travaille.
   Pourquoi : On travaille AVEC quelqu'un : « avec qui ».

3. Je ne comprends pas la raison [que → pour laquelle] il est parti.
   Pourquoi : Il est parti POUR une raison : « pour laquelle ».

4. Le livre [qui → que] je lis est passionnant.
   Pourquoi : Je lis le livre (complément direct) : « que ».

5. L'homme [que → qui] parle est mon oncle.
   Pourquoi : C'est l'homme qui parle (sujet) : « qui ».

6. Je me souviens du jour [que → où] nous nous sommes rencontrés.
   Pourquoi : Un moment : « le jour où ».

7. C'est l'ami [que → à qui] j'ai prêté ma voiture.
   Pourquoi : On prête quelque chose À quelqu'un : « à qui ».

8. Voici le stylo [que → avec lequel] j'ai signé le contrat.
   Pourquoi : On signe AVEC un stylo : « avec lequel ».

9. La maison où j'ai grandi et que mes parents ont vendue me manque.
   Pourquoi : Correct : « où » (lieu), puis « que » (ils ont vendu la maison).

10. C'est l'entreprise ___ elle travaille depuis dix ans.
    Choix : que / **où** / qui
    Pourquoi : Un lieu : « où » (ou « dans laquelle »).

11. Tri : quel pronom ? Refaites la phrase simple.
    Colonnes : qui ou que | où ou préposition + lequel / qui
    - le chat … dort → qui ou que
    - la ville … j'habite → où ou préposition + lequel / qui
    - le film … j'ai vu → qui ou que
    - l'ami … je pense (penser à) → où ou préposition + lequel / qui
    - le jour … il est arrivé → où ou préposition + lequel / qui
    - la chanson … tu chantes → qui ou que
    Pourquoi : Le chat qui dort, le film que j'ai vu, la chanson que tu chantes. La ville où j'habite, l'ami à qui je pense, le jour où il est arrivé.

## Exercices avancés

12. Les questions [que → auxquelles] il a répondu étaient difficiles.
    Pourquoi : On répond À des questions : à + lesquelles = « auxquelles ».

13. C'est un projet [que → auquel] je tiens beaucoup.
    Pourquoi : On tient À un projet : à + lequel = « auquel ».

14. Les amies [avec lesquels → avec lesquelles] je pars sont sympathiques.
    Pourquoi : « Lequel » s'accorde avec « amies » (féminin pluriel) : « lesquelles ».

15. C'est la fille [que je sors avec → avec qui je sors].
    Pourquoi : La préposition se place devant le pronom : « avec qui je sors ».

16. Le parc près [de qui → duquel] nous habitons est magnifique.
    Pourquoi : Pour une chose, après « près de » : de + lequel = « duquel ».

17. C'est le sujet ___ nous avons longuement discuté.
    Choix : que / **sur lequel** / où
    Pourquoi : On discute SUR un sujet : « sur lequel ».

18. La personne à qui j'ai écrit m'a répondu le jour même.
    Pourquoi : Correct : on écrit À quelqu'un : « à qui ».

19. L'époque [que → où] nous vivons est passionnante.
    Pourquoi : Un moment (une époque) : « où ».
