# Futur ou conditionnel : -rai ou -rais

Identifiant : futur-conditionnel
Niveau : lycée
Résumé : Je viendrai ou je viendrais ? Passez à « nous ».

## Fiche

À la 1re personne du singulier, on confond souvent :
- le **futur** : je **-rai** (un fait à venir, considéré comme sûr) ;
- le **conditionnel** : je **-rais** (une hypothèse, un souhait, une demande polie).

**L'astuce** : conjuguez avec **nous**.
- nous viend**rons** → futur → je viend**rai**
- nous viend**rions** → conditionnel → je viend**rais**

> Demain, je serai au bureau. (nous serons)
> Si j'avais le temps, je viendrais. (nous viendrions)
> Je voudrais un café. (politesse)

**Repère** : après « si » + imparfait, on emploie le conditionnel.

## Pour aller plus loin

- **Futur dans le passé** : il m'a promis qu'il **viendrait**.
- Si + plus-que-parfait → conditionnel passé : si j'avais su, je **serais** venu.

## Exercices essentiels

1. Si j'avais le temps, je [viendrai → viendrais] avec plaisir.
   Pourquoi : « Si nous avions le temps, nous viendrions » : conditionnel.

2. Demain, je [serais → serai] au bureau dès 8 heures.
   Pourquoi : « Demain, nous serons » : futur, « je serai ».

3. Quand j'aurai fini, je t'[appellerais → appellerai].
   Pourquoi : « Quand nous aurons fini, nous t'appellerons » : futur.

4. Si vous me le demandiez, je [pourrai → pourrais] vous aider.
   Pourquoi : Si + imparfait → conditionnel : « nous pourrions ».

5. J'___ volontiers un verre d'eau.
   Choix : aimerai / **aimerais**
   Pourquoi : Souhait poli : conditionnel (nous aimerions).

6. Je te ___ la réponse dès que je la connaîtrai.
   Choix : **donnerai** / donnerais
   Pourquoi : Fait à venir : futur (nous donnerons).

7. Tri : Futur ou conditionnel ? Passez à « nous » pour vérifier.
   Colonnes : Futur | Conditionnel
   - Demain, je serai en retard. → Futur
   - Je voudrais un renseignement. → Conditionnel
   - Si je pouvais, je partirais. → Conditionnel
   - Je t'écrirai dès mon arrivée. → Futur
   - J'aimerais vous rencontrer. → Conditionnel
   - Quand j'aurai fini, je sortirai. → Futur
   Pourquoi : Nous serons, nous écrirons, nous sortirons → futur. Nous voudrions, nous partirions, nous aimerions → conditionnel.

8. Quand je [serais → serai] grand, je deviendrai président !
   Pourquoi : « Quand nous serons grands » : futur, « serai ».

9. Je [mangerai → mangerais] du chocolat si j'aimais ça.
   Pourquoi : Si + imparfait (si j'aimais) → conditionnel : « nous mangerions ».
   Source : LanguageTool (CONFUSION_FUTUR_CON[10]#0)

10. Ne m'attendez pas, j'[aurais → aurai] du retard.
   Pourquoi : Fait à venir, certain : futur, « nous aurons » → « j'aurai ».
   Source : LanguageTool (COND_VS_FUTUR[4]#2)

## Exercices avancés

11. Je voudrais un café, s'il vous plaît.
   Pourquoi : Correct : conditionnel de politesse (nous voudrions).

12. Je vous serais reconnaissant de bien vouloir me répondre.
   Pourquoi : Correct : formule polie au conditionnel (nous serions).

13. Il m'a promis qu'il [viendra → viendrait] dès que possible.
   Pourquoi : Dans un récit au passé, l'avenir s'exprime au conditionnel : « il m'a promis qu'il viendrait ».

14. Si j'avais su, je [serai → serais] venu plus tôt.
   Pourquoi : Si + plus-que-parfait → conditionnel passé : « nous serions venus » → « je serais venu ».

15. J'[irais → irai] vous voir quand vous serez installés.
   Pourquoi : « Quand vous serez installés » : fait à venir, futur (nous irons) → « j'irai ».

16. Manon pensait que je [viendrai → viendrais].
   Pourquoi : Dans un récit au passé, l'avenir s'exprime au conditionnel (« futur dans le passé ») : « elle pensait que nous viendrions ».
   Source : LanguageTool (CONFUSION_FUTUR_CON[16]#0)

17. Bonjour, j'[aurai → aurais] aimé savoir si la soupe était chaude.
   Pourquoi : Souhait poli : conditionnel passé, « nous aurions aimé » → « j'aurais aimé ».
