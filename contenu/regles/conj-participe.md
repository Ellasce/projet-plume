# Participe passé : conclu, inclus, dû

Identifiant : conj-participe
Niveau : supérieur
Résumé : Conclu sans s mais inclus avec s : la terminaison muette.

## Fiche

**L'astuce** : mettez le participe au **féminin**. La consonne finale s'entend alors.
> conclu → conclue (pas de s) ; exclu → exclue
> inclus → incluse (s) ; acquis → acquise ; clos → close ; absous → absoute

**Autres cas** :
- **dû** (de devoir) prend un accent circonflexe au masculin singulier seulement, pour le distinguer de « du » : dû, mais due, dus.
- **mû** (de mouvoir) peut s'écrire **mu** depuis les rectifications de 1990.
- **suffi**, **résolu**, **peint**, **né** : attention aux formes du présent (il suffit, il résout).
