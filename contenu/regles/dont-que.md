# dont ou que

Identifiant : dont-que
Niveau : lycée
Résumé : « Dont » remplace un complément introduit par « de ».

## Analyse

Décision demandée : choisir le pronom relatif « dont » ou « que ».
Cas de base
  1. dont remplace un complément introduit par « de » (avoir besoin de, parler de,
     se souvenir de, être fier de, avoir peur de). Test : refaire la phrase avec « de ».
  2. que remplace un COD (verbe sans préposition : aimer quelque chose, voir quelqu'un).
Cas particuliers et pièges
  3. « ce dont j'ai besoin » (et non « ce que j'ai besoin ») ; « ce que je veux ».
  4. « la manière dont », « la façon dont ».
  5. « dont » + complément du nom (un arbre dont les feuilles tombent = les feuilles de l'arbre).
  6. Double emploi : « c'est de cela dont » → « c'est de cela que » (règle Constructions fautives).
Hors sujet : qui, où, lequel (règle à venir sur les pronoms relatifs).
Niveau : lycée.

## En bref

- **dont** remplace un complément construit avec **de** : avoir besoin **de** → ce **dont** j'ai besoin.
- **que** remplace un complément **sans préposition** : vouloir quelque chose → ce **que** je veux.

**Le test** : refaites la phrase simple. J'ai besoin **de** ce livre → le livre **dont** j'ai besoin.

## Fiche

- **dont** remplace un complément construit avec **de**. On l'emploie avec : avoir besoin **de**, parler **de**, se souvenir **de**, être fier **de**, avoir peur **de**, rêver **de**…
> J'ai besoin **de** ce livre. → le livre **dont** j'ai besoin
- **que** remplace un complément **sans préposition** (un COD).
> Je lis ce livre. → le livre **que** je lis

**Le test** : refaites la phrase simple avec le verbe. S'il faut **de**, écrivez **dont** ; sinon, **que**.

**Les pièges** :
- On dit **ce dont** j'ai besoin, **ce dont** on parle, mais **ce que** je veux.
- **la manière dont**, **la façon dont** : « il parle d'une manière » → la manière **dont** il parle.

## Pour aller plus loin

- **dont** peut aussi remplacer un complément du nom : un arbre **dont** les feuilles tombent (les feuilles **de** l'arbre).
- Ne mettez pas « de » deux fois : c'est **de** cela **qu'**il s'agit (et non « de cela dont »).

## Exercices essentiels

1. Tu as tout ce [que → dont] tu as besoin ?
   Pourquoi : On a besoin DE quelque chose : « ce dont tu as besoin ».

2. Voici exactement ce [que → dont] j'ai besoin.
   Pourquoi : Avoir besoin DE : « dont ».

3. C'est le film [que → dont] tout le monde parle.
   Pourquoi : On parle DE ce film : « dont ».

4. Prends les outils [que → dont] tu as besoin.
   Pourquoi : Avoir besoin DES outils : « dont ».

5. Le film [dont → que] j'ai vu hier était excellent.
   Pourquoi : On voit quelque chose (sans « de ») : « que ».

6. Voici la maison [que → dont] je rêve depuis toujours.
   Pourquoi : On rêve DE quelque chose : « dont ».

7. C'est un voyage [que → dont] je me souviendrai longtemps.
   Pourquoi : On se souvient DE quelque chose : « dont ».

8. Le gâteau [dont → que] tu as préparé est délicieux.
   Pourquoi : On prépare quelque chose (sans « de ») : « que ».

9. Voici le livre dont je t'ai parlé et que je te prête.
   Pourquoi : Correct : parler DE ce livre → « dont » ; prêter ce livre (sans « de ») → « que ».

10. C'est le projet ___ elle est la plus fière.
    Choix : que / **dont**
    Pourquoi : On est fier DE quelque chose : « dont ».

11. Tri : « dont » ou « que » ? Refaites la phrase avec le verbe.
    Colonnes : dont (verbe + de) | que (sans préposition)
    - le livre … j'ai besoin → dont (verbe + de)
    - le livre … je lis → que (sans préposition)
    - l'ami … je parle → dont (verbe + de)
    - l'ami … je vois → que (sans préposition)
    - le chien … j'ai peur → dont (verbe + de)
    - la chanson … j'aime → que (sans préposition)
    Pourquoi : Avoir besoin de, parler de, avoir peur de → « dont ». Lire, voir, aimer quelque chose → « que ».

## Exercices avancés

12. J'aime la façon [que → dont] elle chante.
    Pourquoi : « Elle chante d'une façon » : « la façon dont ».

13. Ce [que → dont] j'ai envie, c'est d'un bon bain.
    Pourquoi : Avoir envie DE : « ce dont ».

14. C'est un arbre [que → dont] les feuilles tombent tôt.
    Pourquoi : Les feuilles DE l'arbre : « dont ».

15. C'est de ce sujet [dont il → qu'il] faut parler.
    Pourquoi : « De » est déjà exprimé (de ce sujet) : « c'est de ce sujet qu'il faut parler ».

16. Voici l'élève [que → dont] les parents sont venus.
    Pourquoi : Les parents DE l'élève : « dont ».

17. Dis-moi ce ___ tu as envie.
    Choix : que / **dont**
    Pourquoi : On a envie DE quelque chose : « ce dont ».

18. Le métier dont il rêvait est celui qu'il exerce aujourd'hui.
    Pourquoi : Correct : rêver DE ce métier → « dont » ; exercer ce métier → « que ».

19. Ce [que → dont] j'ai peur, c'est de l'oublier.
    Pourquoi : Avoir peur DE quelque chose : « ce dont ».
