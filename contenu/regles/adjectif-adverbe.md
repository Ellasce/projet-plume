# Adjectif ou adverbe : sentir bon, parler fort

Identifiant : adjectif-adverbe
Niveau : lycée
Résumé : Ces fleurs sentent bon, ils parlent fort : employés après un verbe, ces adjectifs ne s'accordent pas.

## Analyse

Décision demandée : accorder ou non un adjectif selon qu'il qualifie un nom ou modifie un verbe.
Cas de base
  1. Adjectif employé comme adverbe, après un verbe : invariable (sentir bon, parler fort,
     coûter cher, voir clair, chanter faux, travailler dur, peser lourd, s'arrêter net, tenir bon).
  2. Adjectif qui qualifie un nom (épithète ou attribut) : accord (des voix fortes ;
     ces pommes sont chères).
  Test : peut-on le remplacer par un adverbe en -ment (fortement) ? → adverbe, invariable.
Cas particuliers et pièges
  3. Coupé court, haut placé : l'adjectif modifie le participe, invariable (des cheveux coupés court).
  4. Cas d'accord par l'usage (des fleurs fraîches cueillies, une fenêtre grande ouverte) :
     non exercés.
Niveau : lycée.

## En bref

- Après un **verbe**, ces adjectifs jouent le rôle d'un **adverbe** : **invariables** → ces fleurs sentent **bon**, ils parlent **fort**, ces bijoux coûtent **cher**.
- Avec un **nom**, ils **s'accordent** → des voix **fortes**, des bijoux **chers**.

## Fiche

Certains adjectifs s'emploient **après un verbe**, pour dire **comment** se fait l'action. Ils jouent alors le rôle d'un **adverbe** et restent **invariables** :
> sentir **bon**, parler **fort**, coûter **cher**, voir **clair**, chanter **faux**, travailler **dur**, peser **lourd**, s'arrêter **net**, tenir **bon**, viser **haut**.

Quand ils décrivent un **nom**, ce sont de vrais adjectifs : ils **s'accordent**.
> Des voix **fortes**. Ces pommes sont **chères**. Ces cartons sont **lourds**.

**Le test** : posez la question « comment ? » après le verbe. Elles parlent comment ? fort → adverbe, invariable.

**Le piège** : comparez « ces bijoux coûtent **cher** » (verbe coûter, invariable) et « ces bijoux sont **chers** » (attribut de « bijoux », accord).

## Pour aller plus loin

- Avec un participe : des cheveux coupés **court** (invariable).
- L'usage accorde dans quelques expressions figées (des fleurs fraîches cueillies, une fenêtre grande ouverte) : ce sont des exceptions.

## Exercices essentiels

1. Ces fleurs sentent [bonnes → bon].
   Pourquoi : Après le verbe « sentir » : adverbe, invariable.

2. Ils parlent [forts → fort].
   Pourquoi : Parler comment ? fort : adverbe, invariable.

3. Ces chaussures coûtent [chères → cher].
   Pourquoi : Après le verbe « coûter » : invariable.

4. Elles chantent [fausses → faux].
   Pourquoi : Chanter comment ? faux : invariable.

5. Nous avons travaillé [durs → dur].
   Pourquoi : Après le verbe « travailler » : invariable.

6. Les voitures se sont arrêtées [nettes → net].
   Pourquoi : S'arrêter net (brusquement) : invariable.

7. Elle a les cheveux coupés [courts → court].
   Pourquoi : « Court » modifie le participe « coupés » : invariable.

8. Ces valises pèsent [lourdes → lourd].
   Pourquoi : Après le verbe « peser » : invariable.

9. Ces roses sont belles et sentent bon.
   Pourquoi : Correct : « belles » (attribut, accordé), « bon » (après « sentir », invariable).

10. Ces bijoux coûtent ___.
    Choix : **cher** / chers
    Pourquoi : Après le verbe « coûter » : invariable.

11. Tri : adverbe ou adjectif ?
    Colonnes : adverbe (invariable) | adjectif (accordé)
    - Elles parlent (fort). → adverbe (invariable)
    - Des voix (fort) → adjectif (accordé)
    - Ces gâteaux sentent (bon). → adverbe (invariable)
    - De (bon) gâteaux → adjectif (accordé)
    - Ils voient (clair). → adverbe (invariable)
    - Des eaux (clair) → adjectif (accordé)
    Pourquoi : Après un verbe : invariable. Avec un nom : accord.

## Exercices avancés

12. Ces cartons sont [lourd → lourds].
    Pourquoi : Attribut de « ces cartons » (après « être ») : accord.

13. Ils ont tenu [bons → bon] jusqu'au bout.
    Pourquoi : « Tenir bon » : invariable.

14. Elles voient [claires → clair] dans son jeu.
    Pourquoi : « Voir clair » : invariable.

15. Des voix fortes chantaient fort dans la rue.
    Pourquoi : Correct : « fortes » qualifie « voix », « fort » modifie « chantaient ».

16. Ces pommes sont ___.
    Choix : **chères** / cher
    Pourquoi : Après « être », attribut de « ces pommes » : accord.

17. Ses filles visent [hautes → haut].
    Pourquoi : « Viser haut » : invariable.
