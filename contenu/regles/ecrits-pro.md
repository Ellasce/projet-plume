# Les écrits professionnels : formules et tournures

Identifiant : ecrits-pro
Niveau : supérieur
Résumé : Je vous saurais gré, veuillez agréer, à la suite de : les formules justes d'un courriel ou d'une lettre.

## Analyse

Décision demandée : écrire correctement les formules d'un courriel ou d'une lettre professionnels.
Cas de base
  1. Je vous saurais gré de… (savoir gré, et non « serais gré »).
  2. Veuillez (impératif de vouloir) : veuillez trouver, veuillez agréer.
  3. Je vous prie d'agréer… (prier, et non « pris »).
  4. Formule d'appel : « Madame, », « Monsieur, », « Madame, Monsieur, » ; « Chère Madame, »
     sans le nom de famille.
  5. « Monsieur le Directeur » : majuscule au titre dans l'appel.
Cas particuliers et pièges
  6. suite à → à la suite de (voir « Tournures critiquées »).
  7. Usages variables selon les entreprises (Cordialement, Bien à vous) : non exercés.
Niveau : supérieur.

## En bref

- Je vous **saurais** gré (savoir gré), et non « serais gré ».
- **Veuillez** trouver ci-joint ; je vous **prie** d'agréer.
- Appel : **Madame,** — ou **Chère Madame,** sans le nom de famille.

## Fiche

**Les formules justes** :
- « Je vous **saurais** gré de bien vouloir me répondre » : l'expression est **savoir gré** (être reconnaissant).
- « **Veuillez** trouver ci-joint… », « **Veuillez** agréer… » : impératif du verbe **vouloir**.
- « Je vous **prie** d'agréer, Madame, l'expression de mes salutations distinguées » : verbe **prier**.

**La formule d'appel** :
- « **Madame,** », « **Monsieur,** », « **Madame, Monsieur,** » (avec majuscules et virgule) ;
- « **Chère Madame,** » : sans le nom de famille ;
- « **Monsieur le Directeur,** » : le titre prend une majuscule.

**Le piège** : « suite à votre demande » est critiqué → **à la suite de** votre demande.

## Pour aller plus loin

- Les formules de fin varient selon le contexte : « Cordialement », « Bien à vous » sont courants dans les courriels.
- Dans la formule de politesse, on reprend la formule d'appel entre virgules : je vous prie d'agréer, **Madame**, l'expression de…

## Exercices essentiels

1. Je vous [serais → saurais] gré de bien vouloir me répondre.
   Pourquoi : L'expression est « savoir gré » : « je vous saurais gré ».

2. [Veuiller → Veuillez] trouver ci-joint mon dossier.
   Pourquoi : Impératif du verbe vouloir : « veuillez ».

3. Je vous [pris → prie] d'agréer mes salutations distinguées.
   Pourquoi : Verbe prier au présent : « je vous prie ».

4. [Chère Madame Martin → Chère Madame], je vous remercie de votre réponse.
   Pourquoi : Avec « chère », on n'ajoute pas le nom de famille.

5. [Suite à → À la suite de] notre entretien, je vous envoie le devis.
   Pourquoi : « Suite à » est critiqué : « à la suite de ».

6. [Monsieur le directeur → Monsieur le Directeur], je sollicite un rendez-vous.
   Pourquoi : Dans la formule d'appel, le titre prend une majuscule.

7. Nous vous [serions → saurions] gré de régler cette facture.
   Pourquoi : « Savoir gré » : « nous vous saurions gré ».

8. [Veuillez agréez → Veuillez agréer] mes salutations distinguées.
   Pourquoi : Après « veuillez », l'infinitif : « agréer ».

9. Monsieur le Directeur, je vous saurais gré de m'accorder un entretien.
   Pourquoi : Correct : titre avec une majuscule dans l'appel, et « savoir gré ».

10. Je vous ___ gré de votre compréhension.
    Choix : **saurais** / serais
    Pourquoi : L'expression est « savoir gré ».

11. Tri : formule correcte ou fautive ?
    Colonnes : correcte | fautive
    - Je vous saurais gré de… → correcte
    - Je vous serais gré de… → fautive
    - À la suite de votre appel… → correcte
    - Suite à votre appel… → fautive
    - Chère Madame, → correcte
    - Chère Madame Dupont, → fautive
    Pourquoi : Savoir gré, à la suite de, et « Chère Madame » sans le nom sont les formes recommandées.

## Exercices avancés

12. Je vous [prierai → prie] de bien vouloir me rappeler.
    Pourquoi : La formule s'écrit au présent : « je vous prie ».

13. [Veuiller → Veuillez] nous excuser pour ce retard.
    Pourquoi : Impératif du verbe vouloir : « veuillez ».

14. [Madame Monsieur → Madame, Monsieur], nous accusons réception de votre courrier.
    Pourquoi : Dans l'appel, on sépare « Madame » et « Monsieur » par une virgule.

15. À la suite de votre demande, veuillez trouver ci-joint le contrat.
    Pourquoi : Correct : « à la suite de », « veuillez trouver ci-joint ».

16. ___ trouver ci-joint les documents demandés.
    Choix : **Veuillez** / Veuiller / Voulez
    Pourquoi : Impératif du verbe vouloir : « veuillez ».

17. Je vous [serai → saurai] gré de me tenir informé.
    Pourquoi : « Savoir gré » au futur : « je vous saurai gré ».
