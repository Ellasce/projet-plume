# Le trait d'union

Identifiant : trait-union
Niveau : lycée
Résumé : Dis-moi, est-ce, peut-être, vingt-deux, c'est-à-dire : où mettre le trait d'union.

## Analyse

Décision demandée : mettre ou non un trait d'union.
Cas de base
  1. Impératif + pronom : dis-moi, donne-le-moi, allez-y, prends-en.
  2. Inversion du sujet : est-ce, viens-tu, peut-il, a-t-il (avec -t- entre deux traits).
  3. Nombres composés inférieurs à cent : vingt-deux, quatre-vingt-dix (rectifications de 1990 : tous les nombres).
  4. -ci et -là après un nom ou un pronom : ce jour-là, celui-ci.
Cas particuliers et pièges
  5. peut-être (= sans doute) / peut être (verbe pouvoir + être).
  6. Mots composés courants : c'est-à-dire, après-midi, grand-mère, arc-en-ciel, là-bas.
  7. Pas de trait d'union après un impératif suivi d'un infinitif : « laisse-moi faire » (oui),
     mais « viens me voir » (me est complément de voir).
  8. et un, et une : vingt et un (sans trait d'union en orthographe traditionnelle).
Niveau : lycée.

## En bref

On met un **trait d'union** :
- entre un **impératif** et son pronom : **dis-moi**, **allez-y** ;
- quand le sujet est **après le verbe** : **est-ce**, **viens-tu**, **a-t-il** ;
- dans les **nombres** jusqu'à cent : **vingt-deux** ;
- dans **peut-être** quand il signifie « sans doute ».

## Fiche

On met un **trait d'union** :
- entre un **impératif** et le pronom qui le suit : **dis-moi**, **donne-le-moi**, **allez-y**, **prends-en** ;
- quand le **sujet est placé après le verbe** : **est-ce** que, **viens-tu**, **peut-il**, **a-t-il** (le -t- est entouré de deux traits d'union) ;
- dans les **nombres composés** jusqu'à cent : **vingt-deux**, **quatre-vingt-dix** ;
- avec **-ci** et **-là** : ce jour-**là**, celui-**ci**, là-**bas**.

**Les pièges** :
- **peut-être** (avec trait d'union) signifie « sans doute » : il viendra **peut-être**. Sans trait d'union, c'est le verbe pouvoir suivi de « être » : cela **peut être** utile (cela pouvait être utile).
- **c'est-à-dire** prend deux traits d'union.

## Pour aller plus loin

- Mots composés courants : **après-midi**, **grand-mère**, **arc-en-ciel**, **porte-monnaie**, **au-dessus**, **là-dedans**.
- Après un impératif, pas de trait d'union si le pronom dépend du verbe suivant : **viens me voir** (me voir), mais **laisse-moi faire** (laisse-moi).
- Depuis les **rectifications de 1990**, on peut relier tous les éléments d'un nombre : **trois-cent-vingt-et-un**. Les deux écritures sont acceptées.

## Exercices essentiels

1. Je me demande si je devrais [peut être → peut-être] y aller.
   Pourquoi : « Sans doute » : adverbe « peut-être », avec un trait d'union.
   Source : Tatoeba n° 4835693

2. Tu as [peut être → peut-être] raison, mais je ne suis pas d'accord.
   Pourquoi : « Tu as sans doute raison » : « peut-être ».

3. Mon père étudie l'astronomie, [c'est à dire → c'est-à-dire] la science des étoiles.
   Pourquoi : « C'est-à-dire » prend deux traits d'union.
   Source : Tatoeba n° 12965460

4. [Dis moi → Dis-moi] pourquoi je devrais faire ça.
   Pourquoi : Impératif suivi de son pronom : « dis-moi ».
   Source : Tatoeba n° 7763318

5. [Est ce → Est-ce] que c'est ta chanson préférée ?
   Pourquoi : Le sujet « ce » est placé après le verbe : « est-ce ».
   Source : Tatoeba n° 138646

6. J'avais [vingt trois → vingt-trois] ans quand j'ai peint cette toile.
   Pourquoi : Nombre composé inférieur à cent : « vingt-trois ».

7. [Viens tu → Viens-tu] avec nous ce soir ?
   Pourquoi : Sujet après le verbe : « viens-tu ».

8. [Ce jour là → Ce jour-là], il neigeait.
   Rappel : avec -ci et -là : ce jour-là, celui-ci, là-bas.
   Pourquoi : « -là » s'attache au nom par un trait d'union : « ce jour-là ».

9. Il viendra peut-être cet après-midi.
   Pourquoi : Correct : « peut-être » (sans doute) et « après-midi » prennent un trait d'union.

10. Cela ___ dangereux.
    Choix : **peut être** / peut-être
    Pourquoi : « Cela pouvait être dangereux » : c'est le verbe pouvoir suivi de « être », sans trait d'union.

11. Tri : trait d'union ou non ?
    Colonnes : avec trait d'union | sans trait d'union
    - dis … moi → avec trait d'union
    - il … peut être fatigué (= il pouvait être) → sans trait d'union
    - est … ce que → avec trait d'union
    - vingt … deux → avec trait d'union
    - viens … me voir → sans trait d'union
    - c'est … à … dire → avec trait d'union
    Pourquoi : Impératif + pronom, inversion, nombre composé, « c'est-à-dire » → trait d'union. Verbe pouvoir + être, et pronom qui dépend d'un autre verbe (viens me voir) → sans.

## Exercices avancés

12. [A t il → A-t-il] déjà mangé ?
    Pourquoi : Inversion avec un -t- ajouté : deux traits d'union, « a-t-il ».

13. [Donne le moi → Donne-le-moi], s'il te plaît.
    Pourquoi : Impératif suivi de deux pronoms : deux traits d'union.

14. [Allez y → Allez-y], je vous suis.
    Pourquoi : Impératif + « y » : « allez-y ».

15. Les réponses sont à la page [quatre vingt dix → quatre-vingt-dix].
    Pourquoi : Nombre composé inférieur à cent : traits d'union.

16. Viens me voir demain.
    Pourquoi : Correct : « me » dépend de « voir », pas de « viens » : pas de trait d'union.

17. Mais qu'[est ce → est-ce] que ça veut dire ?
    Pourquoi : Inversion : « est-ce ».
    Source : Tatoeba n° 11485008

18. Après la pluie, un ___ est apparu.
    Choix : arc en ciel / **arc-en-ciel**
    Pourquoi : « Arc-en-ciel » est un mot composé avec deux traits d'union.

19. [Prends en → Prends-en] autant que tu veux.
    Pourquoi : Impératif + « en » : trait d'union (et le verbe garde son s : prends-en).
