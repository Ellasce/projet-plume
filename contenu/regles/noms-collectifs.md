# L'accord après beaucoup de, peu de, la foule de…

Identifiant : noms-collectifs
Niveau : supérieur
Résumé : Beaucoup de gens pensent (pluriel) ; la foule des supporters envahit le terrain (singulier).

## Analyse

Décision demandée : accorder le verbe après un adverbe de quantité ou un nom collectif.
Cas de base
  1. Adverbe de quantité (beaucoup de, peu de, trop de, assez de, combien de, nombre de,
     quantité de) : le verbe s'accorde avec le nom qui suit (beaucoup de gens pensent ;
     trop de bruit gêne).
  2. Nom collectif précédé de le, la, ce, son… (la foule de, ce groupe de, le troupeau de) :
     le verbe s'accorde avec le collectif, au singulier (la foule des supporters envahit).
Cas particuliers et pièges
  3. Collectif précédé de « un, une » (une foule de, un grand nombre de, une multitude de),
     fractions (la moitié de), la majorité de : l'usage accepte les deux accords ;
     non exercés.
  4. la plupart : voir « Accords délicats ».
Niveau : supérieur.

## En bref

- **beaucoup de, peu de, trop de, combien de, nombre de** : accord avec le **nom qui suit** → beaucoup de gens **pensent** ; trop de bruit **gêne**.
- **la foule de, ce groupe de, le troupeau de** : accord avec le **collectif**, au **singulier** → la foule des supporters **envahit** le terrain.

## Fiche

**Après un adverbe de quantité** (beaucoup de, peu de, trop de, assez de, combien de, nombre de, quantité de), le verbe s'accorde avec le **nom qui suit** :
> Beaucoup de gens **pensent**… Peu d'élèves **ont** réussi. Trop de bruit **gêne** les voisins.

**Après un nom collectif précédé de « le, la, ce, son… »** (la foule, ce groupe, le troupeau, la meute), on considère l'ensemble : le verbe est au **singulier**.
> La foule des supporters **envahit** le terrain. Ce groupe d'enfants **chante** très juste.

**Le test** : le premier mot est-il un adverbe (beaucoup, peu…) ou un nom précédé de « le, la, ce » ?

## Pour aller plus loin

- Après **un, une** + collectif (une foule de, un grand nombre de) ou une fraction (la moitié de), l'usage accepte le singulier ou le pluriel, selon qu'on pense à l'ensemble ou aux éléments.
- « Trop de travail **tue** le travail » : le nom qui suit est au singulier, le verbe aussi.

## Exercices essentiels

1. Beaucoup de gens [pense → pensent] que c'est trop cher.
   Pourquoi : Après « beaucoup de », accord avec « gens » : pluriel.

2. Peu d'élèves [a → ont] réussi l'examen.
   Pourquoi : Après « peu de », accord avec « élèves » : pluriel.

3. La foule des supporters [envahissent → envahit] le terrain.
   Pourquoi : « La foule » (avec « la ») : accord avec le collectif, singulier.

4. Trop de voitures [encombre → encombrent] le centre-ville.
   Pourquoi : Après « trop de », accord avec « voitures » : pluriel.

5. Ce groupe d'enfants [chantent → chante] très juste.
   Pourquoi : « Ce groupe » : accord avec le collectif, singulier.

6. Combien de personnes [viendra → viendront] ?
   Pourquoi : Après « combien de », accord avec « personnes » : pluriel.

7. Le troupeau de moutons [traversent → traverse] la route.
   Pourquoi : « Le troupeau » : accord avec le collectif, singulier.

8. Nombre d'experts [estime → estiment] que la crise va durer.
   Pourquoi : « Nombre de » (= beaucoup de) : accord avec « experts », pluriel.

9. Beaucoup d'enfants aiment ce livre, mais ce groupe d'adultes le trouve ennuyeux.
   Pourquoi : Correct : « beaucoup d'enfants » → pluriel ; « ce groupe » → singulier.

10. Peu de candidats ___ venus.
    Choix : **sont** / est
    Pourquoi : Après « peu de », accord avec « candidats » : pluriel.

11. Tri : singulier ou pluriel ?
    Colonnes : singulier | pluriel
    - Beaucoup de livres (être) abîmés. → pluriel
    - La foule des curieux (grossir). → singulier
    - Peu d'amis (venir). → pluriel
    - Ce groupe de touristes (partir). → singulier
    - Trop de bruit (gêner). → singulier
    - Combien d'élèves (savoir) nager ? → pluriel
    Pourquoi : Après beaucoup, peu, trop, combien : accord avec le nom qui suit. Après « la, ce » + collectif : singulier.

## Exercices avancés

12. Quantité de gens [croit → croient] cette rumeur.
    Pourquoi : « Quantité de » (= beaucoup de) : accord avec « gens », pluriel.

13. Trop de travail [tuent → tue] le travail.
    Pourquoi : Après « trop de », accord avec « travail », singulier.

14. La meute de loups [hurlent → hurle] la nuit.
    Pourquoi : « La meute » : accord avec le collectif, singulier.

15. Peu d'argent suffit parfois au bonheur.
    Pourquoi : Correct : après « peu de », accord avec « argent », singulier.

16. Ce troupeau de vaches ___ dans le pré.
    Choix : **broute** / broutent
    Pourquoi : « Ce troupeau » : singulier.

17. Assez de personnes [s'est → se sont] inscrites.
    Pourquoi : Après « assez de », accord avec « personnes » : pluriel.
