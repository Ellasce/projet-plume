# Le son « s » : s, ss, c, ç, sc

Identifiant : son-s
Niveau : collège
Résumé : Poisson (ss entre deux voyelles), glace (c devant e), garçon (ç devant o).

## Analyse

Décision demandée : écrire le son « s » avec s, ss, c, ç ou sc.
Cas de base
  1. Entre deux voyelles, s se prononce « z » : il faut ss pour garder « s » (poisson, glisser).
  2. c se prononce « s » devant e, i, y (glace, cinéma).
  3. Devant a, o, u, il faut une cédille : ç (garçon, leçon, reçu).
Cas particuliers et pièges
  4. Paires de sens : poison / poisson, désert / dessert, base / basse.
  5. sc : science, piscine, descendre (à retenir).
Hors sujet : les verbes en -cer (règle « Verbes en -cer, -ger… »).
Niveau : collège.

## En bref

- Entre deux voyelles, **ss** pour entendre « s » : poi**ss**on (poi**s**on se prononce « z »).
- **c** devant **e, i, y** : gla**c**e ; **ç** devant **a, o, u** : gar**ç**on, re**ç**u.
- Quelques mots en **sc** : **sc**ience, pi**sc**ine, de**sc**endre.

## Fiche

- Entre deux voyelles, un seul **s** se prononce « z » : une ro**s**e, un poi**s**on. Pour entendre « s », on double : un poi**ss**on, gli**ss**er.
- La lettre **c** se prononce « s » devant **e, i, y** : gla**c**e, **c**inéma.
- Devant **a, o, u**, il faut une **cédille** : gar**ç**on, le**ç**on, re**ç**u.
- Quelques mots s'écrivent avec **sc** : **sc**ience, pi**sc**ine, de**sc**endre.

**Le test** : regardez les voyelles autour du son.
> poi?on, entre deux voyelles → **ss** (poisson).
> gar?on, devant o → **ç** (garçon).

**Les pièges** :
- Le sens change : un **poison** / un **poisson** ; un **désert** / un **dessert**.
- La cédille ne se met jamais devant **e** ou **i** : glace, ciel (sans cédille).

## Pour aller plus loin

- Les mots en **sc** viennent souvent du latin : **sc**ience, con**sc**ience, a**sc**enseur.
- **nécessaire** : un c puis deux s.

## Exercices essentiels

1. Le [poison → poisson] nage dans le bocal.
   Pourquoi : Entre deux voyelles, pour entendre « s » : « ss ». Un « poison » est autre chose.

2. Ce [garcon → garçon] est mon frère.
   Pourquoi : Devant o, le c prend une cédille : « garçon ».

3. Il a bien appris sa [leson → leçon].
   Pourquoi : Le son « s » devant o s'écrit ici « ç » : « leçon ».

4. Attention, ça [glise → glisse] !
   Pourquoi : Entre deux voyelles, « s » se prononcerait « z » : « glisse ».

5. J'ai pris un [desert → dessert] au chocolat.
   Pourquoi : Le plat sucré s'écrit avec ss : « dessert ». Le « désert » est une étendue de sable.

6. Il a mangé une [glasse → glace].
   Pourquoi : Devant e, le c se prononce « s » : « glace ».

7. La [sience → science] m'intéresse beaucoup.
   Pourquoi : « Science » s'écrit avec sc.

8. J'ai [recu → reçu] ta lettre.
   Pourquoi : Devant u, il faut une cédille : « reçu ».

9. Le garçon a reçu une glace à la pistache.
   Pourquoi : Correct : « ç » devant o et u, « c » devant e.

10. Le ___ est rouge vif.
    Choix : **poisson** / poison
    Pourquoi : L'animal s'écrit avec ss : « poisson ».

11. Tri : ss ou ç ?
    Colonnes : ss | ç
    - pa…er (passer) → ss
    - fa…ade → ç
    - cla…e → ss
    - gar…on → ç
    - po…ible → ss
    - re…u → ç
    Pourquoi : Entre deux voyelles, devant e ou i : ss. Devant a, o, u : ç.

## Exercices avancés

12. Il faut [desendre → descendre] l'escalier.
    Pourquoi : « Descendre » s'écrit avec sc.

13. Nous allons à la [pisine → piscine].
    Pourquoi : « Piscine » s'écrit avec sc.

14. C'est [nésessaire → nécessaire].
    Pourquoi : « Nécessaire » : un c, puis deux s.

15. Le [macon → maçon] construit un mur.
    Pourquoi : Devant o, il faut une cédille : « maçon ».

16. Il est descendu à la piscine en ascenseur.
    Pourquoi : Correct : « descendu », « piscine » et « ascenseur » s'écrivent avec sc.

17. Il fait ses ___ de mathématiques.
    Choix : **exercices** / exercisses / exersices
    Pourquoi : « Exercice » : le son « s » s'écrit c devant e et i.
