# Les deux-points et le point-virgule

Identifiant : deux-points
Niveau : lycée
Résumé : Les deux-points annoncent (une explication, une liste, une citation) ; le point-virgule relie deux phrases proches.

## Analyse

Décision demandée : choisir entre deux-points et point-virgule.
Cas de base
  1. Deux-points : annoncent une explication ou une cause (elle n'est pas venue : elle était
     malade), une énumération, une citation (il a dit : « … »).
  2. Point-virgule : sépare deux propositions de même importance, souvent parallèles ou opposées
     (les uns lisaient ; les autres jouaient).
  3. Après l'un comme après l'autre, on continue en minuscule (sauf citation ou nom propre).
Cas particuliers et pièges
  4. Cas où les deux sont possibles selon le sens voulu : non exercés ; on garde des phrases
     où la relation (annonce ou parallèle) est claire.
Niveau : lycée.

## En bref

- **Deux-points** ( : ) pour **annoncer** : une explication, une liste, une citation → elle n'est pas venue **:** elle était malade.
- **Point-virgule** ( ; ) pour **relier** deux phrases de même importance → les uns lisaient **;** les autres jouaient.
- Après l'un ou l'autre, **minuscule**.

## Fiche

Les **deux-points** annoncent ce qui suit :
- une **explication**, une **cause** : elle n'est pas venue **:** elle était malade ;
- une **énumération** : il faut trois ingrédients **:** de la farine, des œufs et du lait ;
- une **citation** : il a dit **:** « Je reviens. »

Le **point-virgule** relie deux phrases **de même importance**, souvent parallèles ou opposées :
> Les uns lisaient **;** les autres jouaient aux cartes.

**Après** les deux-points ou le point-virgule, on continue en **minuscule** (sauf pour une citation ou un nom propre).

**Le test** : ce qui suit explique-t-il ou détaille-t-il ce qui précède ? → deux-points. Est-ce une seconde phrase parallèle ? → point-virgule.

## Pour aller plus loin

- En typographie française, on met une **espace avant** les deux-points et le point-virgule.
- Dans certaines phrases, les deux sont possibles : le sens change légèrement (explication ou simple juxtaposition).

## Exercices essentiels

1. Il a acheté trois [choses ; du → choses : du] pain, du lait et des œufs.
   Pourquoi : On annonce une énumération : deux-points.

2. Elle n'est pas venue [; elle → : elle] était malade.
   Pourquoi : On annonce une explication (la cause) : deux-points.

3. Il a dit [; « Je → : « Je] reviens. »
   Pourquoi : On annonce une citation : deux-points.

4. Voici ma réponse : [Non → non].
   Pourquoi : Après les deux-points, on continue en minuscule.

5. Le matin, il court [: l'après-midi → ; l'après-midi], il nage.
   Pourquoi : Deux phrases parallèles, de même importance : point-virgule.

6. Il pleuvait ; [Nous → nous] sommes restés à la maison.
   Pourquoi : Après un point-virgule, on continue en minuscule.

7. Ma mère m'a demandé [; « As-tu → : « As-tu] fini ? »
   Pourquoi : On annonce une citation : deux-points.

8. Je n'ai qu'une [envie ; dormir → envie : dormir].
   Pourquoi : On annonce ce qu'est cette envie : deux-points.

9. Les uns lisaient ; les autres jouaient aux cartes.
   Pourquoi : Correct : deux phrases parallèles reliées par un point-virgule.

10. Il a tout prévu ___ les billets, l'hôtel et la voiture.
    Choix : **:** / ;
    Pourquoi : On annonce une énumération : deux-points.

11. Tri : deux-points ou point-virgule ?
    Colonnes : deux-points | point-virgule
    - annoncer une explication → deux-points
    - relier deux phrases parallèles → point-virgule
    - annoncer une énumération → deux-points
    - introduire une citation → deux-points
    - opposer deux phrases de même importance → point-virgule
    - séparer « les uns… » et « les autres… » → point-virgule
    Pourquoi : Les deux-points annoncent ; le point-virgule relie des phrases de même importance.

## Exercices avancés

12. Paul aime la mer [: Julie → ; Julie] préfère la montagne.
    Pourquoi : Deux phrases parallèles qui s'opposent : point-virgule.

13. Le résultat est clair [; nous → : nous] avons gagné.
    Pourquoi : Ce qui suit explique ce qui précède : deux-points.

14. Il a prononcé ces mots [; « Merci → : « Merci] à tous. »
    Pourquoi : On annonce une citation : deux-points.

15. Il faut trois ingrédients : de la farine, des œufs et du lait.
    Pourquoi : Correct : les deux-points annoncent une énumération.

16. Les enfants jouaient dehors ___ les parents préparaient le repas.
    Choix : **;** / :
    Pourquoi : Deux phrases parallèles, de même importance : point-virgule.

17. [Attention ; le → Attention : le] sol est glissant.
    Pourquoi : Ce qui suit explique l'avertissement : deux-points.
