# Participe passé : coûter, valoir, courir, peser, vivre et verbes impersonnels

Identifiant : pp-couter-valoir
Niveau : supérieur
Résumé : Les trois cents euros que ce vélo m'a coûté, mais les efforts que ce travail m'a coûtés.

## Analyse

Décision demandée : accorder ou non le participe passé de coûter, valoir, courir, peser, vivre,
et celui des verbes impersonnels, quand un complément est placé avant.
Cas de base
  1. Sens propre (un prix, un poids, une distance, une durée) : le complément placé avant
     n'est pas un COD ; le participe reste invariable (les dix kilomètres qu'il a couru).
  2. Sens figuré : le complément est un COD ; le participe s'accorde s'il est placé avant
     (les efforts que ce travail m'a coûtés ; les dangers qu'il a courus).
  3. Verbes impersonnels (il y a, il faut, il fait) : participe toujours invariable
     (les orages qu'il y a eu ; les heures qu'il a fallu).
Cas particuliers et pièges
  4. peser = mesurer le poids de quelque chose : COD, accord (les valises que le douanier a pesées) ;
     peser = avoir tel poids : invariable (les soixante kilos qu'il a pesé).
  5. valoir = procurer : accord (les honneurs que son talent lui a valus).
  6. durer : toujours invariable (les deux heures qu'a duré le film).
  7. vivre + durée : usage hésitant (accord toléré) ; non exercé.
Niveau : supérieur.

## En bref

- **Sens propre** (prix, poids, distance, durée) : **invariable** → les 300 € que ce vélo m'a **coûté**.
- **Sens figuré** (le complément est un vrai COD) : **accord** s'il est placé avant → les efforts que ce travail m'a **coûtés**.
- **Verbes impersonnels** : toujours **invariables** → les orages qu'il y a **eu**.

## Fiche

Ces verbes ont deux sens. Le participe passé ne s'accorde que lorsque le complément est un **vrai COD**, placé avant.

**Sens propre** : un **prix**, un **poids**, une **distance**, une **durée**. Ce n'est pas un COD (on répond à « combien ? ») : **invariable**.
> Les trois cents euros que ce vélo m'a **coûté**. Les dix kilomètres qu'il a **couru**.

**Sens figuré** : le complément répond à « quoi ? ». C'est un COD : **accord** s'il est placé avant.
> Les efforts que ce travail m'a **coûtés**. Les dangers qu'il a **courus**. Les honneurs que son talent lui a **valus**.

**Verbes impersonnels** (il y a, il faut, il fait…) : le participe est **toujours invariable**.
> Les orages qu'il y a **eu**. Les heures qu'il a **fallu**. La chaleur qu'il a **fait**.

**Le test** : posez la question « combien ? » (sens propre, invariable) ou « quoi ? » (COD, accord).

**Les pièges** :
- **peser** : « le douanier a pesé quoi ? les valises » → les valises qu'il a **pesées** ; mais « il pesait combien ? soixante kilos » → les soixante kilos qu'il a **pesé**.
- **durer** n'a jamais de COD : les deux heures qu'a **duré** le film.

## Pour aller plus loin

- **valoir** au sens de « procurer » : les récompenses que ce film lui a **values**.
- **vivre** suivi d'une durée (les vingt ans qu'il a vécu) : l'usage hésite ; au sens figuré (les épreuves qu'il a **vécues**), on accorde.

## Exercices essentiels

1. Les trois cents euros que ce vélo m'a [coûtés → coûté] sont vite oubliés.
   Pourquoi : Un prix (combien ?) : ce n'est pas un COD, le participe reste invariable.

2. Les efforts que ce travail m'a [coûté → coûtés] étaient immenses.
   Pourquoi : Sens figuré : « que » (les efforts) est un COD placé avant : accord, « coûtés ».

3. Les dangers qu'il a [couru → courus] l'ont rendu prudent.
   Pourquoi : Courir un danger (quoi ?) : COD placé avant, accord.

4. Les dix kilomètres qu'il a [courus → couru] l'ont épuisé.
   Pourquoi : Une distance (combien ?) : invariable.

5. Les orages qu'il y a [eus → eu] ont abîmé les récoltes.
   Pourquoi : « Il y a » est impersonnel : participe toujours invariable.

6. Les valises que le douanier a [pesé → pesées] étaient trop lourdes.
   Pourquoi : Le douanier a pesé quoi ? les valises : COD placé avant, accord.

7. Les soixante kilos qu'il a [pesés → pesé] autrefois lui semblent loin.
   Pourquoi : Un poids (combien pesait-il ?) : invariable.

8. Les moments difficiles qu'elle a [vécu → vécus] l'ont rendue plus forte.
   Pourquoi : Vivre des moments (quoi ?) : COD placé avant, accord.

9. Les heures qu'il a fallu pour finir ont paru longues.
   Pourquoi : Correct : « il faut » est impersonnel, « fallu » reste invariable.

10. Les récompenses que ce film lui a ___ sont nombreuses.
    Choix : **values** / valu
    Pourquoi : Valoir = procurer : « que » (les récompenses) est un COD placé avant, accord.

11. Tri : accord ou invariable ?
    Colonnes : accord | invariable
    - les efforts que cela m'a (coûter) → accord
    - les vingt euros que cela m'a (coûter) → invariable
    - les dangers qu'il a (courir) → accord
    - les cinq kilomètres qu'il a (courir) → invariable
    - la chaleur qu'il a (faire) → invariable
    - les honneurs que cela lui a (valoir) → accord
    Pourquoi : Sens figuré, avec un vrai COD : accord. Prix, distance, verbe impersonnel : invariable.

## Exercices avancés

12. Les mille euros que ce tableau a [valus → valu] autrefois paraissent dérisoires.
    Pourquoi : Un prix (combien valait-il ?) : invariable.

13. Les inondations qu'il y a [eues → eu] ce printemps ont surpris tout le monde.
    Pourquoi : « Il y a » est impersonnel : invariable.

14. Les risques que vous avez [couru → courus] étaient inutiles.
    Pourquoi : Courir un risque (quoi ?) : COD placé avant, accord.

15. Toutes les larmes que cette rupture lui a coûtées n'y ont rien changé.
    Pourquoi : Correct : sens figuré (cela lui a coûté quoi ? des larmes) : accord.

16. Les trois heures qu'il a ___ pour réparer la voiture m'ont semblé longues.
    Choix : **fallu** / fallues
    Pourquoi : « Il faut » est impersonnel : « fallu » reste invariable.

17. Les deux heures qu'a [durées → duré] le film m'ont paru interminables.
    Pourquoi : « Durer » n'a jamais de COD : invariable.
