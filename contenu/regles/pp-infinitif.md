# Participe passé suivi d'un infinitif

Identifiant : pp-infinitif
Niveau : supérieur
Résumé : La maison qu'il a fait construire ; les musiciens que j'ai entendus jouer.

## Fiche

**Fait** suivi d'un infinitif est **toujours invariable**.
> La maison qu'ils ont fait construire. Elle s'est fait couper les cheveux.

**Laissé** suivi d'un infinitif est invariable (rectifications de 1990, aujourd'hui recommandées).

**Pour les autres verbes** (vu, entendu, senti, regardé…) : le participe s'accorde avec le COD placé avant **si celui-ci fait l'action de l'infinitif**.
> Les musiciens que j'ai entendus jouer. (les musiciens jouent → accord)
> La chanson que j'ai entendu chanter. (la chanson ne chante pas → invariable)

**Infinitif sous-entendu** : dû, pu, voulu restent invariables.
> Il a fait tous les efforts qu'il a pu (faire).

## Pour aller plus loin

- **Dû**, **pu**, **voulu** avec un infinitif sous-entendu : les efforts qu'il a dû (faire).

## Exercices essentiels

1. La maison qu'ils ont [faite → fait] construire est magnifique.
   Pourquoi : « Fait » suivi d'un infinitif est toujours invariable.

2. Les musiciens que j'ai [entendu → entendus] jouer étaient excellents.
   Pourquoi : Ce sont les musiciens qui jouent : accord avec « que » (les musiciens).

3. La chanson que j'ai entendu chanter m'a rappelé mon enfance.
   Pourquoi : Correct : la chanson ne chante pas, « entendu » reste invariable.

4. Elle s'est [faite → fait] couper les cheveux.
   Pourquoi : « Fait » + infinitif : toujours invariable, même avec un verbe pronominal.

5. Les arbres que j'ai ___ abattre étaient centenaires.
   Choix : **vu** / vus
   Pourquoi : Les arbres n'abattent pas, ils sont abattus : invariable.

6. Les enfants que j'ai ___ courir dans le parc semblaient heureux.
   Choix : vu / **vus**
   Pourquoi : Ce sont les enfants qui courent : accord.

7. Il les a [faits → fait] fuir.
   Pourquoi : « Fait » suivi d'un infinitif est toujours invariable.

8. Vous l'avez [faite → fait] souffrir.
   Pourquoi : « Fait » suivi d'un infinitif est toujours invariable.

## Exercices avancés

9. Il n'a pas obtenu toutes les réponses qu'il aurait [voulues → voulu].
   Pourquoi : Infinitif sous-entendu (voulu obtenir) : invariable.

10. Il a fait tous les efforts qu'il a pu.
   Pourquoi : Correct : « pu » (faire) sous-entendu, invariable.

11. Les ponts que j'ai [vus → vu] construire sont déjà fissurés.
   Pourquoi : Les ponts ne construisent pas, ils sont construits : « vu » reste invariable.

12. La chanteuse que j'ai [entendu → entendue] chanter hier était remarquable.
   Pourquoi : C'est la chanteuse qui chante : accord avec « que » (la chanteuse), « entendue ».

13. Il a fait tous les efforts qu'il a [dus → dû].
   Pourquoi : Infinitif sous-entendu (qu'il a dû faire) : « dû » reste invariable.

14. Je lui ai donné tous les conseils que j'ai [pus → pu].
   Pourquoi : Infinitif sous-entendu (que j'ai pu donner) : « pu » reste invariable.
   Source : LanguageTool (PPA_ACCORD_INFINITIF_IMPLICITE[0]#0)

15. Les exercices que j'ai [réussis → réussi] à faire n'étaient pas très compliqués.
   Pourquoi : « Que » est le COD de « faire », pas de « réussi » : participe invariable.
   Source : LanguageTool (PPA_ACCORD_INFINITIF_IMPLICITE[2]#0)
