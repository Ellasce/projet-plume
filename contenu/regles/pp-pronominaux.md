# Participe passé des verbes pronominaux

Identifiant : pp-pronominaux
Niveau : supérieur
Résumé : Elles se sont lavées, mais elles se sont lavé les mains.

## Fiche

**1. Verbes toujours pronominaux** (s'évanouir, se souvenir, s'enfuir, s'absenter…) : accord avec le sujet.
> Elle s'est souvenue de tout.

**2. Les autres verbes pronominaux** : remplacez mentalement **être** par **avoir** et appliquez la règle du COD placé avant.
> Elle s'est lavée. (elle a lavé qui ? « se » = elle, placé avant → accord)
> Elle s'est lavé les mains. (lavé quoi ? « les mains », placé après → invariable)

**3. Quand « se » est un COI** (parler à quelqu'un, sourire à quelqu'un), il n'y a pas d'accord.
> Ils se sont parlé. Elles se sont souri.

Ces participes restent toujours invariables : **parlé, souri, succédé, plu, déplu, nui, ressemblé, menti, téléphoné, suffi**.

## Pour aller plus loin

- **Se rendre compte** : participe invariable (ils se sont rendu compte).
- **Se permettre** : on permet À quelqu'un, invariable (elles se sont permis).

## Exercices essentiels

1. Elles se sont [lavées → lavé] les mains avant de passer à table.
   Pourquoi : Lavé quoi ? « les mains », placé après : invariable.

2. Ils se sont [parlés → parlé] pendant des heures.
   Pourquoi : On parle À quelqu'un : « se » est COI, pas d'accord.

3. Elle s'est souvenue de son premier jour d'école.
   Pourquoi : Correct : « se souvenir » est toujours pronominal, accord avec le sujet.

4. Les deux équipes se sont [succédées → succédé] sur le terrain.
   Pourquoi : On succède À quelqu'un : « succédé » reste invariable.

5. Elle s'est [coupé → coupée] en cuisinant.
   Pourquoi : Elle a coupé qui ? « se » = elle, placé avant : « coupée ».

6. Nous nous sommes [téléphonés → téléphoné] hier.
   Pourquoi : On téléphone À quelqu'un : invariable.

7. Ils se sont regardés sans dire un mot.
   Pourquoi : Correct : ils ont regardé qui ? « se » (eux-mêmes), placé avant → accord.

8. Tri : « Elles se sont… » : le participe s'accorde-t-il ? Demandez-vous si on fait l'action « à quelqu'un ».
   Colonnes : Accord | Invariable
   - Elles se sont (regarder) → Accord
   - Elles se sont (parler) → Invariable
   - Elles se sont (aider) → Accord
   - Elles se sont (sourire) → Invariable
   - Elles se sont (rencontrer) → Accord
   - Elles se sont (téléphoner) → Invariable
   Pourquoi : On regarde, aide, rencontre quelqu'un : « se » est COD → accord (regardées). On parle, sourit, téléphone À quelqu'un : « se » est COI → invariable (parlé).

## Exercices avancés

9. Les présidents qui se sont ___ ont tous promis des réformes.
   Choix : **succédé** / succédés
   Pourquoi : Succéder À quelqu'un : invariable.

10. Elles se sont ___ dès le premier regard.
   Choix : **plu** / plues
   Pourquoi : Plaire À quelqu'un : « plu » est toujours invariable.

11. Elles se sont [permises → permis] de nous interrompre.
   Pourquoi : On permet À quelqu'un : « se » est COI, « permis » reste invariable.

12. Ils se sont [rendus → rendu] compte de leur erreur.
   Pourquoi : Dans « se rendre compte », le participe reste invariable (le COD est « compte »).

13. Relis la lettre qu'elle s'est [écrit → écrite].
   Pourquoi : Elle a écrit quoi ? « que » (la lettre), placé avant : accord au féminin, « écrite ».

14. Les catastrophes se sont [succédées → succédé].
   Pourquoi : Succéder À quelque chose : « se » est COI, « succédé » reste invariable.
   Source : LanguageTool (SE_SUCCEDER[0]#0)

15. Mes professeurs d'espagnol se sont [révélé → révélés] peu pédagogues.
   Pourquoi : « Se révéler » : accord avec le sujet « mes professeurs » → « révélés ».
   Source : LanguageTool (ETRE_VPPA_OU_ADJ[12]#3)

16. Une entraide s'est petit à petit [créé → créée].
   Pourquoi : « Se créer » (sens passif) : accord avec le sujet « une entraide » → « créée ».
   Source : LanguageTool (ETRE_VPPA_OU_ADJ[4]#2)
