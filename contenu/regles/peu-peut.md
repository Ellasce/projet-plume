# peu, peut ou peux

Identifiant : peu-peut
Niveau : collège
Résumé : La petite quantité ou le verbe pouvoir ? Le test de « pouvait ».

## Analyse

Décision demandée : écrire « peu », « peut » ou « peux ».
Cas de base
  1. peut = verbe pouvoir, 3e personne du singulier. Test : remplacer par « pouvait ».
  2. peu = adverbe de quantité (pas beaucoup). Test : remplacer par « beaucoup ».
Cas particuliers et pièges
  3. peux = verbe pouvoir avec « je » ou « tu ».
  4. Expressions avec « peu » : un peu, peu importe, peu à peu, quelque peu, à peu près.
  5. « peut-être » (adverbe, avec trait d'union = sans doute) / « peut être » (verbe pouvoir + être).
Niveau : collège.

## En bref

- **peut** est le verbe **pouvoir** : il **peut** venir. On peut dire **pouvait**.
- **peu** veut dire « pas beaucoup » : un **peu** de sel.

> Elle peut partir. → Elle pouvait partir ✔ → **peut**
> Il mange peu. → Il mange pouvait ✘ → **peu**

## Fiche

- **peut** est le verbe **pouvoir** avec il, elle ou on. On peut le remplacer par **pouvait** : il **peut** venir.
- **peu** veut dire « pas beaucoup » : un **peu** de sel, il mange **peu**.

**Le test** : remplacez par **pouvait**. Si la phrase reste correcte, écrivez **peut**. Sinon, écrivez **peu**.
> Elle peut partir. → Elle pouvait partir ✔ → **peut**
> Il mange peu. → Il mange pouvait ✘ → **peu**

**Les pièges** :
- **un peu**, **un peu de**, **un peu plus** : toujours « peu ».
- Après **on**, **cela**, **qui**, c'est souvent le verbe : on **peut** essayer.

## Pour aller plus loin

- Avec **je** et **tu**, le verbe pouvoir s'écrit **peux** : je peux, tu peux.
- Expressions avec **peu** : **peu** importe, **peu** à **peu**, quelque **peu**, à **peu** près.
- **peut-être** (avec un trait d'union) signifie « sans doute » : il est **peut-être** parti. Sans trait d'union, c'est le verbe pouvoir suivi de être : cela **peut être** dangereux (cela pouvait être dangereux).

## Exercices essentiels

1. Je ne comprends pas comment on [peu → peut] aimer cela.
   Pourquoi : « Comment on pouvait aimer cela » : verbe pouvoir, « peut ».
   Source : Tatoeba n° 7070834

2. Est-ce qu'on [peu → peut] rester amies quand même ?
   Pourquoi : « Est-ce qu'on pouvait rester amies » : verbe pouvoir, « peut ».
   Source : Tatoeba n° 13629609

3. Cela ne [peu → peut] être autorisé.
   Pourquoi : « Cela ne pouvait être autorisé » : verbe pouvoir, « peut ».
   Source : Tatoeba n° 5899606

4. Je suis fatigué, je vais me reposer un [peut → peu].
   Pourquoi : « Un peu » : petite quantité. « Un pouvait » ne veut rien dire.
   Source : Tatoeba n° 13458485

5. Fais bouillir un [peut → peu] d'eau.
   Pourquoi : « Un peu d'eau » : petite quantité, « peu ».
   Source : Tatoeba n° 332240

6. Je ne veux qu'un [peut → peu] plus de temps.
   Pourquoi : « Un peu plus » : quantité, « peu ».
   Source : Tatoeba n° 2447883

7. L'amitié [peu → peut] vous donner un sentiment de communauté et d'appartenance.
   Pourquoi : « L'amitié pouvait vous donner » : verbe pouvoir, « peut ».
   Source : Tatoeba n° 11615719

8. Cela a coûté [peut → peu] cher.
   Pourquoi : « Peu cher » = pas très cher : adverbe, « peu ».
   Source : Tatoeba n° 5136726

9. Il peut venir un peu plus tard.
   Pourquoi : Correct : « il pouvait venir » (verbe pouvoir), puis « un peu » (quantité).

10. Elle ___ nous aider demain.
    Choix : peu / **peut**
    Pourquoi : « Elle pouvait nous aider » : verbe pouvoir.

11. Il reste ___ de pain.
    Choix : **peu** / peut
    Pourquoi : « Peu de pain » = pas beaucoup de pain.

12. Tri : « peu » ou « peut » ? Essayez « pouvait ».
    Colonnes : peu (pas beaucoup) | peut (= pouvait)
    - un … de sel → peu (pas beaucoup)
    - Il … partir. → peut (= pouvait)
    - très … de monde → peu (pas beaucoup)
    - On … essayer. → peut (= pouvait)
    - un … plus loin → peu (pas beaucoup)
    - Qui … m'aider ? → peut (= pouvait)
    Pourquoi : Il pouvait partir, on pouvait essayer, qui pouvait m'aider → « peut ». Les autres indiquent une petite quantité → « peu ».

## Exercices avancés

13. Je sais que je [peut → peux] compter sur toi.
    Pourquoi : Verbe pouvoir (je pouvais), mais avec « je » il s'écrit « peux ».
    Source : Tatoeba n° 8085905

14. Si tu as un problème, tu [peut → peux] le dire.
    Pourquoi : Verbe pouvoir avec « tu » : « tu peux ».
    Source : Tatoeba n° 10473581

15. Elle déclara qu'elle le suivrait, [peut → peu] importe où il aille.
    Pourquoi : Expression « peu importe » : « peu ».
    Source : Tatoeba n° 1395636

16. Il est [peut être → peut-être] déjà parti.
    Pourquoi : On peut dire « il est sans doute déjà parti » : adverbe « peut-être », avec un trait d'union.

17. Cela peut être dangereux.
    Pourquoi : Correct : « cela pouvait être dangereux » : verbe pouvoir suivi de être, sans trait d'union.

18. ___ à peu, il a repris confiance.
    Choix : **Peu** / Peut
    Pourquoi : Expression « peu à peu » (petit à petit).

19. Tu [peut → peux] parler aussi un peu de français.
    Pourquoi : Verbe pouvoir avec « tu » : « tu peux ». Le second mot est bien « peu » (un peu).
    Source : Tatoeba n° 2341386

20. Ce film est quelque [peut → peu] ennuyeux.
    Pourquoi : Expression « quelque peu » (un peu) : « peu ».
