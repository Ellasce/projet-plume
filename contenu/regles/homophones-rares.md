# Homophones moins connus : différend, fonds, repaire, golfe

Identifiant : homophones-rares
Niveau : supérieur
Résumé : Un différend (désaccord), des fonds (de l'argent), un repaire (un abri), le golfe (la mer).

## Analyse

Décision demandée : choisir entre des homophones de sens différents.
Cas de base
  1. différent (adjectif : pas pareil) / différend (nom : désaccord).
  2. fond (le bas, l'arrière : le fond de la mer) / fonds (argent, capital : collecter des fonds ;
     fonds de commerce) / fonts (fonts baptismaux).
  3. pause (arrêt) / pose (action de poser ; attitude).
  4. repaire (abri de bêtes ou de malfaiteurs) / repère (marque qui sert à se retrouver).
  5. golf (le sport) / golfe (avancée de la mer).
  6. compte (calcul) / conte (histoire) / comte (titre de noblesse).
Niveau : supérieur.

## En bref

- **différent** = pas pareil ; un **différend** = un désaccord.
- le **fond** = le bas ; des **fonds** = de l'argent.
- une **pause** = un arrêt ; une **pose** = l'action de poser.
- un **repaire** = un abri ; un **repère** = une marque.

## Fiche

- **différent** (adjectif) : pas pareil → des avis **différents**. Un **différend** (nom) : un désaccord → régler un **différend**.
- le **fond** : le bas, l'arrière → au **fond** de la mer. Les **fonds** : de l'argent → collecter des **fonds**, un **fonds** de commerce. Les **fonts** baptismaux : le bassin du baptême.
- une **pause** : un arrêt → faire une **pause**. Une **pose** : l'action de poser, une attitude → la **pose** d'une moquette, prendre la **pose**.
- un **repaire** : un abri de bêtes ou de malfaiteurs → un **repaire** de brigands. Un **repère** : une marque pour se retrouver → un point de **repère**.
- le **golf** : le sport. Le **golfe** : une avancée de la mer → le **golfe** de Gascogne.
- le **compte** (calcul), le **conte** (histoire), le **comte** (noble).

**Le test** : remplacez par une définition (désaccord, argent, arrêt, abri…).

## Pour aller plus loin

- **fonds** garde son s au singulier : un **fonds** de commerce.
- **repère** vient de « repérer » : on repère un lieu grâce à un **repère**.

## Exercices essentiels

1. Ils ont réglé leur [différent → différend] à l'amiable.
   Pourquoi : Un désaccord : le nom « différend ».

2. Nos avis sont très [différends → différents].
   Pourquoi : Pas pareils : l'adjectif « différents ».

3. Il a collecté des [fond → fonds] pour l'association.
   Pourquoi : De l'argent : « fonds ».

4. Le trésor gît au [fonds → fond] de la mer.
   Pourquoi : Le bas de la mer : « fond ».

5. Faisons une [pose → pause] de dix minutes.
   Pourquoi : Un arrêt : « pause ».

6. La [pause → pose] de la moquette prendra une journée.
   Pourquoi : L'action de poser : « pose ».

7. Cette grotte est un [repère → repaire] de brigands.
   Pourquoi : Un abri de malfaiteurs : « repaire ».

8. Ce clocher sert de [repaire → repère] aux marins.
   Pourquoi : Une marque pour se retrouver : « repère ».

9. Les fonts baptismaux se trouvent au fond de l'église.
   Pourquoi : Correct : « fonts baptismaux » (le bassin), « au fond » (à l'arrière).

10. Ils jouent au ___ le dimanche.
    Choix : **golf** / golfe
    Pourquoi : Le sport : « golf ».

11. Tri : différent ou différend ?
    Colonnes : différent (pas pareil) | différend (désaccord)
    - deux avis … → différent (pas pareil)
    - un … entre voisins → différend (désaccord)
    - des goûts … → différent (pas pareil)
    - régler un … → différend (désaccord)
    - un caractère … → différent (pas pareil)
    - un … commercial → différend (désaccord)
    Pourquoi : L'adjectif (pas pareil) : différent. Le nom (désaccord) : différend.

## Exercices avancés

12. Le bateau navigue dans le [golf → golfe] de Gascogne.
    Pourquoi : Une avancée de la mer : « golfe ».

13. Il a lu un [compte → conte] de fées.
    Pourquoi : Une histoire : « conte ».

14. Le [conte → comte] habitait un château.
    Pourquoi : Un titre de noblesse : « comte ».

15. Le comte a fait le compte de ses terres.
    Pourquoi : Correct : le « comte » (noble) et le « compte » (calcul).

16. Il a racheté un ___ de commerce.
    Choix : **fonds** / fond
    Pourquoi : Un capital, une entreprise : « fonds de commerce ».

17. Elle prend la [pause → pose] pour le photographe.
    Pourquoi : Une attitude : « pose ».
