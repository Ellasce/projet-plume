# Excepté, vu, passé, compris, ci-joint : avant ou après le nom

Identifiant : participes-invariables
Niveau : supérieur
Résumé : Excepté les enfants, mais les enfants exceptés ; ci-joint les photos, mais la lettre ci-jointe.

## Analyse

Décision demandée : accorder ou non excepté, vu, passé, compris, y compris, non compris,
attendu, ci-joint, ci-inclus.
Cas de base
  1. Placés avant le nom (ou en tête de phrase), ils jouent le rôle d'une préposition :
     invariables (excepté les enfants, vu les circonstances, passé dix heures).
  2. Placés après le nom, ce sont des participes ou adjectifs : ils s'accordent
     (les enfants exceptés, la lettre ci-jointe, la TVA comprise).
Cas particuliers et pièges
  3. ci-joint, ci-inclus : invariables en tête de phrase (ci-joint les photos) ;
     variables après le nom (la copie ci-incluse).
  4. Cas hésitants non exercés : « vous trouverez ci-joint(e) la facture » (les deux sont admis),
     « étant donné(e) la situation » (accord toléré).
Niveau : supérieur.

## En bref

- **Avant** le nom ou en **tête** de phrase : **invariable** → **excepté** les enfants, **vu** les circonstances, **ci-joint** les photos.
- **Après** le nom : **accord** → les enfants **exceptés**, la lettre **ci-jointe**, la TVA **comprise**.

## Fiche

**Avant le nom** (ou en tête de phrase), ces mots jouent le rôle d'une **préposition** : ils sont **invariables**.
> **Excepté** les plus jeunes, tout le monde a nagé. **Vu** les circonstances, la réunion est reportée. **Passé** dix heures, les portes sont fermées. **Y compris** les taxes, le prix reste raisonnable.

**Après le nom**, ce sont des **participes** : ils **s'accordent** avec ce nom.
> Les plus jeunes **exceptés**, tout le monde a nagé. La lettre **ci-jointe**. La TVA **comprise**.

**Le test** : regardez la place du mot. Avant le nom → invariable. Après → accord.

**Les pièges** :
- **ci-joint** et **ci-inclus** en tête de phrase : invariables (**ci-joint** les photos de la fête).
- **attendu** et **non compris** suivent la même règle : **attendu** les difficultés ; **non compris** les boissons.

## Pour aller plus loin

- Dans « vous trouverez **ci-joint** (ou **ci-jointe**) la facture », les deux accords sont admis : le mot est entre le verbe et le nom.
- **étant donné** devant un nom : l'invariabilité est la plus courante, l'accord est toléré (étant donné ou étant donnée la situation).

## Exercices essentiels

1. [Exceptés → Excepté] les plus jeunes, tout le monde a nagé.
   Pourquoi : Placé avant le nom : préposition, invariable.

2. [Vus → Vu] les circonstances, la réunion est reportée.
   Pourquoi : Placé avant le nom : « vu » est invariable.

3. [Passées → Passé] dix heures, les portes sont fermées.
   Pourquoi : Placé avant le nom : « passé » est invariable.

4. Veuillez lire la lettre [ci-joint → ci-jointe].
   Pourquoi : Placé après le nom : accord avec « la lettre ».

5. [Ci-jointes → Ci-joint] les photos de la fête.
   Pourquoi : En tête de phrase : « ci-joint » est invariable.

6. Les enfants [excepté → exceptés], toute la famille est venue.
   Pourquoi : Placé après le nom : accord avec « les enfants ».

7. [Y comprises → Y compris] les taxes, le prix reste raisonnable.
   Pourquoi : Placé avant le nom : « y compris » est invariable.

8. Toutes les pièces, la cuisine [compris → comprise], seront repeintes.
   Pourquoi : Placé après le nom : accord avec « la cuisine ».

9. Passé minuit, tout est fermé, excepté la pharmacie.
   Pourquoi : Correct : « passé » et « excepté », placés avant le nom, sont invariables.

10. ___ les jours fériés, le musée est ouvert.
    Choix : **Excepté** / Exceptés
    Pourquoi : Placé avant le nom : invariable.

11. Tri : invariable ou accordé ?
    Colonnes : invariable (avant le nom) | accordé (après le nom)
    - excepté les enfants → invariable (avant le nom)
    - les enfants exceptés → accordé (après le nom)
    - passé huit heures → invariable (avant le nom)
    - la facture ci-jointe → accordé (après le nom)
    - y compris la TVA → invariable (avant le nom)
    - la TVA comprise → accordé (après le nom)
    Pourquoi : Avant le nom, ces mots sont des prépositions, invariables. Après, ils s'accordent.

## Exercices avancés

12. La copie [ci-inclus → ci-incluse] doit être signée.
    Pourquoi : Placé après le nom : accord avec « la copie ».

13. [Attendues → Attendu] les difficultés, nous avons renoncé.
    Pourquoi : Placé avant le nom : « attendu » (= étant donné) est invariable.

14. [Non comprises → Non compris] les boissons, le repas coûte vingt euros.
    Pourquoi : Placé avant le nom : « non compris » est invariable.

15. Toutes les factures, celles de juin exceptées, ont été payées.
    Pourquoi : Correct : placé après « celles de juin », « exceptées » s'accorde.

16. La TVA ___, le total est de cent euros.
    Choix : **comprise** / compris
    Pourquoi : Placé après le nom : accord avec « la TVA ».

17. [Passée → Passé] la première semaine, tout devient plus facile.
    Pourquoi : Placé avant le nom : « passé » est invariable.
