# L'imparfait

Identifiant : conj-base-imparfait
Niveau : collège
Résumé : Les mêmes terminaisons pour tous les verbes : -ais, -ais, -ait…

## Fiche

L'imparfait a **les mêmes terminaisons pour tous les verbes** : **-ais, -ais, -ait, -ions, -iez, -aient**.

**Le radical** est celui de « nous » au présent :
> nous finissons → je finiss**ais** ; nous prenons → je pren**ais** ; nous faisons → je fais**ais**
Seule exception : **être** → j'**étais**.

**Pièges** :
- avec les verbes en **-ier** et **-yer**, on garde le i ou le y du radical **et** celui de la terminaison : nous étud**ii**ons, vous cr**ii**ez, nous voy**i**ons ;
- avec manger et commencer, on garde le e ou le ç devant a : je mang**e**ais, il commen**ç**ait.
