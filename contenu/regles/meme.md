# même ou mêmes

Identifiant : meme
Niveau : lycée
Résumé : Les mêmes livres (pareils, accord) ; même les enfants (= aussi, invariable).

## Analyse

Décision demandée : accorder ou non « même ».
Cas de base
  1. même adjectif : s'accorde avec le nom ou le pronom.
     - devant le nom, il signifie « pareil » : les mêmes chaussures ;
     - après un pronom, avec un trait d'union : eux-mêmes, elles-mêmes, nous-mêmes.
  2. même adverbe : signifie « aussi, y compris » ; invariable (même les enfants ont compris).
  Test : remplacer par « aussi » ou « y compris » → adverbe, invariable.
Cas particuliers et pièges
  3. Après un nom, au sens de « exactement » : les paroles mêmes de son père (adjectif, accord).
  4. Devant un adjectif ou un verbe : adverbe (même fatigués, ils ont continué ; ils ont même oublié).
  5. « vous-même » (politesse, une personne) / « vous-mêmes » (plusieurs) : non exercé sans contexte.
Niveau : lycée.

## En bref

- **mêmes** (avec s) = **pareils**, devant un nom pluriel : les **mêmes** chaussures ; et après un pronom pluriel : eux-**mêmes**.
- **même** (sans s) = **aussi, y compris** : **même** les enfants ont compris.

## Fiche

- **même** adjectif s'**accorde** :
  - devant un nom, il veut dire **pareil** : les **mêmes** chaussures, la **même** robe ;
  - après un pronom, avec un trait d'union : **eux-mêmes**, **elles-mêmes**, **nous-mêmes**, **elle-même**.
- **même** adverbe veut dire **aussi, y compris**. Il est **invariable** : **même** les enfants ont compris.

**Le test** : remplacez par « aussi » ou « y compris ».
> Même les enfants ont compris. → Y compris les enfants ✔ → adverbe, **même**.
> Nous avons les mêmes chaussures. → les pareilles ✔ → adjectif, **mêmes**.

**Les pièges** :
- **eux-mêmes, elles-mêmes, nous-mêmes** : pluriel, avec un s.
- Devant un adjectif ou un verbe, c'est l'adverbe : **même** fatigués, ils ont continué.

## Pour aller plus loin

- Après un nom, au sens de « exactement » : ce sont les paroles **mêmes** de son père (accord).
- **ils ont même oublié** : l'adverbe porte sur le verbe, il reste invariable.

## Exercices essentiels

1. Nous avons les [même → mêmes] chaussures.
   Pourquoi : « Les chaussures pareilles » : adjectif, accordé au pluriel, « mêmes ».

2. Ils l'ont fait [eux-même → eux-mêmes].
   Pourquoi : Après « eux » (pluriel) : « eux-mêmes ».

3. [Mêmes → Même] les enfants ont compris.
   Pourquoi : « Y compris les enfants » : adverbe, invariable.

4. Elles portent la [mêmes → même] robe.
   Pourquoi : « La robe » est au singulier : « même ».

5. Nous l'avons construit [nous-même → nous-mêmes].
   Pourquoi : Après « nous » (plusieurs personnes) : « nous-mêmes ».

6. Tout le monde est venu, [mêmes → même] les plus âgés.
   Pourquoi : « Y compris les plus âgés » : adverbe, « même ».

7. Ces deux frères ont les [même → mêmes] yeux.
   Pourquoi : « Les yeux pareils » : adjectif, « mêmes ».

8. Elle a réparé le vélo [elle-mêmes → elle-même].
   Pourquoi : Après « elle » (une seule personne) : « elle-même ».

9. Même les meilleurs élèves font les mêmes erreurs.
   Pourquoi : Correct : « même » (y compris), puis « les mêmes erreurs » (pareilles).

10. Ils ont tous ___ goûts.
    Choix : **les mêmes** / les même
    Pourquoi : « Des goûts pareils » : adjectif au pluriel, « les mêmes ».

11. Tri : même ou mêmes ?
    Colonnes : même (aussi, ou singulier) | mêmes (pareils, pluriel)
    - ___ mon chien a peur. → même (aussi, ou singulier)
    - les ___ idées → mêmes (pareils, pluriel)
    - Elles l'ont dit elles-___. → mêmes (pareils, pluriel)
    - la ___ couleur → même (aussi, ou singulier)
    - ___ toi, tu ris ! → même (aussi, ou singulier)
    - les ___ résultats → mêmes (pareils, pluriel)
    Pourquoi : « Aussi, y compris » ou un nom au singulier : même. « Pareils » au pluriel, ou eux-, elles-, nous- : mêmes.

## Exercices avancés

12. Ils ont [mêmes → même] oublié leurs clés.
    Pourquoi : L'adverbe porte sur le verbe (ils ont aussi oublié) : invariable.

13. Ce sont les paroles [même → mêmes] de son père.
    Pourquoi : Après le nom, au sens de « exactement » : adjectif, accordé avec « paroles ».

14. [Mêmes → Même] fatigués, ils ont continué.
    Pourquoi : Devant un adjectif, au sens de « y compris » : adverbe, invariable.

15. Ils sont restés eux-mêmes, même dans la difficulté.
    Pourquoi : Correct : « eux-mêmes » (pronom pluriel), puis « même » (y compris).

16. Ces chiffres sont restés les ___ depuis un an.
    Choix : **mêmes** / même
    Pourquoi : « Les chiffres pareils » : adjectif au pluriel, « mêmes ».

17. Elles se sont coiffées [elles-même → elles-mêmes].
    Pourquoi : Après « elles » (pluriel) : « elles-mêmes ».
