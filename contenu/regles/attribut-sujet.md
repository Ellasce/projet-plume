# L'accord de l'attribut du sujet

Identifiant : attribut-sujet
Niveau : collège
Résumé : Ma sœur est contente, les rues paraissent désertes : l'attribut s'accorde avec le sujet.

## Analyse

Décision demandée : accorder l'attribut du sujet (adjectif ou nom) après un verbe d'état.
Cas de base
  1. Verbes d'état : être, sembler, paraître, devenir, rester, demeurer, avoir l'air.
  2. L'attribut (adjectif ou nom) s'accorde en genre et en nombre avec le sujet.
  Test : remplacer le verbe par « être » ; ce qui suit décrit le sujet.
Cas particuliers et pièges
  3. Sujets masculin + féminin : masculin pluriel (Paul et Léa sont contents).
  4. avoir l'air + chose : accord avec le sujet (cette tarte a l'air délicieuse).
  5. Nom attribut : il prend aussi la marque du féminin et du pluriel quand il le peut
     (elles sont devenues infirmières).
Hors sujet : adjectifs employés comme adverbes (règle « Adjectif ou adverbe »).
Niveau : collège.

## En bref

Après **être, sembler, paraître, devenir, rester, avoir l'air**, le mot qui décrit le sujet (l'**attribut**) **s'accorde avec le sujet** :
> Ma sœur est **contente**. Les rues paraissent **désertes**.

## Fiche

Les **verbes d'état** relient le sujet à un mot qui le décrit : **être, sembler, paraître, devenir, rester, demeurer, avoir l'air**. Ce mot est l'**attribut du sujet**. Il s'accorde **en genre et en nombre avec le sujet**.
> Ma sœur est **contente**. Les enfants semblent **fatigués**. Ces fleurs restent **fraîches**.

**Le test** : remplacez le verbe par **être**. Le mot qui suit décrit-il le sujet ? Alors il s'accorde avec lui.

**Les pièges** :
- Un masculin et un féminin : **masculin pluriel** (Paul et Léa sont **contents**).
- **avoir l'air** + une chose : accord avec le sujet (cette tarte a l'air **délicieuse**).

## Pour aller plus loin

- Un **nom** attribut prend aussi le féminin et le pluriel quand il le peut : mes cousines sont devenues **infirmières**.
- **demeurer** suit la même règle : les résultats demeurent **incertains**.

## Exercices essentiels

1. Ma sœur est [content → contente].
   Pourquoi : L'attribut s'accorde avec « ma sœur » (féminin) : « contente ».

2. Les enfants semblent [fatigué → fatigués].
   Pourquoi : Après « sembler », accord avec « les enfants » : « fatigués ».

3. Ces fleurs restent [frais → fraîches].
   Pourquoi : Accord avec « ces fleurs » (féminin pluriel) : « fraîches ».

4. Elle est devenue [célèbres → célèbre].
   Pourquoi : Accord avec « elle » (singulier) : « célèbre ».

5. Les rues paraissent [désert → désertes].
   Pourquoi : Accord avec « les rues » (féminin pluriel) : « désertes ».

6. Mes parents sont [heureuse → heureux].
   Pourquoi : Accord avec « mes parents » (masculin pluriel) : « heureux ».

7. Cette tarte a l'air [délicieux → délicieuse].
   Pourquoi : « Avoir l'air » + une chose : accord avec « cette tarte » : « délicieuse ».

8. Les nuits deviennent [froide → froides].
   Pourquoi : Accord avec « les nuits » : « froides ».

9. Les élèves sont attentifs et la salle reste silencieuse.
   Pourquoi : Correct : « attentifs » (les élèves), « silencieuse » (la salle).

10. Ces chemises sont ___.
    Choix : **sales** / sale
    Pourquoi : Accord avec « ces chemises » (pluriel) : « sales ».

11. Tri : quel accord ?
    Colonnes : masculin pluriel | féminin pluriel
    - Les garçons sont (content). → masculin pluriel
    - Les filles semblent (prêt). → féminin pluriel
    - Mes oncles restent (calme). → masculin pluriel
    - Ces routes deviennent (dangereux). → féminin pluriel
    - Paul et Léa sont (ravi). → masculin pluriel
    - Ses sœurs paraissent (inquiet). → féminin pluriel
    Pourquoi : L'attribut s'accorde avec le sujet ; un masculin et un féminin réunis donnent le masculin pluriel.

## Exercices avancés

12. Paul et Léa sont [contentes → contents].
    Pourquoi : Un masculin et un féminin : masculin pluriel, « contents ».

13. Elles se sentent [seul → seules].
    Pourquoi : Accord avec « elles » : « seules ».

14. Cette solution semble [simples → simple].
    Pourquoi : Accord avec « cette solution » (singulier) : « simple ».

15. Les résultats demeurent incertains.
    Pourquoi : Correct : après « demeurer », accord avec « les résultats ».

16. Tes idées me paraissent ___.
    Choix : **justes** / juste
    Pourquoi : Accord avec « tes idées » : « justes ».

17. Mes cousines sont devenues [infirmier → infirmières].
    Pourquoi : Le nom attribut prend le féminin pluriel : « infirmières ».
