# censé ou sensé

Identifiant : cense-sense
Niveau : supérieur
Résumé : Il est censé venir (= supposé) ; une idée sensée (= raisonnable).

## Analyse

Décision demandée : écrire censé ou sensé (et leurs accords).
Cas de base
  1. censé : adjectif = supposé, considéré comme ; presque toujours suivi d'un infinitif
     (il est censé venir). Test : remplacer par « supposé ».
  2. sensé : adjectif = raisonnable, qui a du bon sens (une idée sensée). Test : remplacer par « raisonnable ».
Cas particuliers et pièges
  3. Les deux s'accordent : censée, censés, sensée, sensés.
  4. « Nul n'est censé ignorer la loi ».
  5. sensé vient de « sens » (bon sens) ; censé vient du latin censere (estimer).
Niveau : supérieur.

## En bref

- **censé** = **supposé**, suivi d'un verbe : il est **censé** venir → il est **supposé** venir.
- **sensé** = **raisonnable**, qui a du bon **sens** : une idée **sensée**.

## Fiche

- **censé** veut dire **supposé** ; il est presque toujours suivi d'un **infinitif** : tu es **censé** arriver à huit heures.
- **sensé** veut dire **raisonnable**, plein de bon **sens** : c'est une remarque très **sensée**.

**Le test** : remplacez par « supposé » ou par « raisonnable ».
> Tu es censé arriver à huit heures. → Tu es supposé arriver ✔ → **censé**.
> Une remarque sensée. → Une remarque raisonnable ✔ → **sensée**.

**Les pièges** :
- Les deux **s'accordent** : elle est **censée** partir ; des arguments **sensés**.
- Un moyen de retenir : **sensé** comme bon **sens**.

## Pour aller plus loin

- « **Nul n'est censé ignorer la loi** » : personne n'est supposé l'ignorer.
- **censé** s'accorde avec le sujet : ils sont **censés** partir à midi.

## Exercices essentiels

1. Tu es [sensé → censé] arriver à huit heures.
   Pourquoi : « Tu es supposé arriver » : « censé ».

2. C'est une remarque très [censée → sensée].
   Pourquoi : « Une remarque raisonnable » : « sensée ».

3. Il était [sensé → censé] m'appeler hier.
   Pourquoi : « Il était supposé m'appeler » : « censé ».

4. Elle a pris une décision [censée → sensée].
   Pourquoi : « Une décision raisonnable » : « sensée ».

5. Nous sommes [sensés → censés] rendre le devoir lundi.
   Pourquoi : « Nous sommes supposés rendre » : « censés ».

6. Une personne [censée → sensée] ne ferait pas ça.
   Pourquoi : « Une personne raisonnable » : « sensée ».

7. Ce médicament est [sensé → censé] soulager la douleur.
   Pourquoi : « Supposé soulager » : « censé ».

8. Ses arguments sont [censés → sensés].
   Pourquoi : « Ses arguments sont raisonnables » : « sensés ».

9. Il est censé être prudent, mais ce n'est pas un garçon sensé.
   Pourquoi : Correct : « censé être » (supposé être), « un garçon sensé » (raisonnable).

10. Les élèves sont ___ apporter leur livre.
    Choix : **censés** / sensés
    Pourquoi : « Supposés apporter » : « censés ».

11. Tri : censé ou sensé ?
    Colonnes : censé (supposé) | sensé (raisonnable)
    - Il est ___ venir demain. → censé (supposé)
    - Un conseil ___. → sensé (raisonnable)
    - Elle est ___ tout savoir. → censé (supposé)
    - Une réponse ___. → sensé (raisonnable)
    - Le train est ___ partir à midi. → censé (supposé)
    - Un homme ___. → sensé (raisonnable)
    Pourquoi : Suivi d'un verbe, au sens de « supposé » : censé. Au sens de « raisonnable » : sensé.

## Exercices avancés

12. Nul n'est [sensé → censé] ignorer la loi.
    Pourquoi : « Nul n'est supposé ignorer la loi » : « censé ».

13. Elle est [sensée → censée] être en vacances.
    Pourquoi : « Supposée être en vacances » : « censée ».

14. C'est la réponse la plus [censée → sensée].
    Pourquoi : « La plus raisonnable » : « sensée ».

15. Une proposition sensée est censée convaincre.
    Pourquoi : Correct : « sensée » (raisonnable), puis « censée convaincre » (supposée convaincre).

16. Voilà un conseil ___.
    Choix : **sensé** / censé
    Pourquoi : « Un conseil raisonnable » : « sensé ».

17. Ils sont [censé → censés] partir à midi.
    Pourquoi : « Censé » s'accorde avec « ils » : « censés ».
