# Les trois groupes de verbes

Identifiant : conj-groupes
Niveau : collège
Résumé : Chanter, finir, prendre : à quel groupe appartient un verbe ?

## Fiche

On classe les verbes en **trois groupes**, selon leur infinitif et leur conjugaison.

**1er groupe** : les verbes en **-er** (sauf **aller**). C'est le plus grand groupe, et il est très régulier.
> chanter, manger, jouer, envoyer

**2e groupe** : les verbes en **-ir** qui font **-issons** avec « nous ».
> finir → nous finissons ; choisir → nous choisissons ; grandir, rougir, réussir

**3e groupe** : **tous les autres**. Ce sont les verbes irréguliers :
- les verbes en -ir qui ne font pas -issons : partir (nous partons), courir, offrir, ouvrir, venir ;
- les verbes en -oir : voir, pouvoir, vouloir, savoir ;
- les verbes en -re : prendre, faire, dire, mettre ;
- et **aller**.

**L'astuce** : pour un verbe en -ir, dites « nous … ». Si vous entendez **-issons**, c'est le 2e groupe.

**Être** et **avoir** sont des **auxiliaires** : on les étudie à part.

## Pour aller plus loin

- **haïr** et **fleurir** sont du 2e groupe (nous haïssons, nous fleurissons).
- **maudire** est du 3e groupe, malgré « nous maudissons » : il finit en -ire.
- **envoyer** reste au 1er groupe malgré son futur irrégulier (j'enverrai).
- **offrir**, **ouvrir**, **courir**, **voir** sont du 3e groupe.

## Exercices essentiels

1. Le verbe « chanter » est du ___.
   Choix : **1er groupe** / 2e groupe / 3e groupe
   Pourquoi : Verbe en -er (autre que aller) : 1er groupe.

2. Le verbe « finir » est du ___.
   Choix : 1er groupe / **2e groupe** / 3e groupe
   Pourquoi : « Nous finissons » : 2e groupe.

3. Le verbe « partir » est du ___.
   Choix : 1er groupe / 2e groupe / **3e groupe**
   Pourquoi : « Nous partons », pas « partissons » : 3e groupe.

4. Le verbe « aller » est du ___.
   Choix : 1er groupe / 2e groupe / **3e groupe**
   Pourquoi : « Aller » finit en -er, mais il est très irrégulier (je vais, j'irai) : c'est un verbe du 3e groupe.

5. Le verbe « grandir » est du ___.
   Choix : 1er groupe / **2e groupe** / 3e groupe
   Pourquoi : « Nous grandissons » : 2e groupe.

6. Le verbe « choisir » est du ___.
   Choix : 1er groupe / **2e groupe** / 3e groupe
   Pourquoi : « Nous choisissons » : 2e groupe.

7. Le verbe « prendre » est du ___.
   Choix : 1er groupe / 2e groupe / **3e groupe**
   Pourquoi : Verbe en -re : 3e groupe.

8. Tri : 2e ou 3e groupe ? Dites « nous … » : entendez-vous -issons ?
   Colonnes : 2e groupe | 3e groupe
   - réussir → 2e groupe
   - dormir → 3e groupe
   - obéir → 2e groupe
   - venir → 3e groupe
   - applaudir → 2e groupe
   - ouvrir → 3e groupe
   Pourquoi : Nous réussissons, obéissons, applaudissons → 2e groupe. Nous dormons, venons, ouvrons → 3e groupe.

## Exercices avancés

   Choix : 1er groupe / 2e groupe / **3e groupe**

   Choix : 1er groupe / 2e groupe / **3e groupe**
   Pourquoi : « Nous offrons » : 3e groupe, même s'il se conjugue au présent comme un verbe en -er (j'offre).
