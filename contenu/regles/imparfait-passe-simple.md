# Imparfait ou passé simple dans un récit

Identifiant : imparfait-passe-simple
Niveau : collège
Résumé : Il pleuvait (le décor) quand, soudain, le téléphone sonna (l'action).

## Analyse

Décision demandée : choisir entre imparfait et passé simple dans un récit au passé.
Cas de base
  1. Imparfait : le décor, la description, l'action en cours, l'habitude
     (il pleuvait, chaque matin il prenait le bus).
  2. Passé simple : les actions ponctuelles, soudaines ou qui se succèdent
     (soudain, le téléphone sonna ; il entra et s'assit).
Cas particuliers et pièges
  3. Mots repères : soudain, tout à coup, ce jour-là → passé simple ;
     chaque jour, autrefois, souvent, pendant que → imparfait.
  4. Action en cours interrompue par une autre : imparfait + passé simple
     (il traversait la rue quand une voiture surgit).
  5. On n'exerce que des phrases où les repères rendent le choix évident.
Niveau : collège.

## En bref

Dans un récit au passé :
- **imparfait** pour le **décor** et les **habitudes** : il **pleuvait** ; chaque matin, il **prenait** le bus ;
- **passé simple** pour les **actions** qui font avancer l'histoire : soudain, le téléphone **sonna**.

## Fiche

**L'imparfait** décrit ce qui dure ou se répète :
- le **décor**, la description : la maison **était** grande ; le soleil **brillait** ;
- une action **en cours** : pendant qu'il **lisait**…
- une **habitude** : chaque matin, il **prenait** le bus.

**Le passé simple** raconte les **actions** qui font avancer l'histoire :
- une action **soudaine** : tout à coup, un chien **aboya** ;
- des actions **qui se suivent** : elle ouvrit la porte, **entra** et s'assit.

**Le test** : demandez-vous si c'est le décor (imparfait) ou un événement (passé simple).

**Les pièges** :
- Les mots **soudain, tout à coup, ce jour-là** annoncent souvent le passé simple.
- Les mots **chaque jour, autrefois, souvent, pendant que** annoncent l'imparfait.

## Pour aller plus loin

- Une action **en cours** est souvent interrompue par une action **soudaine** : il traversait la rue quand une voiture **surgit**.
- Une **cause** ou une **circonstance** se met à l'imparfait : comme il **faisait** froid, il mit son manteau.

## Exercices essentiels

1. Il pleuvait quand, soudain, le téléphone [sonnait → sonna].
   Pourquoi : « Soudain » : une action brève qui fait avancer le récit, passé simple.

2. Chaque matin, il [prit → prenait] le bus de huit heures.
   Pourquoi : « Chaque matin » : une habitude, imparfait.

3. Le soleil [brilla → brillait] et les oiseaux chantaient.
   Pourquoi : Le décor (comme « chantaient ») : imparfait.

4. Elle ouvrit la porte, [entrait → entra] et s'assit.
   Pourquoi : Des actions qui se suivent : passé simple.

5. Pendant qu'il [lut → lisait], sa sœur dessinait.
   Pourquoi : « Pendant que » : une action en cours, imparfait.

6. Autrefois, nous [allâmes → allions] à la mer tous les étés.
   Pourquoi : « Autrefois, tous les étés » : une habitude, imparfait.

7. Tout à coup, un chien [aboyait → aboya].
   Pourquoi : « Tout à coup » : une action soudaine, passé simple.

8. La maison [fut → était] grande et silencieuse.
   Pourquoi : Une description : imparfait.

9. Il faisait nuit ; soudain, une lumière s'alluma.
   Pourquoi : Correct : le décor à l'imparfait, l'action soudaine au passé simple.

10. Ce jour-là, il ___ trois fois à la porte.
    Choix : **frappa** / frappait
    Pourquoi : « Ce jour-là » : un événement précis, passé simple.

11. Tri : imparfait ou passé simple ?
    Colonnes : imparfait (décor, habitude) | passé simple (action)
    - Il faisait beau. → imparfait (décor, habitude)
    - Soudain, il cria. → passé simple (action)
    - Chaque soir, elle lisait. → imparfait (décor, habitude)
    - Il se leva et partit. → passé simple (action)
    - La rue était calme. → imparfait (décor, habitude)
    - Tout à coup, la porte claqua. → passé simple (action)
    Pourquoi : Le décor et les habitudes : imparfait. Les événements soudains ou qui se suivent : passé simple.

## Exercices avancés

12. Il [marchait → marcha] une heure, puis il s'arrêta.
    Pourquoi : Des actions qui se suivent (puis il s'arrêta) : passé simple.

13. Comme il [fit → faisait] froid, il mit son manteau.
    Pourquoi : Une circonstance, la cause : imparfait.

14. Au moment où il [traversa → traversait] la rue, une voiture surgit.
    Pourquoi : Une action en cours, interrompue par une autre : imparfait.

15. Les enfants jouaient dans la cour quand la cloche sonna.
    Pourquoi : Correct : l'action en cours à l'imparfait, l'événement au passé simple.

16. Tous les dimanches, ils ___ chez leur grand-mère.
    Choix : **dînaient** / dînèrent
    Pourquoi : « Tous les dimanches » : une habitude, imparfait.

17. Il [éteignait → éteignit] la lampe, ferma les yeux et s'endormit.
    Pourquoi : Trois actions qui se suivent : passé simple.
