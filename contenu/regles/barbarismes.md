# Les barbarismes : formes déformées à éviter

Identifiant : barbarismes
Niveau : supérieur
Résumé : Ils croient (et non croivent), quand même (et non comme même), pécuniaire (et non pécunier).

## Analyse

Décision demandée : remplacer un mot ou une forme déformés par la forme correcte.
Cas de base
  1. Formes verbales qui n'existent pas : ils croivent → croient ; ils voyent → voient ;
     il faut que je vais → que j'aille ; ils extraiyent → extraient.
  2. Mots déformés : comme même → quand même ; pécunier → pécuniaire ;
     en définitif → en définitive ; un espèce de → une espèce de ; aéropage → aréopage.
  3. Confusion de construction : je m'en rappelle → je m'en souviens (ou je me le rappelle).
Cas particuliers et pièges
  4. Barbarismes déjà vus ailleurs (rouvrir, obnubilé, indemne, dilemme) : règle
     « Constructions fautives ».
Niveau : supérieur.

## En bref

Un **barbarisme** est un mot déformé ou une forme qui n'existe pas :
- ils croivent → ils **croient** ; il faut que je vais → que j'**aille** ;
- comme même → **quand même** ; pécunier → **pécuniaire** ; en définitif → **en définitive** ;
- un espèce de → **une** espèce de.

## Fiche

**Formes verbales qui n'existent pas** :
- ils croivent → ils **croient** ; ils voyent → ils **voient** ;
- il faut que je vais → il faut que j'**aille** ;
- je m'en rappelle → je m'en **souviens** (ou je me le **rappelle** : on se rappelle quelque chose).

**Mots déformés** :
- comme même → **quand même** ;
- pécunier → **pécuniaire** (qui concerne l'argent) ;
- en définitif → **en définitive** (finalement) ;
- un espèce de → **une** espèce de (« espèce » est féminin) ;
- aéropage → **aréopage** (une assemblée de personnes savantes).

**Le test** : en cas de doute, cherchez le mot dans un dictionnaire : un barbarisme n'y figure pas.

## Pour aller plus loin

- D'autres barbarismes sont traités dans « Constructions fautives » : rouvrir (et non réouvrir), obnubilé, indemne, dilemme.
- « Pécuniaire » est le même au masculin et au féminin : un problème **pécuniaire**, une aide **pécuniaire**.

## Exercices essentiels

1. Ils [croivent → croient] tout ce qu'on leur dit.
   Pourquoi : Le verbe croire fait « ils croient ».

2. Il pleut, mais je sors [comme même → quand même].
   Pourquoi : L'expression est « quand même ».

3. Il a des soucis [pécuniers → pécuniaires].
   Pourquoi : L'adjectif est « pécuniaire », au masculin comme au féminin.

4. [En définitif → En définitive], nous avons pris la bonne décision.
   Pourquoi : La locution est « en définitive » (finalement).

5. C'est [un espèce → une espèce] de chapeau rond.
   Pourquoi : « Espèce » est féminin : « une espèce de ».

6. Il faut que [je vais → j'aille] à la banque.
   Pourquoi : Après « il faut que », subjonctif du verbe aller : « que j'aille ».

7. Ils [voyent → voient] la mer de leur fenêtre.
   Pourquoi : Le verbe voir fait « ils voient ».

8. Ton anniversaire ? Je m'en [rappelle → souviens] très bien.
   Pourquoi : On se souvient DE quelque chose (d'où « en ») ; on se rappelle quelque chose (sans « de »).
   Aussi accepté : Je me le rappelle

9. Ils croient qu'il viendra quand même.
   Pourquoi : Correct : « ils croient », « quand même ».

10. Il a reçu une aide ___.
    Choix : **pécuniaire** / pécunière / pécunier
    Pourquoi : L'adjectif est « pécuniaire ».

11. Tri : forme correcte ou barbarisme ?
    Colonnes : barbarisme | forme correcte
    - comme même → barbarisme
    - quand même → forme correcte
    - ils croivent → barbarisme
    - ils croient → forme correcte
    - en définitif → barbarisme
    - en définitive → forme correcte
    Pourquoi : Comme même, croivent, en définitif sont des formes déformées.

## Exercices avancés

12. Un [aéropage → aréopage] de savants a examiné la question.
    Pourquoi : Le mot est « aréopage » (une assemblée de savants).

13. Il faut que tu [vas → ailles] voir le médecin.
    Pourquoi : Après « il faut que », subjonctif : « que tu ailles ».

14. Ces machines [extraiyent → extraient] le charbon.
    Pourquoi : Le verbe extraire fait « ils extraient ».

15. C'est une espèce de grand oiseau blanc.
    Pourquoi : Correct : « espèce » est féminin, « une espèce de ».

16. Je ne sais pas, mais j'irai ___.
    Choix : **quand même** / comme même
    Pourquoi : L'expression est « quand même ».

17. Cet accord a des conséquences [pécunières → pécuniaires].
    Pourquoi : L'adjectif est « pécuniaire », même au féminin : « pécuniaires ».
