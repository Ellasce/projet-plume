# Infinitif ou participe passé : -er, -é, -ez

Identifiant : infinitif-participe
Niveau : lycée
Résumé : Manger, mangé ou mangez ? Le test du verbe « prendre ».

## Fiche

Les verbes en **-er** se prononcent pareil à l'infinitif (**-er**), au participe passé (**-é**) et à la 2e personne du pluriel (**-ez**).

**L'astuce** : remplacez le verbe par un verbe comme **prendre**, **vendre** ou **mordre**, qui ne se prononce pas pareil.
- Si vous entendez **prendre** → infinitif en **-er**.
- Si vous entendez **pris** → participe passé en **-é**.
- Si le sujet est **vous** → **-ez**.

> Il faut appeler (prendre) le médecin.
> Elle a oublié (pris) ses clés.
> Vous parlez trop vite.

**Repères** : après une préposition (à, de, pour, sans…) ou après un autre verbe conjugué, on a presque toujours l'infinitif. Après **avoir** ou **être**, on a le participe passé.

## Pour aller plus loin

- Après un verbe de perception ou « laisser », on emploie l'infinitif : j'ai entendu les enfants **chanter**, il s'est laissé **tenter**.
- Un participe employé seul s'accorde comme un adjectif : les clés **oubliées**.

## Exercices essentiels

1. Il faut [appelé → appeler] le médecin avant midi.
   Pourquoi : « Il faut prendre » : on entend l'infinitif, donc « appeler ».

2. Elle a [oublier → oublié] ses clés dans la voiture.
   Pourquoi : Après l'auxiliaire avoir : « elle a pris » → participe passé « oublié ».

3. Nous sommes allés nous [promené → promener] au bord du lac.
   Pourquoi : « Allés nous prendre… » : après le verbe aller, infinitif « promener ».

4. Vous [parlé → parlez] trop vite pour moi.
   Pourquoi : Le sujet est « vous » : terminaison « -ez ».

5. Le dossier [envoyer → envoyé] hier n'est jamais arrivé.
   Pourquoi : « Le dossier pris hier » : participe passé employé comme adjectif, « envoyé ».

6. Pensez à ___ vos documents avant la réunion.
   Choix : **imprimer** / imprimé / imprimez
   Pourquoi : « Pensez à prendre » : après la préposition « à », infinitif.

7. Le colis a été ___ ce matin.
   Choix : livrer / **livré** / livrez
   Pourquoi : « A été pris » : participe passé après l'auxiliaire être.

8. Tri : Quelle terminaison faut-il ? Pensez au test du verbe « prendre ».
   Colonnes : -er (infinitif) | -é (participe)
   - Il faut appel… le médecin. → -er (infinitif)
   - Elle a oubli… ses clés. → -é (participe)
   - Le colis a été livr… hier. → -é (participe)
   - Pensez à imprim… vos documents. → -er (infinitif)
   - Je viens de termin… mon rapport. → -er (infinitif)
   - Une porte ferm… à clé. → -é (participe)
   Pourquoi : On entend « prendre » → -er ; on entend « pris » → -é.

9. J'ai eu du mal à [passé → passer] le cap.
   Pourquoi : Après la préposition « à » : infinitif (j'ai eu du mal à prendre).
   Source : LanguageTool (A_INFINITIF[5]#1)

10. Il vaut mieux [arrivé → arriver] en avance.
   Pourquoi : « Il vaut mieux prendre » : infinitif « arriver ».
   Source : LanguageTool (CONFUSION_E_ER[24]#0)

11. Je ne veux pas [changé → changer] d'école.
   Pourquoi : Après le verbe « vouloir » : infinitif (je ne veux pas prendre).
   Source : LanguageTool (FAIRE_VPPA[1]#0)

## Exercices avancés

12. Il commence à travailler à huit heures.
   Pourquoi : Correct : après la préposition « à », l'infinitif « travailler ».

13. Avant de signer, lisez attentivement le contrat.
   Pourquoi : Correct : « lisez » est à l'impératif, 2e personne du pluriel.

14. J'ai entendu les enfants [chanté → chanter] dans le couloir.
   Pourquoi : Après un verbe de perception (entendre, voir), on emploie l'infinitif : « entendu les enfants prendre ».

15. Il s'est laissé [tenté → tenter] par une dernière part de gâteau.
   Pourquoi : « Se laisser » + infinitif : « il s'est laissé prendre » → « tenter ».

16. Ces documents, il faut les [envoyé → envoyer] avant vendredi.
   Pourquoi : « Il faut les prendre » : infinitif, malgré le pronom « les » placé avant.

17. Les clés [oublier → oubliées] sur la table sont à moi.
   Pourquoi : « Les clés prises sur la table » : participe passé employé comme adjectif, accordé avec « les clés ».

18. Après avoir mangé, nous sommes allés nous promener.
   Pourquoi : Correct : après « avoir », le participe passé (mangé) ; après « allés nous », l'infinitif (promener).

19. Léo s'est fait [grondé → gronder] par son père.
   Pourquoi : Après « se faire », on emploie l'infinitif : « s'est fait prendre » → « gronder ».

20. Il a, par exemple, [abandonner → abandonné].
   Pourquoi : Après l'auxiliaire avoir : participe passé (il a pris) → « abandonné ».
   Source : LanguageTool (ETRE_VPPA_OU_ADJ[37]#0)

21. Ton problème a l'air [compliquer → compliqué].
   Pourquoi : « A l'air pris » : participe passé employé comme adjectif, « compliqué ».
   Source : LanguageTool (CONFUSION_INF_PPA[1]#0)
