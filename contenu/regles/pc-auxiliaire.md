# Passé composé : être ou avoir ?

Identifiant : pc-auxiliaire
Niveau : collège
Résumé : Presque toujours avoir ; être pour certains verbes de mouvement et les verbes pronominaux.

## Analyse

Décision demandée : choisir l'auxiliaire du passé composé (être ou avoir).
Cas de base
  1. La plupart des verbes se conjuguent avec avoir (j'ai mangé, il a fini).
  2. Avec être : une quinzaine de verbes (aller, venir, arriver, partir, entrer, sortir, monter,
     descendre, tomber, rester, naître, mourir, devenir, retourner, passer, revenir…).
  3. Avec être : tous les verbes pronominaux (je me suis levé).
Cas particuliers et pièges
  4. Verbes être/avoir selon le sens : monter, descendre, sortir, rentrer, passer, retourner
     prennent avoir quand ils ont un COD (j'ai sorti la poubelle ; je suis sorti).
  5. Les verbes être et avoir eux-mêmes : j'ai été, j'ai eu.
  6. Erreurs fréquentes : « il a tombé », « je m'ai trompé », « elle a resté ».
Hors sujet : l'accord du participe passé (règles du thème Accords).
Niveau : collège.

## En bref

- La plupart des verbes se conjuguent avec **avoir** : j'**ai** mangé.
- Quelques verbes de mouvement ou de changement d'état prennent **être** : je **suis** allé, il **est** tombé, elle **est** née.
- Les verbes **pronominaux** prennent toujours **être** : je **me suis** trompé.

## Fiche

- La plupart des verbes se conjuguent avec **avoir** : j'**ai** mangé, il **a** fini, nous **avons** couru.
- Une quinzaine de verbes prennent **être** : aller, venir, revenir, arriver, partir, entrer, sortir, monter, descendre, tomber, rester, retourner, naître, mourir, devenir, passer.
> elle **est** partie, ils **sont** restés, je **suis** tombé
- Les verbes **pronominaux** (se lever, se tromper, s'amuser…) prennent **toujours être** : je **me suis** levé.

**Les pièges** :
- On entend souvent « il a tombé » ou « je m'ai trompé » : il faut dire **il est tombé**, **je me suis trompé**.
- **être** et **avoir** eux-mêmes se conjuguent avec avoir : j'**ai** été malade, j'**ai** eu peur.

## Pour aller plus loin

- **monter, descendre, sortir, rentrer, passer, retourner** prennent **avoir** quand ils sont suivis d'un complément d'objet (on peut demander « quoi ? ») :
> Je **suis** sorti. / J'**ai** sorti **la poubelle**.
> Elle **est** montée. / Elle **a** monté **les valises**.

## Exercices essentiels

1. Il [a → est] tombé dans l'escalier.
   Pourquoi : « Tomber » se conjugue avec être : « il est tombé ».

2. Je [m'ai → me suis] trompé de chemin.
   Pourquoi : Verbe pronominal (se tromper) : toujours avec être, « je me suis trompé ».

3. Elle [a → est] restée chez elle toute la journée.
   Pourquoi : « Rester » se conjugue avec être.

4. Nous [sommes → avons] mangé une pizza.
   Pourquoi : « Manger » se conjugue avec avoir, comme la plupart des verbes.

5. Ils [ont → sont] partis en vacances hier.
   Pourquoi : « Partir » se conjugue avec être.

6. Mon grand-père [a → est] né en 1950.
   Pourquoi : « Naître » se conjugue avec être.

7. Vous [êtes → avez] fini vos devoirs ?
   Pourquoi : « Finir » se conjugue avec avoir.

8. Les enfants se [ont → sont] bien amusés.
   Pourquoi : Verbe pronominal (s'amuser) : avec être.

9. Il est arrivé en retard, mais il a vite rattrapé son retard.
   Pourquoi : Correct : « arriver » prend être ; « rattraper » prend avoir.

10. Elle ___ venue me voir.
    Choix : a / **est**
    Pourquoi : « Venir » se conjugue avec être.

11. Tri : être ou avoir au passé composé ?
    Colonnes : avoir | être
    - manger → avoir
    - aller → être
    - courir → avoir
    - mourir → être
    - dormir → avoir
    - devenir → être
    Pourquoi : Aller, mourir, devenir font partie des verbes qui prennent être ; les autres prennent avoir.

## Exercices avancés

12. [Je suis → J'ai] sorti la poubelle ce matin.
    Pourquoi : « Sortir » a un complément (la poubelle) : il se conjugue avec avoir.

13. Elle [a → est] montée au grenier.
    Pourquoi : Sans complément d'objet, « monter » se conjugue avec être.

14. Il [est → a] descendu les cartons à la cave.
    Pourquoi : « Descendre » a un complément (les cartons) : avec avoir.

15. [Je suis → J'ai] été très malade l'hiver dernier.
    Pourquoi : « Être » se conjugue avec avoir : « j'ai été ».

16. Nous [sommes → avons] eu de la chance.
    Pourquoi : « Avoir » se conjugue avec avoir : « nous avons eu ».

17. Ils ___ passé leurs vacances en Bretagne.
    Choix : **ont** / sont
    Pourquoi : « Passer » a un complément (leurs vacances) : avec avoir.

18. Elle est rentrée tard et a rentré la voiture au garage.
    Pourquoi : Correct : « rentrer » sans complément prend être ; avec un complément (la voiture), il prend avoir.

19. Elle [a → est] devenue médecin.
    Pourquoi : « Devenir » se conjugue avec être.
