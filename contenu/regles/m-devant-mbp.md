# m devant m, b, p

Identifiant : m-devant-mbp
Niveau : collège
Résumé : Emporter, ombre, important : devant m, b ou p, on écrit m au lieu de n.

## Analyse

Décision demandée : écrire m ou n devant une consonne (son « an », « on », « in »).
Cas de base
  1. Devant m, b, p, on écrit m : emporter, ombre, important, emmener, immense.
  2. Devant les autres consonnes, on écrit n : contre, intéressant, chanter.
Cas particuliers et pièges
  3. Exceptions : bonbon, bonbonne, embonpoint, néanmoins (n devant b ou m).
  4. Devant m, cela fait souvent deux m : emmener, immense, immobile.
Niveau : collège.

## En bref

- Devant **m, b, p**, on écrit **m** : e**m**porter, o**m**bre, i**m**portant.
- Partout ailleurs, on écrit **n** : co**n**tre, i**n**téressant.
- Exceptions : bo**n**bon, embo**n**point, néa**n**moins.

## Fiche

- Devant les lettres **m**, **b** et **p**, le son « an », « on » ou « in » s'écrit avec un **m** : e**m**porter, e**m**brasser, o**m**bre, ta**m**bour, i**m**portant, co**m**poser.
- Devant toutes les autres consonnes, il s'écrit avec un **n** : co**n**tre, i**n**téressant, cha**n**ter.

**Le test** : regardez la lettre qui suit. **m, b, p** → **m**.
> e?porter → p après → **emporter**.
> co?tre → t après → **contre**.

**Les pièges** :
- Devant un **m**, on obtient souvent deux m : e**mm**ener, i**mm**ense, i**mm**obile.
- Trois exceptions courantes : **bonbon**, **embonpoint**, **néanmoins**.

## Pour aller plus loin

- **bonbonne** suit **bonbon** : un n devant b.
- **néanmoins** garde le n de « néant ».

## Exercices essentiels

1. Il faut [enporter → emporter] un parapluie.
   Pourquoi : Devant p : m, « emporter ».

2. Ce rendez-vous est très [inportant → important].
   Pourquoi : Devant p : m, « important ».

3. Le chat dort à l'[onbre → ombre].
   Pourquoi : Devant b : m, « ombre ».

4. Elle aime [conposer → composer] des chansons.
   Pourquoi : Devant p : m, « composer ».

5. Le [tanbour → tambour] résonne dans la rue.
   Pourquoi : Devant b : m, « tambour ».

6. Il est [inpossible → impossible] d'entrer.
   Pourquoi : Devant p : m, « impossible ».

7. Elle a ouvert un [conpte → compte] en banque.
   Pourquoi : Devant p : m, « compte ».

8. J'ai [enmené → emmené] mon frère au parc.
   Pourquoi : Devant m : m, d'où deux m, « emmené ».

9. Il a acheté des bonbons et une lampe.
   Pourquoi : Correct : « bonbon » est une exception (n devant b) ; « lampe » suit la règle (m devant p).

10. Il est ___ de mentir à sa sœur.
    Choix : **impossible** / inpossible
    Pourquoi : Devant p : m.

11. Tri : m ou n ?
    Colonnes : m | n
    - o…bre → m
    - co…tre → n
    - ca…pagne → m
    - i…téressant → n
    - e…mener → m
    - bo…bon → n
    Pourquoi : Devant m, b, p : m (ombre, campagne, emmener). Ailleurs : n (contre, intéressant). « Bonbon » est une exception.

## Exercices avancés

12. Les enfants adorent les [bombons → bonbons].
    Pourquoi : « Bonbon » est une exception : n devant b.

13. Avec l'âge, il a pris de l'[enbonpoint → embonpoint].
    Pourquoi : « Em- » devant b, puis « -bon- » avec un n : « embonpoint » est une exception.

14. Il est fatigué ; [néammoins → néanmoins], il continue.
    Pourquoi : « Néanmoins » est une exception : n devant m.

15. Ils habitent une [inmense → immense] maison.
    Pourquoi : Devant m : m, d'où deux m, « immense ».

16. Le pompier a emmené l'enfant à l'ombre.
    Pourquoi : Correct : « emmené » (m devant m), « ombre » (m devant b).

17. Ils se sont ___ dans le parc.
    Choix : **embrassés** / enbrassés
    Pourquoi : Devant b : m, « embrassés ».
