# Le pluriel des noms composés

Identifiant : noms-composes
Niveau : lycée
Résumé : Des coffres-forts, des arcs-en-ciel, des tire-bouchons : seuls les noms et les adjectifs s'accordent.

## Analyse

Décision demandée : mettre au pluriel un nom composé avec trait d'union.
Cas de base
  1. Seuls les **noms** et les **adjectifs** peuvent prendre la marque du pluriel ;
     les verbes, les adverbes et les prépositions restent invariables.
  2. nom + adjectif, adjectif + nom, nom + nom : les deux s'accordent
     (des coffres-forts, des beaux-frères, des choux-fleurs).
  3. nom + préposition + nom : seul le premier s'accorde (des arcs-en-ciel, des chefs-d'œuvre).
  4. verbe + nom : seul le nom peut s'accorder (des tire-bouchons).
  5. mot invariable + nom : seul le nom s'accorde (des sous-marins, des arrière-pensées).
Cas particuliers et pièges
  6. Nom complément sans préposition : des timbres-poste (pour la poste).
  7. Noms composés sans trait d'union : des pommes de terre.
  8. Rectifications de 1990 : verbe + nom et préposition + nom suivent la règle des mots simples
     (un compte-goutte, des compte-gouttes ; des après-midis). On n'exerce que des cas
     où les deux usages donnent la même réponse.
Niveau : lycée.

## En bref

Dans un nom composé, **seuls les noms et les adjectifs** prennent la marque du pluriel :
- des **coffres-forts** (nom + adjectif), des **choux-fleurs** (nom + nom) ;
- des **arcs-en-ciel** (seul le premier nom : « arcs de ciel ») ;
- des **tire-bouchons**, des **sous-marins** (le verbe et « sous » ne changent pas).

## Fiche

**La règle** : seuls les **noms** et les **adjectifs** s'accordent. Les **verbes**, **adverbes** et **prépositions** ne changent jamais.

- **nom + adjectif** ou **adjectif + nom** : les deux s'accordent → des coffre**s**-fort**s**, des beau**x**-frère**s**.
- **nom + nom** : les deux s'accordent → des chou**x**-fleur**s**.
- **nom + préposition + nom** : seul le premier nom s'accorde → des arc**s**-en-ciel, des chef**s**-d'œuvre.
- **verbe + nom** : le verbe ne change pas → des tire-bouchon**s**.
- **mot invariable + nom** : seul le nom s'accorde → des sous-marin**s**, des arrière-pensée**s**.

**Le test** : demandez-vous ce qu'est chaque mot (nom, adjectif, verbe, préposition).

**Les pièges** :
- **arc-en-ciel** : on voit plusieurs **arcs**, pas plusieurs ciels → des arcs-en-ciel.
- **tire-bouchon** : « tire » est un verbe, il reste invariable → des tire-bouchons.

## Pour aller plus loin

- Un nom complément sans préposition reste au singulier : des **timbres-poste** (des timbres pour la poste).
- Sans trait d'union, chaque mot suit sa règle : des **pommes de terre**.
- Les **rectifications de 1990** simplifient certains cas (des après-midis, un compte-goutte, des compte-gouttes). Les deux usages sont acceptés.

## Exercices essentiels

1. La banque possède deux [coffre-forts → coffres-forts].
   Pourquoi : Nom + adjectif : les deux s'accordent, « coffres-forts ».

2. J'ai acheté des [choux-fleur → choux-fleurs].
   Pourquoi : Nom + nom : les deux s'accordent, « choux-fleurs ».

3. Il a vu deux [arcs-en-ciels → arcs-en-ciel].
   Pourquoi : Nom + préposition + nom : seul le premier s'accorde (des arcs de ciel).

4. Ce musée expose des [chef-d'œuvres → chefs-d'œuvre].
   Pourquoi : Nom + préposition + nom : seul « chef » s'accorde.

5. Range les [tires-bouchons → tire-bouchons].
   Pourquoi : « Tire » est un verbe : il ne change pas. Seul le nom prend un s.

6. Les [sous-marin → sous-marins] ont plongé.
   Pourquoi : « Sous » est invariable ; le nom « marin » s'accorde.

7. J'avoue avoir des [arrières-pensées → arrière-pensées].
   Pourquoi : « Arrière » est ici un adverbe, invariable ; « pensées » s'accorde.

8. Mes deux [beau-frères → beaux-frères] sont venus.
   Pourquoi : Adjectif + nom : les deux s'accordent, « beaux-frères ».

9. Mes beaux-parents ont deux chiens-loups.
   Pourquoi : Correct : adjectif + nom (beaux-parents) et nom + nom (chiens-loups), tous accordés.

10. Il y a des ___ dans le ciel.
    Choix : **arcs-en-ciel** / arc-en-ciels / arcs-en-ciels
    Pourquoi : Seul le premier nom s'accorde : « arcs-en-ciel ».

11. Tri : combien de mots s'accordent ?
    Colonnes : les deux mots | un seul mot
    - coffre-fort → les deux mots
    - arc-en-ciel → un seul mot
    - chou-fleur → les deux mots
    - tire-bouchon → un seul mot
    - beau-frère → les deux mots
    - sous-marin → un seul mot
    Pourquoi : Nom + adjectif, adjectif + nom, nom + nom : les deux. Avec une préposition, un verbe ou un adverbe : un seul.

## Exercices avancés

12. Elle collectionne les [timbres-postes → timbres-poste].
    Pourquoi : « Poste » est un complément (des timbres pour la poste) : il reste au singulier.

13. Nous avons épluché des [pommes-de-terre → pommes de terre].
    Pourquoi : « Pomme de terre » s'écrit sans trait d'union ; seul « pommes » s'accorde.

14. Nos [grand-pères → grands-pères] jouaient ensemble.
    Pourquoi : Adjectif + nom : les deux s'accordent, « grands-pères ».

15. Il a les avant-bras couverts de coups de soleil.
    Pourquoi : Correct : « avant » est invariable, et « bras » se termine déjà par s.

16. Les [wagon-lits → wagons-lits] sont en tête du train.
    Pourquoi : Nom + nom : les deux s'accordent, « wagons-lits ».

17. Ces deux tableaux sont des ___.
    Choix : **chefs-d'œuvre** / chef-d'œuvres / chefs-d'œuvres
    Pourquoi : Seul le premier nom s'accorde : « chefs-d'œuvre ».
