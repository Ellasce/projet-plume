# leur ou leurs

Identifiant : leur-leurs
Niveau : collège
Résumé : Devant un verbe, jamais de s. Devant un nom, on regarde le nom.

## Analyse

Décision demandée : écrire « leur » ou « leurs ».
Cas de base
  1. leur + verbe = pronom personnel (à eux, à elles) : invariable. Test : remplacer par « lui ».
  2. leur(s) + nom = déterminant possessif : il s'accorde avec le nom (leur maison, leurs enfants).
Cas particuliers et pièges
  3. Pronom placé après le verbe à l'impératif : donne-leur.
  4. « le leur », « la leur », « les leurs » : pronom possessif.
  5. Un seul objet pour chacun : singulier ou pluriel selon le sens (ils ont mis leur manteau).
  6. Pronom dans une question ou une négation : ne leur a-t-il pas…
À éviter dans les exercices : « leur fils » (le nom ne montre pas son nombre).
Niveau : collège.

## En bref

- Devant un **verbe**, **leur** ne prend **jamais de s** : je **leur** parle. On peut dire **lui**.
- Devant un **nom**, on regarde le nom : **leur** maison (une seule), **leurs** enfants (plusieurs).

> Je leur écris. → Je lui écris ✔ → **leur**
> Ils rangent leurs affaires. → « affaires » est au pluriel → **leurs**

## Fiche

- Devant un **verbe**, **leur** est un pronom (« à eux », « à elles »). Il ne prend **jamais de s**. On peut le remplacer par **lui** : je **leur** parle (je lui parle).
- Devant un **nom**, **leur** est un déterminant. Il s'accorde avec ce nom : **leur** maison (une maison), **leurs** enfants (plusieurs enfants).

**Le test** : regardez le mot qui suit.
> Je leur écris. → verbe (je lui écris) → **leur**
> Ils rangent leurs affaires. → nom au pluriel → **leurs**
> Ils vendent leur voiture. → nom au singulier → **leur**

**Les pièges** :
- Entre « leur » et le verbe, il peut y avoir un autre petit mot : je **leur** ai dit, il ne **leur** a pas répondu.
- Après un impératif, le pronom se place derrière le verbe : donne-**leur** ce livre.

## Pour aller plus loin

- **le leur, la leur, les leurs** : ce sont des pronoms possessifs. On met un s quand on parle de plusieurs choses : ces livres sont **les leurs**, cette maison est **la leur**.
- Quand chacun possède une seule chose, on écrit souvent le singulier : ils ont mis **leur** manteau.

## Exercices essentiels

1. Nous [leurs → leur] avons donné de l'argent et des vêtements.
   Pourquoi : Devant le verbe (nous lui avons donné) : pronom, jamais de s.
   Source : Tatoeba n° 2826455

2. Je [leurs → leur] ai tout raconté.
   Pourquoi : « Je lui ai tout raconté » : pronom devant le verbe, « leur ».
   Source : Tatoeba n° 3691750

3. Il [leurs → leur] a écrit une lettre.
   Pourquoi : « Il lui a écrit » : pronom devant le verbe, « leur ».
   Source : Tatoeba n° 7492199

4. Elles ont oublié d'éteindre [leur → leurs] micros.
   Pourquoi : Devant le nom « micros », au pluriel : « leurs ».
   Source : Tatoeba n° 12197723

5. Ils ont gardé [leur → leurs] découvertes secrètes.
   Pourquoi : Devant le nom « découvertes », au pluriel : « leurs ».
   Source : Tatoeba n° 11961288

6. Je ne souligne pas [leur → leurs] erreurs.
   Pourquoi : Devant le nom « erreurs », au pluriel : « leurs ».
   Source : Tatoeba n° 1934274

7. Les voisins ont repeint [leurs → leur] maison.
   Pourquoi : Devant le nom « maison », au singulier : « leur ».

8. Mes amis m'ont prêté [leurs → leur] voiture.
   Pourquoi : Devant le nom « voiture », au singulier : « leur ».

9. Je leur ai rendu leurs clés.
   Pourquoi : Correct : « je lui ai rendu » (pronom, sans s), puis « leurs clés » (nom au pluriel).

10. Je ___ téléphone demain.
    Choix : **leur** / leurs
    Pourquoi : « Je lui téléphone » : pronom devant le verbe, jamais de s.

11. Les enfants rangent ___ jouets.
    Choix : leur / **leurs**
    Pourquoi : Devant le nom « jouets », au pluriel.

12. Tri : « leur » ou « leurs » ? Regardez le mot qui suit.
    Colonnes : leur (sans s) | leurs (avec s)
    - Je … parle. → leur (sans s)
    - … chaussures → leurs (avec s)
    - … maison → leur (sans s)
    - Il … a répondu. → leur (sans s)
    - … amis → leurs (avec s)
    - … parents → leurs (avec s)
    Pourquoi : Devant un verbe (je lui parle, il lui a répondu) ou un nom singulier (maison) → « leur ». Devant un nom pluriel → « leurs ».

## Exercices avancés

13. Pourquoi ne [leurs → leur] a-t-il pas pardonné ?
    Pourquoi : « Pourquoi ne lui a-t-il pas pardonné » : pronom devant le verbe, « leur ».
    Source : Tatoeba n° 12067055

14. Ils t'ont rendu ce que tu [leurs → leur] as donné.
    Pourquoi : « Ce que tu lui as donné » : pronom devant le verbe, « leur ».
    Source : Tatoeba n° 8083983

15. Ces livres sont les [leur → leurs].
    Pourquoi : « Les leurs » remplace plusieurs livres : pronom possessif au pluriel.

16. Cette maison est la [leurs → leur].
    Pourquoi : « La leur » remplace une seule maison : singulier.

17. Donne-[leurs → leur] ces documents.
    Pourquoi : « Donne-lui ces documents » : pronom placé après l'impératif, toujours sans s.

18. Ils ont mis leur manteau et leurs gants.
    Pourquoi : Correct : un seul manteau pour chacun (singulier), mais plusieurs gants (pluriel).

19. Les deux sœurs nous ont présenté ___ mère.
    Choix : **leur** / leurs
    Pourquoi : Elles ont une seule mère : nom au singulier, « leur ».

20. Nombreux sont ceux qui font [leur → leurs] achats ici.
    Pourquoi : Devant le nom « achats », au pluriel : « leurs ».
    Source : Tatoeba n° 4579670
