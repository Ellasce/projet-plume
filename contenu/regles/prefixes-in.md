# Les préfixes il-, ir-, im- : illégal, irréel, immobile

Identifiant : prefixes-in
Niveau : lycée
Résumé : Le préfixe in- devient il- devant l, ir- devant r, im- devant m, b, p : d'où illisible, irréel, immobile.

## Analyse

Décision demandée : écrire le préfixe négatif in- et sa consonne devant le mot de base.
Cas de base
  1. in- + l → il- (deux l) : illégal, illisible, illimité.
  2. in- + r → ir- (deux r) : irréel, irrégulier, irresponsable.
  3. in- + m → im- (deux m) : immobile, immortel, immature ; in- + b, p → im- : imbuvable, impossible.
  4. Devant une voyelle ou les autres consonnes : in- simple (inutile, inégal, inconnu).
Cas particuliers et pièges
  5. Pas de double consonne devant une voyelle : inoubliable, inespéré (un seul n).
Niveau : lycée.

## En bref

Le préfixe **in-** (= pas) change devant certaines lettres, et la consonne se **double** :
- devant **l** → **ill-** : **ill**égal ; devant **r** → **irr-** : **irr**éel ; devant **m** → **imm-** : **imm**obile ;
- devant **b, p** → **im-** : **im**buvable, **im**possible ;
- devant une **voyelle** : **in-** seul → **in**utile, **in**oubliable.

## Fiche

Le préfixe **in-** veut dire « pas, le contraire de ». Il s'adapte à la lettre qui suit :
- devant **l** : **il-**, d'où deux l → **ill**égal, **ill**isible, **ill**imité ;
- devant **r** : **ir-**, d'où deux r → **irr**éel, **irr**égulier, **irr**esponsable ;
- devant **m** : **im-**, d'où deux m → **imm**obile, **imm**ortel, **imm**ature ;
- devant **b** et **p** : **im-** → **im**buvable, **im**possible ;
- devant une **voyelle** ou une autre consonne : **in-** → **in**utile, **in**égal, **in**connu.

**Le test** : enlevez le préfixe. « légal » commence par l → **ill**égal.

**Le piège** : devant une voyelle, un seul n : **in**oubliable, **in**espéré, **in**utile.

## Pour aller plus loin

- Le même phénomène se retrouve avec ad- et con- : **acc**ompagner, **coll**aborer, **corr**iger.
- **inhabituel**, **inhumain** : devant un h, in- reste simple.

## Exercices essentiels

1. Cette écriture est [ilisible → illisible].
   Pourquoi : in- + lisible : devant l, « ill- », deux l.

2. Ce verbe est [irégulier → irrégulier].
   Pourquoi : in- + régulier : devant r, « irr- », deux r.

3. Il est resté [imobile → immobile].
   Pourquoi : in- + mobile : devant m, « imm- », deux m.

4. Ce comportement est [ilégal → illégal].
   Pourquoi : in- + légal : « illégal », deux l.

5. Cette scène semble [inréelle → irréelle].
   Pourquoi : in- + réelle : devant r, « irr- ».

6. Il a pris un forfait [ilimité → illimité].
   Pourquoi : in- + limité : « illimité », deux l.

7. Ce conducteur est [iresponsable → irresponsable].
   Pourquoi : in- + responsable : « irresponsable », deux r.

8. Dans ce livre, les héros sont [imortels → immortels].
   Pourquoi : in- + mortels : « immortels », deux m.

9. Ce souvenir est inoubliable, presque irréel.
   Pourquoi : Correct : « inoubliable » (voyelle : un n), « irréel » (deux r).

10. Ce café est ___.
    Choix : **imbuvable** / inbuvable
    Pourquoi : Devant b, in- devient « im- ».

11. Tri : la consonne est-elle doublée ?
    Colonnes : consonne doublée | pas de double consonne
    - in + légal → consonne doublée
    - in + utile → pas de double consonne
    - in + réel → consonne doublée
    - in + égal → pas de double consonne
    - in + mobile → consonne doublée
    - in + connu → pas de double consonne
    Pourquoi : Devant l, r, m, la consonne double (illégal, irréel, immobile). Ailleurs, in- reste simple.

## Exercices avancés

12. C'était un geste [iréfléchi → irréfléchi].
    Pourquoi : in- + réfléchi : « irréfléchi », deux r.

13. Il est encore un peu [imature → immature].
    Pourquoi : in- + mature : « immature », deux m.

14. Ton aide est [iremplaçable → irremplaçable].
    Pourquoi : in- + remplaçable : « irremplaçable », deux r.

15. Ces taches d'encre sont ineffaçables.
    Pourquoi : Correct : devant une voyelle, in- reste simple, un seul n.

16. C'était une dépense ___.
    Choix : **inutile** / innutile
    Pourquoi : Devant une voyelle, un seul n : « inutile ».

17. Cette victoire était [innespérée → inespérée].
    Pourquoi : Devant une voyelle, un seul n : « inespérée ».
