# Le féminin des noms et des adjectifs

Identifiant : feminin
Niveau : collège
Résumé : Sportif → sportive, acteur → actrice, complet → complète : les terminaisons du féminin.

## Analyse

Décision demandée : former le féminin d'un nom ou d'un adjectif.
Cas de base
  1. En général, on ajoute un e : grand → grande.
  2. -er → -ère (boulanger → boulangère) ; -eux → -euse (heureux → heureuse) ;
     -f → -ve (sportif → sportive) ; -teur → -trice (acteur → actrice) ou -teuse (chanteur → chanteuse).
  3. Doublement de la consonne : -el → -elle, -en → -enne, -on → -onne, -et → -ette (gentil → gentille).
Cas particuliers et pièges
  4. -et → -ète pour complet, concret, discret, inquiet, secret.
  5. -c → -che (blanc → blanche) ou -que (public → publique, grec → grecque).
  6. beau, nouveau, vieux → belle, nouvelle, vieille ; devant voyelle au masculin : bel, nouvel, vieil.
  7. Rectifications de 1990 : non concernées ici.
Niveau : collège.

## En bref

- En général, on ajoute un **e** : grand → grand**e**.
- Des terminaisons changent : -er → **-ère**, -eux → **-euse**, -f → **-ve**, -teur → **-trice** ou **-teuse**.
- Certaines consonnes doublent : gentil → genti**lle**, ancien → ancie**nne**, net → ne**tte**.

## Fiche

- En général, on ajoute un **e** : grand → grand**e**, joli → joli**e**.
- **-er** → **-ère** : boulanger → boulang**ère**, cher → ch**ère**.
- **-eux** → **-euse** : heureux → heur**euse**, jaloux → jal**ouse**.
- **-f** → **-ve** : sportif → sporti**ve**, neuf → neu**ve**.
- **-teur** → **-trice** (acteur → act**rice**) ou **-teuse** (chanteur → chant**euse**).
- On **double la consonne** : -el → **-elle** (cruel), -en → **-enne** (ancien), -on → **-onne** (bon), -et → **-ette** (muet), et gentil → genti**lle**.

**Les pièges** :
- **complet, concret, discret, inquiet, secret** font **-ète** : complète, inquiète.
- **blanc** → blan**che** ; **public** → publi**que** ; **grec** → grec**que**.
- **beau, nouveau, vieux** → **belle, nouvelle, vieille**.

## Pour aller plus loin

- Devant un nom masculin qui commence par une voyelle, on dit **bel, nouvel, vieil** : un **bel** arbre, un **vieil** ami. Le féminin est le même : une **belle** journée, une **vieille** maison.
- **frais** → fra**îche** ; **long** → lon**gue** ; **doux** → dou**ce**.

## Exercices essentiels

1. Ma cousine est très [sportif → sportive].
   Pourquoi : -f devient -ve au féminin : « sportive ».

2. Ma tante est [boulangeuse → boulangère].
   Pourquoi : -er devient -ère : « boulangère ».

3. Cette robe est [neuf → neuve].
   Pourquoi : -f devient -ve : « neuve ».

4. La directrice est très [gentil → gentille].
   Pourquoi : « Gentil » double le l au féminin : « gentille ».

5. Ma voisine est [inquiette → inquiète].
   Pourquoi : « Inquiet » fait partie des exceptions en -ète : « inquiète ».

6. C'est une très bonne [acteuse → actrice].
   Pourquoi : « Acteur » fait « actrice » au féminin.

7. Ma sœur est [heureux → heureuse] de sa nouvelle école.
   Pourquoi : -eux devient -euse : « heureuse ».

8. J'ai lu la version [complette → complète].
   Pourquoi : « Complet » fait « complète » (exception en -ète).

9. La chanteuse italienne est vive et curieuse.
   Pourquoi : Correct : chanteur → chanteuse, italien → italienne, vif → vive, curieux → curieuse.

10. C'est une histoire très ___.
    Choix : **ancienne** / anciene / ancièn
    Pourquoi : -en double le n au féminin : « ancienne ».

11. Tri : -ette ou -ète ?
    Colonnes : -ette | -ète
    - net → -ette
    - complet → -ète
    - muet → -ette
    - secret → -ète
    - coquet → -ette
    - inquiet → -ète
    Pourquoi : La plupart des adjectifs en -et doublent le t (nette, muette, coquette). Complet, concret, discret, inquiet, secret font -ète.

## Exercices avancés

12. Elle porte une veste [blanc → blanche].
    Pourquoi : « Blanc » fait « blanche » au féminin.

13. Ils habitent une [vieil → vieille] maison.
    Pourquoi : Le féminin de « vieux » (vieil) est « vieille ».

14. Elle a une amie [grec → grecque].
    Pourquoi : « Grec » fait « grecque » au féminin.

15. Elle rêve de devenir [chanteure → chanteuse].
    Pourquoi : « Chanteur » fait « chanteuse ».

16. Ma chatte est très [jaloux → jalouse].
    Pourquoi : « Jaloux » fait « jalouse ».

17. Cette longue et douce soirée était parfaite.
    Pourquoi : Correct : long → longue, doux → douce, parfait → parfaite.

18. Nous avons passé une [bel → belle] journée.
    Pourquoi : Le féminin de « beau » (bel) est « belle ».
