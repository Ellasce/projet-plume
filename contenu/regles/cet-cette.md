# ce, cet ou cette

Identifiant : cet-cette
Niveau : collège
Résumé : Cet arbre (masculin), cette idée (féminin) : cet et cette se prononcent pareil.

## Analyse

Décision demandée : écrire ce, cet ou cette devant un nom.
Cas de base
  1. cette : devant un nom féminin (cette idée, cette maison).
  2. ce : devant un nom masculin qui commence par une consonne (ce garçon).
  3. cet : devant un nom masculin qui commence par une voyelle ou un h muet (cet arbre, cet hôtel).
  Test : remplacer par « un » ou « une ». Une → cette ; un → ce ou cet.
Cas particuliers et pièges
  4. Noms dont le genre surprend : un horaire, un incendie, une espèce, une erreur.
  5. Adjectif placé avant le nom : cet énorme chien (c'est le mot suivant qui compte).
  6. h aspiré : ce héros, ce hibou (pas de liaison, donc « ce »).
Hors sujet : ces / ses (règle « ce, se, ces, ses »).
Niveau : collège.

## En bref

- **cet** et **cette** se prononcent pareil : regardez le **genre** du nom.
- **une** → **cette** : **cette** idée. **un** → **cet** devant une voyelle (**cet** arbre), sinon **ce** (**ce** garçon).

## Fiche

- **cette** se place devant un nom **féminin** : **cette** idée, **cette** année.
- **cet** se place devant un nom **masculin** qui commence par une **voyelle** ou un **h muet** : **cet** arbre, **cet** hôtel, **cet** été.
- **ce** se place devant un nom **masculin** qui commence par une **consonne** : **ce** garçon.

**Le test** : remplacez par « un » ou « une ».
> Cet arbre → un arbre ✔ → masculin, **cet**.
> Cette idée → une idée ✔ → féminin, **cette**.

**Les pièges** :
- Des noms masculins qu'on croit féminins : **un** horaire, **un** incendie → **cet** horaire, **cet** incendie.
- Des noms féminins qu'on croit masculins : **une** espèce, **une** erreur → **cette** espèce, **cette** erreur.

## Pour aller plus loin

- C'est le **mot qui suit** qui compte : **cet** énorme chien (voyelle), mais **ce** chien.
- Devant un **h aspiré** (pas de liaison), on écrit **ce** : **ce** héros, **ce** hibou.

## Exercices essentiels

1. Regarde [cette → cet] arbre immense.
   Pourquoi : « Un arbre » : masculin, devant une voyelle, « cet ».

2. J'ai lu [cet → cette] histoire hier soir.
   Pourquoi : « Une histoire » : féminin, « cette ».

3. [Ce → Cet] hôtel est complet.
   Pourquoi : « Un hôtel » : masculin, devant un h muet, « cet ».

4. [Cet → Cette] année, nous partons à la mer.
   Pourquoi : « Une année » : féminin, « cette ».

5. Qui est [cette → cet] homme ?
   Pourquoi : « Un homme » : masculin, devant un h muet, « cet ».

6. [Cet → Cette] idée est excellente.
   Pourquoi : « Une idée » : féminin, « cette ».

7. [Cette → Cet] été, il a fait très chaud.
   Pourquoi : « Un été » : masculin, devant une voyelle, « cet ».

8. [Cet → Ce] garçon court très vite.
   Pourquoi : « Un garçon » : masculin, devant une consonne, « ce ».

9. Cet oiseau s'est posé sur cette branche.
   Pourquoi : Correct : « un oiseau » (cet), « une branche » (cette).

10. ___ ordinateur est trop lent.
    Choix : **Cet** / Cette / Ce
    Pourquoi : « Un ordinateur » : masculin, devant une voyelle, « cet ».

11. Tri : cet ou cette ?
    Colonnes : cet | cette
    - ___ arbre → cet
    - ___ affiche → cette
    - ___ hôpital → cet
    - ___ heure → cette
    - ___ ami → cet
    - ___ amie → cette
    Pourquoi : « un » → cet ; « une » → cette.
