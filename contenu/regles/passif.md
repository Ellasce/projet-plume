# La voix passive

Identifiant : passif
Niveau : lycée
Résumé : La lettre a été écrite par ma sœur : à la voix passive, le participe s'accorde avec le sujet.

## Analyse

Décision demandée : former la voix passive et accorder le participe passé.
Cas de base
  1. Voix passive : être (au temps voulu) + participe passé ; le sujet subit l'action
     (la lettre est écrite par ma sœur).
  2. Le participe s'accorde toujours avec le sujet (les voleurs ont été arrêtés).
  3. Le temps est porté par « être » : est écrite (présent), a été écrite (passé composé),
     sera écrite (futur), avait été écrite (plus-que-parfait).
Cas particuliers et pièges
  4. Ne pas confondre avec le passé composé des verbes qui prennent être (il est parti).
  5. Voix pronominale de sens passif : ce plat se mange froid ; le verbe s'accorde avec le sujet.
Niveau : lycée.

## En bref

À la **voix passive**, le sujet **subit** l'action : **être** + participe passé.
> La lettre **a été écrite** par ma sœur. Les résultats **seront publiés** demain.

Le participe **s'accorde avec le sujet**, comme avec être.

## Fiche

À la **voix active**, le sujet fait l'action : ma sœur écrit la lettre.
À la **voix passive**, le sujet **subit** l'action : la lettre **est écrite** par ma sœur.

**Formation** : le verbe **être** au temps voulu + le **participe passé**.
> est écrite (présent), a été écrite (passé composé), sera écrite (futur), avait été écrite (plus-que-parfait)

**L'accord** : le participe passé s'accorde **toujours avec le sujet**.
> Les voleurs ont été **arrêtés**. Elle a été **élue** présidente.

**Le test** : peut-on ajouter « par quelqu'un » ? La lettre est écrite **par** ma sœur → voix passive.

**Le piège** : « il est parti » n'est pas un passif, c'est le passé composé de « partir » (on ne peut pas ajouter « par quelqu'un »).

## Pour aller plus loin

- La **voix pronominale** peut avoir un sens passif : ces fruits **se mangent** crus (ils sont mangés crus) ; le verbe s'accorde avec le sujet.
- Le complément d'agent peut être introduit par **de** avec certains verbes : elle est aimée **de** tous.

## Exercices essentiels

1. La lettre a été [écrit → écrite] par ma sœur.
   Pourquoi : Voix passive : accord avec le sujet « la lettre » : « écrite ».

2. Les voleurs ont été [arrêté → arrêtés] hier.
   Pourquoi : Accord avec le sujet « les voleurs » : « arrêtés ».

3. Les résultats seront [publié → publiés] demain.
   Pourquoi : Accord avec « les résultats » : « publiés ».

4. La décision [sont → est] prise par le directeur.
   Pourquoi : Le sujet est « la décision » (singulier) : « est ».

5. Ces gâteaux ont été [préparé → préparés] par mon père.
   Pourquoi : Accord avec « ces gâteaux » : « préparés ».

6. Elle a été [élu → élue] présidente.
   Pourquoi : Accord avec « elle » : « élue ».

7. Le match sera [retransmise → retransmis] à la télévision.
   Pourquoi : Accord avec « le match » (masculin) : « retransmis ».

8. Les rues sont [nettoyé → nettoyées] chaque matin.
   Pourquoi : Accord avec « les rues » : « nettoyées ».

9. La salle a été décorée par les élèves.
   Pourquoi : Correct : voix passive, accord avec « la salle ».

10. Ces livres ont été ___ par un même auteur.
    Choix : **écrits** / écrit
    Pourquoi : Accord avec « ces livres » : « écrits ».

11. Tri : voix active ou passive ?
    Colonnes : voix active | voix passive
    - Le chat mange la souris. → voix active
    - La souris est mangée par le chat. → voix passive
    - Les élèves ont rangé la salle. → voix active
    - La salle a été rangée. → voix passive
    - Il est parti tôt. → voix active
    - Elle est aimée de tous. → voix passive
    Pourquoi : À la voix passive, le sujet subit l'action (on peut ajouter « par… »). « Il est parti » est un passé composé actif.

## Exercices avancés

12. Ces fruits se [mange → mangent] crus.
    Pourquoi : Voix pronominale à sens passif : accord avec « ces fruits ».

13. Les invités avaient été [prévenu → prévenus] la veille.
    Pourquoi : Accord avec « les invités » : « prévenus ».

14. Les murs seront [repeint → repeints] la semaine prochaine.
    Pourquoi : Accord avec « les murs » : « repeints ».

15. Ce vin se boit frais et se sert à table.
    Pourquoi : Correct : voix pronominale à sens passif, au singulier comme « ce vin ».

16. La porte a été ___ par le vent.
    Choix : **ouverte** / ouvert
    Pourquoi : Accord avec « la porte » : « ouverte ».

17. Les candidates ont été [reçus → reçues] à l'examen.
    Pourquoi : Accord avec « les candidates » (féminin pluriel) : « reçues ».
