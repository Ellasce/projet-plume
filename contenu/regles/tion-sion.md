# Les mots en -tion, -sion, -ssion

Identifiant : tion-sion
Niveau : collège
Résumé : Permettre → permission, décider → décision, ponctuer → ponctuation : le verbe aide à choisir.

## Analyse

Décision demandée : écrire la terminaison -tion, -sion ou -ssion.
Cas de base
  1. -tion est la terminaison la plus fréquente : action, nation, ponctuation, natation.
  2. Le verbe de la même famille aide :
     - verbes en -ettre → -ission (permettre → permission, admettre → admission) ;
     - verbes en -der, -dre, -ser → -sion (décider → décision, comprendre → compréhension,
       diviser → division) ;
     - verbes en -primer, -cuter, -sser → -ssion (exprimer → expression, discuter → discussion).
Cas particuliers et pièges
  3. Après l, r, n, on trouve souvent -sion (version, pension) mais aussi -tion (portion, mention).
  4. -xion (connexion, réflexion) : voir « Les mots souvent mal orthographiés ».
Niveau : collège.

## En bref

- Le plus souvent : **-tion** → ac**tion**, na**tion**, ponctua**tion**.
- Pensez au **verbe** : perme**ttre** → permi**ssion** ; déci**der** → déci**sion** ; discu**ter** → discu**ssion**.

## Fiche

**-tion** est la terminaison la plus fréquente : ac**tion**, na**tion**, ponctua**tion**, nata**tion**, inten**tion**.

**Le verbe de la même famille** aide souvent :
- verbes en **-ettre** → **-ission** : permettre → permi**ssion**, admettre → admi**ssion**, transmettre → transmi**ssion** ;
- verbes en **-der, -dre, -ser** → **-sion** : décider → déci**sion**, comprendre → compréhen**sion**, diviser → divi**sion** ;
- verbes en **-primer, -cuter** → **-ssion** : exprimer → expre**ssion**, discuter → discu**ssion**.

**Le test** : cherchez le verbe (« permettre », « décider »…) avant d'écrire la fin du mot.

## Pour aller plus loin

- Après **l, r, n**, on trouve souvent -sion (ver**sion**, pen**sion**), mais aussi -tion (por**tion**, men**tion**, atten**tion**) : il faut les retenir.
- **-xion** : conne**xion**, réfle**xion**.

## Exercices essentiels

1. Il a obtenu la [permition → permission] de sortir.
   Pourquoi : « Permettre » donne « permission » (-ission).

2. J'ai pris une [décission → décision].
   Pourquoi : « Décider » donne « décision » (-sion).

3. Fais attention à la [ponctuasion → ponctuation].
   Pourquoi : « Ponctuer » donne « ponctuation » (-tion).

4. Il a l'[expretion → expression] d'un enfant heureux.
   Pourquoi : « Exprimer » donne « expression » (-ssion).

5. Nous avons eu une longue [discution → discussion].
   Pourquoi : « Discuter » donne « discussion », avec deux s.

6. La [télévition → télévision] est allumée.
   Pourquoi : « Téléviser » donne « télévision » (-sion).

7. Il a réussi le concours d'[admition → admission].
   Pourquoi : « Admettre » donne « admission » (-ission).

8. Elle fait de la [natassion → natation].
   Pourquoi : « Nager » / « natation » : terminaison la plus courante, -tion.

9. Cette émission présente une invention étonnante.
   Pourquoi : Correct : « émission » (émettre → -ission), « invention » (-tion).

10. Il a de bonnes ___.
    Choix : **intentions** / intensions
    Pourquoi : « Intention » s'écrit avec -tion.

11. Tri : -tion ou -sion ?
    Colonnes : -tion | -sion
    - ac… → -tion
    - ver… → -sion
    - na… → -tion
    - télévi… → -sion
    - créa… → -tion
    - déci… → -sion
    Pourquoi : -tion est le plus fréquent ; décider, téléviser donnent -sion ; version est à retenir.

## Exercices avancés

12. La [compréhention → compréhension] du texte est difficile.
    Pourquoi : « Comprendre » donne « compréhension » (-sion).

13. La [transmition → transmission] des données a échoué.
    Pourquoi : « Transmettre » donne « transmission » (-ission).

14. Mon grand-père touche une [pention → pension].
    Pourquoi : « Pension » s'écrit avec -sion.

15. L'attention du public et la tension montent.
    Pourquoi : Correct : « attention » (-tion), « tension » (-sion).

16. Ce câble supporte une ___ de 220 volts.
    Choix : **tension** / tention
    Pourquoi : « Tension » s'écrit avec -sion.

17. La [répétission → répétition] commence à 18 heures.
    Pourquoi : « Répéter » donne « répétition » (-tion).
