# Tel, tel que, tel quel

Identifiant : tel-tel-que
Niveau : supérieur
Résumé : Des fruits tels que les pommes, une telle chance, des documents laissés tels quels.

## Analyse

Décision demandée : accorder tel et choisir entre tel que et tel quel.
Cas de base
  1. tel devant un nom (une telle chance, de tels résultats) : accord avec ce nom.
  2. tel que (pour annoncer des exemples) : accord avec le nom qui précède
     (des fruits tels que les pommes ; des villes telles que Lyon).
  3. tel quel (= sans changement) : en deux mots, accordés avec le nom
     (laisser les choses telles quelles). « Tel que » dans ce sens est une faute.
  4. tel attribut en tête de phrase (tel est mon avis) : accord avec le sujet qui suit.
Cas particuliers et pièges
  5. « tel » comparatif sans « que » (il fila tel une flèche) : l'usage hésite ; non exercé.
Niveau : supérieur.

## En bref

- **tel** devant un nom s'accorde avec lui : une **telle** chance, de **tels** résultats.
- **tel que** (exemples) s'accorde avec le nom **avant** : des villes **telles que** Lyon.
- **tel quel** (= sans changement), en deux mots accordés : des documents laissés **tels quels**.

## Fiche

**tel** devant un nom : il s'accorde avec ce nom.
> Une **telle** chance. De **tels** résultats. Un **tel** courage.

**tel que** annonce des exemples : il s'accorde avec le nom qui **précède**.
> Des fruits **tels que** les pommes. Des villes **telles que** Lyon et Lille.

**tel quel** veut dire « sans changement ». Les deux mots s'accordent avec le nom.
> J'ai laissé le dossier **tel quel**. Elle a rendu la copie **telle quelle**. Les choses sont restées **telles quelles**.

**Le test** : « sans changement » → **tel quel** ; des exemples → **tel que**.

**Les pièges** :
- « Je l'ai laissé **tel que** » ✘ → je l'ai laissé **tel quel**.
- En tête de phrase, **tel** s'accorde avec le sujet qui suit : **tel** est mon avis ; **telles** sont les règles.

## Pour aller plus loin

- Après un nom masculin pluriel : des sports **tels que** le tennis.
- Dans une comparaison sans « que » (il fila tel une flèche), l'usage hésite entre les deux accords.

## Exercices essentiels

1. Je n'ai jamais vu une [tel → telle] foule.
   Pourquoi : Devant « foule » (féminin) : « telle ».

2. Il aime les fruits [telles → tels] que les pommes et les poires.
   Pourquoi : Accord avec le nom qui précède, « fruits » (masculin pluriel) : « tels que ».

3. J'ai laissé le dossier [tel que → tel quel].
   Pourquoi : Sans changement : « tel quel ».

4. Nous avons visité des villes [tels → telles] que Lyon et Lille.
   Pourquoi : Accord avec « villes » (féminin pluriel) : « telles que ».

5. Il a de [tels → telles] idées !
   Pourquoi : Devant « idées » (féminin pluriel) : « telles ».

6. Elle a rendu la copie [telle que → telle quelle].
   Pourquoi : Sans changement : « telle quelle ».

7. [Une telle → Un tel] courage force le respect.
   Pourquoi : « Courage » est masculin : « un tel ».

8. Le zoo abrite des animaux [telles → tels] que la girafe et l'éléphant.
   Pourquoi : Accord avec « animaux » (masculin pluriel) : « tels que ».

9. De tels problèmes, tels que ceux-ci, demandent du temps.
   Pourquoi : Correct : « tels » s'accorde avec « problèmes » et avec « ceux-ci ».

10. Je n'ai jamais eu une ___ chance.
    Choix : **telle** / tel
    Pourquoi : Devant « chance » (féminin) : « telle ».

11. Tri : masculin ou féminin ?
    Colonnes : tel, tels | telle, telles
    - des légumes (tel) que les carottes → tel, tels
    - des fleurs (tel) que les roses → telle, telles
    - un (tel) bruit → tel, tels
    - une (tel) vitesse → telle, telles
    - le texte, laissé (tel quel) → tel, tels
    - la porte, laissée (tel quel) → telle, telles
    Pourquoi : Tel s'accorde avec le nom auquel il se rapporte.

## Exercices avancés

12. Les choses sont restées [tel quelles → telles quelles].
    Pourquoi : « Tel quel » : les deux mots s'accordent avec « choses ».

13. Elle pratique des sports [tel → tels] que le tennis.
    Pourquoi : Accord avec « sports » : « tels que ».

14. [Telle → Tel] est mon avis.
    Pourquoi : En tête de phrase, accord avec le sujet « mon avis » (masculin) : « tel ».

15. Telles sont les règles du jeu.
    Pourquoi : Correct : accord avec « les règles », le sujet placé après.

16. Gardez ces documents ___.
    Choix : **tels quels** / tel que / tels que
    Pourquoi : Sans changement : « tels quels », accordé avec « documents ».

17. Il cherche un métier [tels → tel] que boulanger ou pâtissier.
    Pourquoi : Accord avec « un métier » (masculin singulier) : « tel que ».
