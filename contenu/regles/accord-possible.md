# L'accord de « possible »

Identifiant : accord-possible
Niveau : supérieur
Résumé : Le plus de fautes possible (invariable) ; toutes les solutions possibles (accordé).

## Analyse

Décision demandée : accorder ou non « possible ».
Cas de base
  1. Après « le plus, le moins, le mieux, le meilleur… », possible se rapporte au pronom
     sous-entendu « qu'il est possible » : invariable (faites le moins d'erreurs possible).
  2. Quand il qualifie un nom (= qui peut exister, se faire), il s'accorde
     (toutes les solutions possibles ; des retards sont possibles).
  Test : peut-on dire « qu'il est possible » à la place ? → invariable.
Cas particuliers et pièges
  3. « les meilleurs résultats possible » : invariable (= qu'il est possible d'obtenir).
  4. « tous les cas possibles » : accordé (= qui peuvent se présenter).
Niveau : supérieur.

## En bref

- Après **le plus, le moins, le mieux, le meilleur…** : **invariable** → le plus de fautes **possible** (= qu'il est possible).
- Quand il qualifie un **nom** (= qui peut exister) : **accord** → toutes les solutions **possibles**.

## Fiche

**Possible** est invariable quand il suit **le plus, le moins, le mieux, le meilleur, les meilleurs…** : il signifie alors « **qu'il est possible** ».
> Faites le moins d'erreurs **possible**. Il a vendu le plus de livres **possible**. Les meilleurs résultats **possible**.

**Possible** s'accorde quand il **qualifie un nom** : il signifie « qui peut exister, se produire ».
> Toutes les solutions **possibles**. Des retards sont **possibles**.

**Le test** : remplacez par « **qu'il est possible** (de faire, d'avoir) ». Si la phrase garde son sens → invariable.

## Pour aller plus loin

- « Tous les cas **possibles** » : les cas qui peuvent se présenter, accord.
- « Le plus de cas **possible** » : autant qu'il est possible, invariable.

## Exercices essentiels

1. Faites le moins d'erreurs [possibles → possible].
   Pourquoi : Après « le moins » : « qu'il est possible », invariable.

2. Nous avons étudié toutes les solutions [possible → possibles].
   Pourquoi : Les solutions qui peuvent exister : adjectif, accord.

3. Il a vendu le plus de livres [possibles → possible].
   Pourquoi : Après « le plus » : invariable.

4. Des retards sont [possible → possibles] en cas de neige.
   Pourquoi : Attribut de « des retards » : accord.

5. Prenez le moins de bagages [possibles → possible].
   Pourquoi : Après « le moins » : invariable.

6. Il faut envisager tous les cas [possible → possibles].
   Pourquoi : Les cas qui peuvent se présenter : accord.

7. Elle a obtenu les meilleures notes [possibles → possible].
   Pourquoi : « Les meilleures notes qu'il est possible d'obtenir » : invariable.

8. Ce sont les seules issues [possible → possibles].
   Pourquoi : Les issues qui existent : adjectif, accord.

9. Invitez le plus d'amis possible et prévoyez toutes les boissons possibles.
   Pourquoi : Correct : « possible » invariable après « le plus » ; accordé avec « boissons ».

10. Répondez le plus vite ___.
    Choix : **possible** / possibles
    Pourquoi : Après « le plus » : invariable.

11. Tri : invariable ou accordé ?
    Colonnes : invariable (qu'il est possible) | accordé (qui peut exister)
    - le moins de fautes (possible) → invariable (qu'il est possible)
    - toutes les hypothèses (possible) → accordé (qui peut exister)
    - le plus de places (possible) → invariable (qu'il est possible)
    - des erreurs (possible) → accordé (qui peut exister)
    - les meilleurs prix (possible) → invariable (qu'il est possible)
    - plusieurs chemins (possible) → accordé (qui peut exister)
    Pourquoi : Après le plus, le moins, le meilleur : invariable. Avec un nom qu'il qualifie : accord.
